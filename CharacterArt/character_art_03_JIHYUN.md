## 유지할 인물

- 백지현 / jihyun, 30세. 사업전략팀 팀장, 입사 8년 차. 도현의 직속 상사가 아닌 다른 팀 협업 팀장.
- 기본 인상은 당당하고 기 센 누나·여왕형. 또렷하게 눈을 맞추고 상대의 대답을 기다릴 줄 아는 자신감. 책임과 판단 기준을 분명히 한다. 무례함·상시 분노·협박으로 강함을 표현하지 않는다.
- 사적으로는 다정함을 부탁하는 데 망설이며 수줍고 응석 있는 모습이 나온다. 업무 능력과 독립성이 사라지지는 않는다.
- 결론부터 말하는 반말. 서윤처럼 매번 능글맞게 웃지 않는다.
- 현행 사적 성향은 M 성향·칭찬 선호·합의된 주도권 역전. 평소의 단호함과 연인에게만 맡기는 순간의 대비를 유지한다. 기본 표정을 수줍음·겁먹음으로 만들거나 일상적으로 복종하는 인물로 바꾸지 않는다. 실제 업무 잘못에 대한 벌과 연결하지 않는다. 일반 입상에 특정 사적 도구를 추가하지 않는다.

### 이전 기준과의 차이

이전의 재킷 없는 셔츠·검정 트임 펜슬스커트·어두운 스타킹 조합은 과거 업무복이다. 현재 기본은 재킷·바지 조합이며 기존 전신의 허리 짚기 포즈를 강제하지 않는다. 붉은 매니큐어 등 사진에서 가려져 확인되지 않는 상세를 예전 자산만 보고 새 필수값으로 추가하지 않는다.

## 표정 8종

자신감 있는 기본 웃음 / 판단에 집중 / 짧은 만족 / 반론을 듣는 선명한 눈매 / 예상 밖 칭찬에 잠깐 멈춤 / 연인 앞에서만 드러나는 수줍음 / 먼저 다가와 주길 기다리는 망설임 / 힘을 뺀 애정. 수줍은 표정에서 눈과 얼굴 비율을 어린 형태로 바꾸지 않는다.

## 자세와 손

기본은 상체와 어깨의 긴장을 푼 당당한 입상으로 만든다. 설명·조립·앉은 대화에는 동작에 맞는 팔 세트를 사용한다. 타이틀 v002를 편집할 때에는 내린 팔의 가림과 리아와의 경계를 유지한다. 다른 단독 장면에서 드러나는 손은 새로 검수한다.

## 제작·검수

- 장면에 맞게 표정·시선·팔 동작을 바꿀 수 있지만 얼굴 비율·머리·체형·의상 디자인을 다른 인물과 섞지 않는다. 타이틀의 포즈나 표정을 모든 컷의 기본값으로 복제하지 않는다.
- 동일한 원본 타이틀을 직접 참조하고 결과를 원본과 비교한다. 누적 편집본을 새 화풍 기준으로 삼지 않는다.
- 신장·신체 치수·가려진 등판·다리·신발은 사진만으로 확정하지 않는다. 새 전신에서 필요한 미확인 부분은 제작 제안과 확인 결과를 분리해 기록한다.
- 귀걸이·귀 피어싱·임의 장신구를 추가하지 않는다. 남색 사원증 스트랩과 세로 홀더 한 개를 유지한다. 카드 안쪽 이름·회사 로고는 제공된 디자인 없이 생성하지 않는다.
- 손 크기·관절·겹침·팔 연결은 매 이미지에서 검수한다. 눈·입·머리 가닥·옷 주름이 편집 범위 밖에서 바뀌었는지도 원본과 비교한다.
- 새 입상은 [레이어 기준](character_art_08_LAYERS.md)을 따른다. [공통 지침](character_art_01_COMMON.md)의 도현 손·팔 허용 규칙을 적용하고 얼굴·전신을 자동 추가하지 않는다.
