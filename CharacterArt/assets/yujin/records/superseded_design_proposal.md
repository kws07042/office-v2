# 차유진 — 이미지 제작용 캐릭터 설정

## 과거 외형 A안 — 생성 기준에서 제외

| 요소 | 한 장의 초안을 위한 제안 |
|---|---|
| 실루엣 | 어깨의 긴장을 조금 모으는 준비된 자세. 작은 체구의 느낌을 쓰더라도 성인 비율 유지 |

| 디테일 | 카디건 작은 단추 4개를 초안 기준으로 검토. 장식 없는 짧은 소매 끝. 귀걸이·귀 피어싱 없음. 헤어핀은 A안 제안 |

| 색 방향 | 세이지·라벤더·크림. 실제 스타일 참조와 맞춰 최종 조정 |

## 자세와 손

기본은 작은 노트 없이 편하게 선 자세부터 검토한다. 두 번째는 개인 노트나 전시 티켓을 보여주며 상대를 바라보는 동작. 노트를 잡는 손은 엄지·손가락의 앞뒤와 페이지 경계를 분리한다. 노트 글자를 AI로 읽히게 그리지 말고 필요한 글자는 후편집한다.
