# 속옷·잠옷 취향 설정 (성인 장면 도입 CG용)

2026-11-23 사용자 요청으로 정했다. 성인 이벤트 도입 CG에서는 히로인이 그날 입던 옷이 흐트러져 속옷이 보인다. 그때 히로인마다 속옷이 들쭉날쭉하지 않도록 취향을 고정한다.
- 얼굴·헤어·체형은 [현행 외형 기준](APPEARANCE_CURRENT.md)을 따른다.
- 성격과 말투는 대본을 따른다.
- 모든 인물은 27~32세 성인이다. 비치는 소재, 노출, 성행위 묘사는 도입 CG에 넣지 않는다.

## 한눈에

| 인물 | 한 줄 취향 | 색 | 소재·모양 | 절대 안 하는 것 |
|---|---|---|---|---|
| 강리아 | 귀엽고 밝게, 편한 게 먼저. 특별한 날만 레이스 | 하늘색, 흰색, 민트, 남색 | 면 + 얇은 레이스 트림, 작은 리본, 풀컵 브라와 기본 팬티 | 검정 망사, 끈 팬티, 가터 |
| 백지현 | 보이지 않는 데까지 단정하게. 상하 세트는 무조건 맞춤 | 버건디, 와인, 검정, 아이보리 | 무지 새틴·실크, 가장자리에만 절제된 레이스, 장식 최소 | 큰 리본, 프릴, 캐릭터 무늬, 짝 안 맞는 세트 |
| 차유진 | 색과 감촉으로 고른다. 수줍어서 화려한 건 잘 못 산다 | 피치, 세이지그린, 크림, 헤더 그레이 | 부드러운 면·모달, 작은 자수 포인트, 볼륨 있는 체형에 맞는 풀컵 | 원색, 강한 대비, 과한 레이스 |
| 한서윤 | 남이 안 봐도 자기 기분 좋으라고 고른다. 가터는 평소에도 | 짙은 자두색, 검정, 라벤더 | 레이스와 새틴 세트, 가터벨트와 레이스 밴드 니삭스 | 귀여운 무늬, 스포츠 브라 |

## 인물별 설정

### 강리아
- **평소:** 면 소재의 편한 세트에 하늘색이 제일 많다. 현장을 하루 종일 걸어 다녀서 편한 게 먼저다.
- **특별한 날:** 흰 레이스에 파란 리본. 파란 슈슈와 같은 '파란 포인트'를 좋아한다.
- **집:** 남색 스포티 면 세트, 회색 돌핀 반바지.
- **회사 날:** 블라우스 아래 비치지 않게 무난한 검정 면 세트. 모텔 장면이 갑작스러웠다는 게 여기서 드러난다.
- **반응:** 들키면 "오늘 이거 아무 생각 없이 입은 건데!" 하고 웃지만 귀가 빨개진다.

### 백지현
- **평소:** 짙은 버건디 새틴 세트. 레이스는 가장자리에만 있다. 옷은 개어 두고 속옷도 다림질한 듯 단정하다.
- **특별한 날:** 검정 레이스 세트. 고른 이유를 물으면 "결론부터. 네가 볼 거니까."
- **집:** 아이보리 실크 세트, 토프 니트 카디건, 라운지 바지.
- **반응:** 칭찬에 약하다. 속옷을 칭찬받으면 말을 잃는다.

### 차유진
- **평소:** 피치색 면 세트에 작은 자수 리본 하나. 디자이너라 색 조합에는 까다롭다.
- **특별한 날:** 세이지그린 레이스 세트. 니트 원피스와 같은 색이다. 매장에서 한참 망설이다 산 '처음 사 본 레이스'다.
- **집:** 헤더 그레이 면 세트, 오버사이즈 흰 셔츠.
- **반응:** "색… 맞춘 거 티 나요?" 하고 물어보고 바로 후회한다.

### 한서윤
- **평소:** 짙은 자두색 레이스 세트. 업무복에도 가터와 레이스 니삭스를 신는다(외형 기준과 같다).
- **특별한 날:** 검정 새틴 세트, 가터벨트, 검정 레이스 밴드 니삭스.
- **집:** 라벤더 실크 세트, 샴페인색 새틴 잠옷. 작업실에 둔다.
- **반응:** 처음엔 "눈 둘 데 없지?" 하고 떠보다가, 진심인 순간엔 장난을 멈춘다.

## 장면별 사용표 (도입 CG)

| 장면 | 겉옷(흐트러진 상태) | 속옷 |
|---|---|---|
| 리아 R07 첫 밤 | 크림 니트가 한쪽 어깨로, 데님 스커트 | 하늘색 면 + 흰 레이스 트림 |
| 리아 R12 데이트 | 하늘색 오프숄더 니트 원피스, 지퍼 반쯤 | 흰 레이스 + 파란 리본 |
| 리아 R15 생활복 | 흰 후드가 한쪽 어깨로, 회색 반바지 | 남색 스포티 면 |
| 리아 모텔 | 흰 블라우스 단추 반쯤, 검정 펜슬 스커트 | 무난한 검정 면 |
| 지현 R07 | 터틀넥은 개어 두고, 긴 스커트 옆 지퍼 열림 | 버건디 새틴 + 가장자리 레이스 |
| 지현 R12 데이트 | 와인색 랩 원피스 끈이 풀림 | 검정 레이스 세트 |
| 지현 R15 생활복 | 토프 카디건이 어깨로, 라운지 바지 | 아이보리 실크 |
| 유진 R07 | 카디건이 팔꿈치로, 블라우스 단추 풀림, 주름 스커트 | 피치색 면 + 작은 자수 리본 |
| 유진 R12 데이트 | 세이지 니트 원피스를 어깨 아래로 | 세이지그린 레이스 |
| 유진 R15 생활복 | 오버사이즈 흰 셔츠 단추 풀림, 레깅스는 벗어 둠 | 헤더 그레이 면 |
| 서윤 R07 | 회색 니트 원피스를 허리까지, 카디건은 바닥에 | 짙은 자두색 레이스 |
| 서윤 R12 데이트 | 검정 새틴 블라우스 단추 다 풀림, 라벤더 스커트 | 검정 새틴 + 가터 + 레이스 니삭스 |
| 서윤 R15 생활복 | 샴페인 새틴 잠옷 셔츠 단추 풀림 | 라벤더 실크 |

코스프레 장면(R15)은 의상이 몸을 다 가려서 속옷이 보이지 않는다.
