## 반영한 수정
- 리아 우산: 전신 구도를 제외하고 머리~허벅지 구도로 비율 수정, 배경 2D 작화 정리.
- 지현: GitHub 기준 이미지를 직접 참조한 얼굴. 조립은 부품을 내려다보는 집중한 표정, 카드는 편하게 즐기는 자연스러운 웃음.
- 지현이 손에 든 패 3장은 동일한 카드 뒷면. 테이블에 낸 카드와 공개 카드는 앞면.
- 지현 마스터·조립·카드의 블라우스 안쪽에 동일한 짙은 회색 레이스 가장자리.
- 지현 마스터는 재생성 없이 알파만 정리했다. 원본 RGB 배열 동일 검증, 외곽·틈새 투명화, 흰색/남색 배경 검수.
- 입상은 파츠별 레이어 방식으로 제작한다. 규격은 [레이어 제작 기준](character_art_08_LAYERS.md) 참조.

## 크기와 적용 상태
CG 원본은 전부 1672×941, 마스터는 1024×1536이다. 최종 게임 화면 1920×1080 변환과 대화창에 손·책·카드가 가려지는지 검수는 별도다. CG는 평면 PNG이며 입상 레이어 PNG·PSD를 완료한 상태가 아니다. 모든 파일의 크기·SHA256·Git blob SHA는 [CG_CURRENT.json](CG_CURRENT.json)에 기록한다.

리아·유진 원래 마스터와 서윤 기준 이미지는 기존 저장소 파일을 유지한다. 기존 지현 사원증 기준본도 원본 이력으로 보존하며, 현재 의상·누끼 기준은 이 목록의 지현 마스터를 우선한다.
