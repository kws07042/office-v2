참조: [타이틀 v002](../../../assets/title/title_escalator_jihyun_arm_lowered_v002.png)의 오른쪽 앞 강리아. [현행 외형 기준](../../../APPEARANCE_CURRENT.md)을 따른다. 성인28세, 기본 업무복과 중립 미소. 사용자가 지정한 짧은 하의·구두를 반영했고 첫 번째 후보의 색감을 유지하면서 양손과 누끼를 보정했다.

인물의 보호된 내부 색은 유지했고, 누끼의 배경색 혼입을 줄이기 위해 일부 가장자리 RGB·알파는 변경했다. 전체 RGB가 첫 번째 이미지와 동일하다고 주장하지 않는다. 현재 크기는1024×1536이며2048×3072 레이어 원본·표정 파츠·Live2D·게임 연결은 별도다.

이전 생성본과 실패한 수정 시도·중간 마스크는 로컬 작업 이력으로 보존한다. 이 폴더의 .gitignore는 해당 기존 작업 파일만 제외하며 후속 새 버전을 일괄 차단하지 않는다. 최신 후보와 직접 검수 자료만 이번 체크포인트에 포함한다. 현재 승인 자산 목록을 자동 교체하지 않는다.

다음 추천 작업은 지현 마스터1장 제작이다. 지현 외형은 타이틀의 오른쪽 뒤 인물을 직접 참조한다.
