## 참조 범위와 검수 원칙

- 얼굴·헤어·머리 리본·복장·색감의 실제 참조로 사용한다. 인물 성격·말투는 아래 기존 설정을 유지한다.
- 손의 교차 선·손톱 경계와 가장자리의 잔여 픽셀은 따라야 할 고정 디자인에서 제외한다. 새 장면에서는 자연스러운 자세로 만들고 이미지마다 확인한다.
- 확대 손이 좋아 보여도 전신 재편집에서 같은 형태가 유지되는지 별도로 비교한다. 실제 게임 표시 크기에서도 손톱·겹침·선 두께를 확인한다.
- 리아와 같은 애니메이션 계열이지만 머리 광택·명암 대비는 더 부드럽게 보인다. 캐릭터의 머리색·의상 소재 차이를 제거해 억지로 같게 만들지 않고, 후속 자산에서 공통 선화·광원·피부 명암 기준을 대조한다. 완전 동일 그림체라고 판정하지 않는다.
- 입상·분리 레이어는 실제 투명 배경, 배경이 필요한 일반 CG·메신저 사진은 장면 배경을 사용한다.
- 손을 예쁘게 만들겠다는 이유로 과도하게 길고 납작한 손가락·강한 평행 선·큰 손톱을 추가하지 않는다. 얼굴과 어울리는 간결한 선화를 유지한다.
- 도현의 얼굴·몸·손·실루엣·반사는 일반 CG에 기본으로 넣지 않는다. 카메라는 도현이 히로인을 보는 시점이다.

## 자세와 손

기본은 작은 노트 없이 편하게 선 자세부터 검토한다. 두 번째는 개인 노트나 전시 티켓을 보여주며 상대를 바라보는 동작. 노트를 잡는 손은 엄지·손가락의 앞뒤와 페이지 경계를 분리한다. 노트 글자를 AI로 읽히게 그리지 말고 필요한 글자는 후편집한다.
