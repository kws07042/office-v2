## 자산과 게임 적용 상태

현재 참조는 네 인물이 합쳐진 평면 타이틀 PNG다. 새 외형의 개별 전신·표정·입상 파츠가 이미 제작되거나 게임에 연결된 상태로 간주하지 않는다. 입상은 이후 레이어별로 제작한다. 이번 변경은 문서와 자산 인덱스이며 원본 PNG·실행 파일·게임 코드는 보존한다.

2026-11-02 업로드 CG 8장·지현 레이스/알파 정리 마스터는 [보관 목록](CG_CURRENT.md)에 남긴다. 리아 v001·유진 예비 마스터·지현/서윤 이전 의상안도 이력이며 현행 타이틀 외형보다 우선하지 않는다. Windows0.10.0-ria-expressions의 R02 표정 연결은 이전 리아 마스터에 대한 적용 이력이다.
