# 입상 레이어 제작 확정 기준

2026-11-02 사용자 결정: 모든 히로인의 입상은 파츠별 레이어 방식으로 제작한다. 이 문서는 제작 규격이며 실제 파츠 이미지가 이미 완성되었다는 뜻은 아니다.

현행 외형은 [2026-11-04 타이틀 v002](APPEARANCE_CURRENT.md)를 따른다. 이 평면 RGB 단체 이미지는 개별 전신·분리 파츠 완성본이 아니다. 아래 제작 규격은 유지한다.

## 파일과 정렬
- 기본 캔버스 2048×3072 PNG RGBA. 각 파츠는 실제 투명 배경, 동일 캔버스·해상도·원점·발 위치로 출력한다.
- 작업 원본은 레이어가 살아 있는 PSD 또는 동등한 편집 원본. 게임용은 레이어별 PNG + 조합 manifest.
- 파츠마다 자동 여백 자르기 금지. 다른 표정이나 의상을 새로 전신 재생성하여 겹쳐 맞추는 방식은 사용하지 않는다.
- 기본 합성 미리보기와 흰색/남색 배경 QA 미리보기를 별도 보관한다.

## 표정과 포즈
- 표정 8종은 같은 얼굴 바탕과 고정 위치의 눈썹·눈·입·홍조 조합으로 만든다.
- 눈 깜박임과 입 모양은 선택적 확장. 이번 결정만으로 Live2D 리깅·머리 각도 전체 세트를 확정하지 않는다.
- 기본 포즈와 설명 포즈는 별도 팔/손 세트. 어깨나 몸통 방향이 달라지면 해당 몸통도 포즈 세트로 교체한다.
- 의상·소매·팔·손 조합에 호환 목록을 둔다. 서로 다른 포즈의 손을 임의로 조합하지 않는다.
- 가려진 면은 이동 범위만큼 보완한다. 평면 완성본을 단순히 자른 파일을 완전한 교체 레이어로 간주하지 않는다.

- 2026-11-02 사용자 정정: 도현의 손·팔 등장은 허용한다. 상호작용을 전달할 때 활용한다. 얼굴·전신은 이번 제작 범위에서 제외한다.
- 앞선 분류표에서 도현 손을 제외하도록 적은 내용보다 이 최신 결정이 우선한다.
- 네 히로인은 타이틀 v002 원본의 각 인물과 갱신된 개별 문서를 직접 참조한다. CG_CURRENT.md/CG_CURRENT.json의 이전 개별 마스터·CG는 이력이며 현재 외형보다 우선하지 않는다.
- 귀걸이·피어싱 없음. 현행 사진의 얼굴·가르마·헤어 색·의상·사원증을 유지한다. 사진에서 선명하지 않은 서윤의 과거 점·시계를 강제하지 않는다. 리아의 머리 리본과 유진의 목 리본을 서로 섞지 않는다.
- 2026-11-02 사용자 확정: 모든 배경은 히로인과 같은 그림체로 제작한다. 선 굵기·형태 단순화·셀 명암·색감·디테일 밀도를 맞추며 사진 배경·실사 재질·3D 렌더 느낌을 혼합하지 않는다. 배경만 지나치게 사실적이면 수정 대상으로 처리한다.
