# UI 미리보기와 수정 기록

2026-11-19 KST, main의 ac6ea29 기준.

`index.html`을 브라우저에서 열면 우리의 기록, 저장, 불러오기, 설정, 대화, 메신저, 대화 기록을 전환할 수 있습니다. 기존 게임의 실크 색상과 메뉴 구조를 바탕으로 만든 시안입니다. 화면의 수치·저장·대사·메신저는 예시이며 실제 게임 데이터와 연결되지 않습니다. 좁은 화면에서는 브라우저용으로 재배치합니다. 게임의 픽셀 단위 스크린샷은 아닙니다.

## 게임 수정

- 관계 상세에 스크롤을 추가해 긴 설명과 하단 옵션까지 접근할 수 있게 했습니다.
- CG 회상 버튼을 가로 한 줄에서 스크롤 가능한 세로 목록으로 바꿨습니다. 갤러리 높이를 조절해 목록 공간을 확보했습니다.
- 글자 즉시 표시를 끄면 켜기 전 속도로 돌아갑니다. 메뉴를 열 때 이미 즉시 표시 상태였다면 기본 복귀 속도는 초당 40자입니다.

## 확인 범위

- git diff --check와 미리보기 JavaScript 문법 검사 통과.
- Chromium에서 7개 화면을 1280, 736, 390, 320px 너비로 확인. 가로 넘침 없음.
- 관계 탭 전환, 빈 불러오기 칸 비활성화, 즉시 표시 해제 시 67자 속도 복원 확인. 브라우저 JavaScript 오류 없음.
- 첫 브라우저 검사에서 736px 기록 화면의 가로 넘침을 발견해 분기 너비를 수정했습니다.
- Ren'Py 소스는 정적으로 검토했습니다. AGENTS.md의 게임 스크립트 검사 실행 제한에 따라 엔진 실행 검증은 수행하지 않았습니다.

다음 검증은 검토된 공식 SDK 환경에서 관계 설명이 긴 저장 상태, 많은 회상 항목, 글자 속도 스위치를 실제 게임으로 확인하는 것입니다.
