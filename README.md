# 퇴근 후, 우리 — 오피스 V2

비공개 개발 저장소. Source는 **0.35.3-seoyun-parent-review**이며, 저장소의 Windows 실행판은 **0.34.1-dialogue-style**입니다.

## 실행과 제작 상태

기존 `Windows` 실행판은 원화 전면 삭제 후 재빌드 전 상태입니다. 배포용 실행판은 최신 `Source`와 검증된 공식 Ren’Py SDK로 새로 빌드해야 합니다. 런타임·라이선스는 유지하며 개인 저장 파일과 캐시는 제외했습니다.

공통 C01~C08, 네 히로인의 R01~R16·선택 일상·메신저·후일담, 세 답장과 선택 기억이 연결되어 있습니다. 최근에는 고백 직후 R05~R08의 행동·장난·감정 연결을 편집하고, 속마음을 『…』로 표시하며 히로인 이름 색을 구분했습니다. 친밀한 본장면은 기존 생략·자리 표시 상태입니다. 최종 그림·음성·배경·연출은 미완성입니다.

주된 업무 방식(검증·조율·실행)에 따른 미니 사건 6개를 Source에 추가했습니다. C07 선택을 이어받아 한 회차에 2개가 나오며, 첫 사건에서 고른 행동이 둘째 사건의 대사로 돌아옵니다. 첫 사건은 C08 뒤, 둘째 사건은 R08 뒤 또는 동료 결말 앞에 연결합니다. 상세 대본·연결·기억 규칙은 [집필 기록](Docs/업무미니6개_집필과연결_v1.md), 실제 검사 결과는 [검증 기록](Docs/validation/work-minis-2026-11-02.md)을 참고하세요. 이 6개는 기존 Windows 폴더에는 아직 반영되지 않았습니다.

전편 통합 퇴고에서 놀이 선택의 회수, 갈등 뒤 감정 전환, 날짜·시각·물건 이동과 사적 호칭을 다듬었습니다. 95개 사건과 이벤트 전후 16분기를 검토했고, 기존 선택·보상·본장면 생략 위치는 유지했습니다. [전편 퇴고 기록](Docs/전편대본_통합퇴고_v1.md)과 [실행 검증](Docs/validation/full-script-edit-2026-11-02.md)을 우선 참고하세요. 실제 독자의 플레이 시간은 아직 측정하지 않았습니다.

플레이 흐름 보강에서는 유진의 관계 결정을 업무 뒤로 옮기고, 서윤의 비밀 공개 이후 감정을 이어 가며, 지현의 조립·유진의 스케치·리아의 거품 장난을 보강했습니다. [변경 장면과 검증 범위](Docs/플레이흐름_재미보강_v1.md)를 참고하세요. 이 변경도 기존 Windows 실행판에는 아직 반영되지 않았습니다.

## 폴더

- `Windows`: 바탕화면 오피스 V2의 현재 실행판.
- `Source/game`: 설치본 개발자료의 현행 실행 소스·검사 소스·기존 자산. `story`, `tools`는 작성·검수 자료입니다.
- `Docs`: 현행 기획·대본·결정·검수 MD. 최신 대본 상태는 `플레이흐름_재미보강_v1.md`와 현행 Source를 우선합니다. `교제초반_편집보고서_v1.md`, `독백과_이름색_현행규칙_v1.md`, 인물별 `검수후_현행대본.md`는 앞선 단계의 기록으로 보존합니다. 옛 보고서의 버전과 시험 수는 당시 기록입니다.
- `CharacterArt`: 타이틀 v002의 현행 외형 참조와 제작 설정·과거 검수 기록. 기존 캐릭터·CG·후보 PNG는 2026-11-06 사용자 요청으로 삭제했습니다.
- `Source/art`: 삭제 전 후보의 프롬프트·QA 이력. 이미지 후보는 삭제했습니다.
- `Preview`: 기존 UI 웹 시안. 현재 실제 게임 기능의 기준은 Windows 실행판입니다.

캐릭터·CG·후보 원화 51개(설치 복사본·얼굴 마스크 포함)를 삭제하고 타이틀 v002는 참조로 유지했습니다. UI·로고·엔진 이미지·Preview 화면은 유지했습니다. Source는 미제작 입상을 숨기는 처리를 추가했으며, 기존 Windows 빌드는 삭제된 이미지를 참조할 수 있어 배포용으로 사용하려면 최신 Source와 공식 SDK로 새로 빌드해야 합니다. [전수 대본 검토 및 재제작 명세](Docs/production-review-v001/REVIEW.md)와 [삭제 명세](Docs/production-review-v001/art-reset.json)를 참고하세요. 이 변경의 엔진 실행·새 빌드는 미검증입니다.

## 검증

플레이 흐름 보강은 구조·Ren’Py lint와 Linux 실행 147사례·2,072항목을 통과했습니다. [최종 검증 기록](Docs/validation/player-flow-2026-11-02.md)과 [대사 미리보기](Docs/재미보강_장면미리보기.md)를 참고하세요. 이 작업에서는 Windows 폴더를 갱신하거나 새 Windows 배포물을 빌드하지 않았습니다.

전편 퇴고는 구조·린트, Linux Ren’Py 자동 실행 133사례·1,896항목과 새 Windows ZIP 구성 검사를 통과했습니다. [확인 범위와 실패 수정 기록](Docs/validation/full-script-edit-2026-11-02.md)을 참고하세요.

업무 미니 사건 변경은 Linux Ren’Py 실행 검사 57사례·937항목과 공식 SDK를 사용한 새 Windows ZIP 구성 검사를 통과했습니다. [검사 범위와 빌드](Docs/validation/work-minis-2026-11-02.md)에 실패 수정 기록과 미확인 범위를 함께 남겼습니다.

교제 초반 작업은 Windows 자동 검사 86사례·2,026항목, 그 뒤 독백·이름 색 변경은 별도 표시 검사 8사례·32항목을 통과했습니다. 서로 다른 작업의 범위이며 이번 업로드 때문에 전편을 다시 실행했다고 주장하지 않습니다. 자동 검사와 실제 독자의 재미 평가는 다릅니다. 자세한 순서와 미확인 범위는 `Docs/validation`과 각 검수 MD를 참고합니다.

저장·인증 정보·캐시·이전 버전 백업 폴더는 업로드 대상에서 제외했습니다. 글꼴과 런타임 라이선스를 보존합니다. 게임 고유 소스·대본·캐릭터 자산에 대한 별도의 공개 이용 허락은 부여하지 않습니다.
