# 퇴근 후, 우리 — 오피스 V2

Windows 개발판 **0.11.1-office-round**. 완성본이 아닌 개발 중인 프로젝트다.

## 실행

Windows 폴더 전체를 내려받아 `afterwork_script_prototype.exe`를 실행한다. 시작 화면의 **R08 메신저 확인**으로 오피스 라운드 메신저를 확인한다.

## 구성

- Windows: 실행에 필요한 게임·Ren’Py 런타임과 라이선스.
- Source: Ren’Py 원본 프로젝트의 game·story·tools. Ren’Py 8.5.3 기준.
- Docs: 최신 기획·결정·구현 문서.
- Preview: 메신저 실제 게임 캡처.

연락처·채팅·답장 3개·사진 확대·대화 기록·중요 답장의 입력 중 표시를 구현했다. 실제 식탁 사진은 미제공으로 준비 중 카드다. 다른 히로인 루트·최종 배경·음향은 제작 중이며 기존 리아 표정 차분은 검수에서 반려되어 최종 승인 자산이 아니다.

글꼴은 수정하지 않은 Pretendard·Gowun Dodum을 동봉하며 각각의 SIL OFL 1.1 원문은 game/fonts에 포함한다. Ren’Py 및 의존 라이브러리 라이선스는 Windows/licenses를 참고한다. 게임 고유 소스·대본·캐릭터 자산에 대한 별도의 공개 이용 허락은 부여하지 않는다.

저장 데이터·로그·캐시·이전 버전 백업·이전 버전 ZIP은 포함하지 않는다.
