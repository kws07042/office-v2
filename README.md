# 퇴근 후, 우리 — 오피스 V2

Windows 개발판 **0.21.0-immersive-dialogue**, 현행 기획 v2.94. 개발 중인 프로젝트입니다.

## 실행

Windows 폴더 전체를 내려받아 `afterwork_script_prototype.exe`를 실행합니다. 실행 중인 구버전은 종료한 뒤 새 버전을 실행하세요.

## 현재 구현

공통 구간과 네 히로인의 개인 루트·후일담, 선택 기억과 호감도, 오피스 라운드 메신저의 연락처·채팅·답장 3개·사진 확대·기록을 연결했습니다. 중요한 답장에만 짧은 입력 중 표시가 나옵니다.

이번에는 62개 장면 블록과 메신저 본문을 재집필했습니다. 분기·실행 자동 검사 214개 사례, 4,318개 확인을 통과했습니다. 이는 재미의 완성이나 출시 준비 완료를 뜻하지 않습니다.

계획 95개 사건 중 텍스트 구현은 89개 슬롯입니다. 별도 업무 미니 사건 6개, 최종 그림·배경·음성·본장면 자산과 연출은 남아 있습니다. 친밀한 본장면은 생략·자리 표시를 유지합니다. 강리아·차유진의 현재 입상은 최종 전체 연출이 아니며, 기존 리아 표정 차분도 최종 승인 자산이 아닙니다.

## 구성

- Windows: 현재 검증한 Windows 실행판과 Ren’Py 런타임·라이선스.
- Source: 현재 Ren’Py 8.5.3 원본 game·story·tools·라이선스. 테스트 소스는 개발 검증용입니다.
- Docs: 현행 기획·결정·대본·검수 문서. `몰입과말맛_재집필_검수기록_v1.md`와 네 히로인의 `검수후_현행대본`을 우선 참고하세요. 이전 기록은 당시 버전의 이력입니다.
- Preview: 기존 메신저 미리보기. 최신 기능의 기준은 Windows 실행판과 현행 문서입니다.

저장 데이터·캐시·로그·개인 인증 정보·이전 버전 백업은 포함하지 않습니다. 글꼴 라이선스는 game/fonts, Ren’Py 및 의존 라이브러리 라이선스는 Windows/licenses에 있습니다. 게임 고유 소스·대본·캐릭터 자산에 대한 별도의 공개 이용 허락은 부여하지 않습니다.
