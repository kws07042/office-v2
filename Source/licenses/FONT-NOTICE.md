# 시험판 글꼴 출처

`game/SourceHanSansLite.ttf`는 공식 Ren’Py 8.5.3 SDK의 `sdk-fonts/SourceHanSansLite.ttf`를 수정 없이 복사했다. 글꼴 name 테이블의 Unicode 레코드에 아래 저작권·라이선스가 포함되어 있다.

글꼴 메타데이터의 원문 라이선스 URL: https://scripts.sil.org/OFL

OFL 전문은 `OFL.txt`, Ren’Py SDK와 엔진 구성요소의 라이선스는 `RENPY-LICENSE.txt`에 보관했다. DejaVu Sans는 SDK 엔진의 번들 글꼴을 참조하며 해당 구성요소 고지는 SDK 라이선스를 따른다. 현재 글꼴은 내부 시험용이며 최종 기획 UI의 글꼴을 확정한 것으로 취급하지 않는다.
