# 차유진 R01~R04 현행 구현 — 0.13.0-yujin-r04 / 기획 v2.85

## 기존 설정의 적용

유진의 설정을 새로 정한 작업이 아니다. 기존 95개 사건 명세·통합 기획서의 전시 제안, 수줍은 존댓말, 자기 취향과 의도를 직접 설명하는 성격, 첫 연애, 유진이 먼저 하는 고백을 구현했다. R02 손잡기 제안과 R03의 실제 행동 회수도 기존 명세를 따른다. 기존 전시 제목 ‘오후의 온도’를 사용한다. 작품의 방·빛·의자는 이번 장면을 구체화하기 위한 허구의 전시 묘사다.

| 사건 | 이번 구현 | 주요 기억 |
|---|---|---|
| R01 보내려던 메시지 | 유진이 먼저 전시 정보를 보내고 답장 3개로 관심·시각·추천 이유를 나눔 | yujin_r01_reply, 토요일 두 시 입구 약속, 첫 연락 |
| R02 오늘 코스는 제가 골랐어요 | 순서 따르기·창가 먼저 보기·한 작품에 머물기. 유진이 먼저 손잡기를 제안 | 실제 본 장면과 hand / later / talk. 접촉을 미뤄도 감점 없음 |
| R03 질문을 기억한 시안 | 공통 C03의 flow / message / process를 회수. 세부 기억 없는 확인 진입은 새 질문으로 처리. 전시의 실제 접촉 여부를 메시지에서 회수 | yujin_r03_response, 핵심 이해, 금요일 약속, 기록집 소개 여부 |
| R04 부끄럽지만 말할게요 | 유진이 먼저 고백. 바로 교제·준비 대화 뒤 같은 자리 재선택·동료 결말 및 결정 취소 | yujin_prepared_conversation, 교제 동의, 다음 데이트 제안 방식 |

목요일 연락 → 토요일 전시 → 다음 주 월요일 메시지·작업 확인·퇴근 후 카페 → 금요일 고백으로 날짜를 구분했다. 업무 시안은 R03의 짧은 확인 구간으로 두고 퇴근 후 관심·사진·다음 약속으로 연결한다.

## 관계와 후속 연결

- 존댓말과 ‘도현 씨’를 유지한다. 공통에서 리아와 반말을 골랐어도 유진 대사는 갑자기 반말로 바뀌지 않는다.
- 고백은 호감도 30 조건을 두지 않는다. R03의 실제 핵심 이해 뒤 상호 동의로 교제한다. 준비 대화 자체에 점수 보너스는 없다.
- R04에서 첫 입맞춤을 강제로 발생시키지 않는다. 기존 명세의 R05 배치를 위한 여지를 남긴다.
- yujin_next_date_plan은 dohyun_suggests / both_suggest / yujin_suggests다. 다음 토요일은 후보이며 실제 데이트를 완료했다고 기록하지 않는다.
- R04 완료는 유진 루트 전체 완주가 아니다. ending=yujin_early_segment_complete는 수록 구간 종료 표시이며 유진 완주 업적을 새로 해금하지 않는다.
- R05~R16·선택 일상 3개·E01은 기존 전체 기획에 남아 있다. 이번에 구현했다고 표시하지 않는다.

## 공통 시스템 연결

C08에서 차유진을 선택하면 실제 새 루트로 진입한다. 시작 화면에 ‘유진 R01~R04 확인’을 두며 공통 세부 기억 없는 확인 경로임을 짧게 알린다. 메신저는 기존 오피스 라운드를 사용하고 연락처·입력 중·기록·저장·불러오기를 재사용한다. 다른 연락처에 유진 메시지가 섞이지 않게 한다. 관계·호감도 헤더는 선택한 개인 루트를 표시하며 유진 교제 전/후·동료 상태를 구분한다.

## 자산과 미완료

캐릭터·배경 이미지·성인 CG·영상·음성·리깅 파일을 생성하거나 수정하지 않았다. 유진 예비 마스터를 최종 승인·실행 자산으로 새로 채택하지 않았다. 현재 유진 장면은 기존 임시 배경과 텍스트로 확인하며 리아 입상을 대신 띄우지 않는다. 실제 아트와 R05 이후는 후속 제작이다. 사건 95개·일반 CG 18개 목표는 유지한다.

공통 36~48분·고백 진입 60~90분은 제작 목표이며 이번 대본의 실측 결과가 아니다. 자동 실행 시간은 읽기 시간이 아니므로 분량 달성을 주장하지 않는다. 최종 문장 편집 후에는 패키지에서 새 루트를 다시 확인한다. GitHub 원격은 이번 작업에서 자동 갱신하지 않는다.
