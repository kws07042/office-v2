# 연애 중심 편집 실행 검증 — Windows 0.27.0-romance-focus

Ren’Py 구문 검사와 Windows 빌드 완료. 기존 오피스 V2의 대본과 비교해 메뉴 개수, 조건, 호출, 상태 기록, 보상·호감도 처리의 구조를 대조했다. 서윤 R15는 위스키 식사 뒤 집에서 별도의 친밀 선택을 묻고, 기존 진행/귀가/대화 세 갈래로 이어진다.

실제 Windows 진단 사본에서 91사례·2164확인 통과. 검사한 경로는 아래와 같다.

| 검사 | 사례 | 확인 |
|---|---:|---:|
| ria16_flow | 8 | 99 |
| jihyun_final_checks | 17 | 491 |
| yujin08_checks | 12 | 233 |
| yujin_final_checks | 28 | 641 |
| seoyun_checks | 26 | 700 |

패키지 CRC, 상대 경로, 원문·테스트·저장 파일 제외, 게임 파일 54개의 빌드 전후 일치를 확인했다. 이미지는 이전 0.26.0과 같고 리깅·음성·CG는 수정하지 않았다. 자동 검사는 분기와 실행을 확인하며 실제 플레이어의 재미를 증명하지 않는다.
