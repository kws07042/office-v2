# 리아 루트 메신저 연결 — 0.12.0-route-phone / 기획 v2.83

## 적용 범위

- R03: 이전 카페 방문 여부·존댓말/반말에 따른 첫 약속 연락.
- O01·O03: 잠깐 만나기를 미루고 짧게 안부를 전하는 세 번째 선택.
- R08: 기존 답장 3개·사진 확대·기록 연결을 유지.
- R11: 두 사람이 서윤에게 알리기로 선택한 경우에만 ‘함께 보낸 메시지’를 별도 서윤 연락처에 기록한다. 타인의 개인 대화함을 불러오는 기능은 없다. 축하 외의 연애 병행 연락은 추가하지 않는다.
- R12: 화~금 주간 연락과 토요일 재회 약속. O02에서 둘이 붙인 이름이 있으면 우선 기억하고, 없으면 R10 지도에서 고른 장소를 언급한다. 실제로 선택하지 않은 기억은 만들지 않는다. 장소 사진을 새로 생성·전송하지 않는다.
- R12 다음 날: 함께 아침을 맞으면 기존 대면 대화·선택을 유지한다. 각자 귀가한 경로만 연락·답장 3개를 메신저로 표시하며 기대·확정 시각·세 번째 확인 선택의 기존 기억 값을 유지한다.
- R13: 늦은 변경 연락·도현의 응답·도착 시각 재확인을 기록한다. 원래 서술에만 있던 네 시 반 연락은 비노골적인 짧은 실제 메시지로 옮긴다.
- R14: 고정 시각 또는 금요일 상호 확인 분기별로 다음 만남을 재확인한다. 약속 준수·갈등 수습·종료 선택·점수 지급은 기존 규칙을 유지한다.

## 화면과 기록

상단 도구는 오른쪽 정렬을 유지한다. 헤더는 현재 장면의 시간 정보를 표시하며 ‘오늘’ 고정 문구를 사용하지 않는다. 각 메시지에는 당시 location 앞부분을 moment로 저장하고 대화창에 날짜 구분을 표시한다. 이전 저장의 moment 없는 메시지는 ‘이전 대화’로 표시한다. 메시지 ID 중복 방지·회차별 저장·사진 준비 중 처리·0.9초 중요 답장 연출을 유지한다. 기존 장면의 중요한 약속 확정과 서윤 축하에만 입력 중 표시를 사용한다. 대기시간 벌점은 없다.

대화 진행 중 답장 선택이 없는 화면은 Enter/클릭 진행으로도 넘길 수 있다. 답장 3개가 표시될 때에는 자동으로 답을 고르지 않는다. 기록 열람은 본편을 진행하지 않는다.

## 제작 범위와 호환

새 사건·새 CG·캐릭터 이미지·리깅·음성을 추가하지 않는다. 장면에서 작성만 하고 보내지 않은 R03 초안이나 상대가 보여준 사진첩은 수신 기록에 넣지 않는다. 원래 도착 연락을 짧게 요약하던 서술 일부는 그대로 유지하며 실제 대사로 존재하던 문자 구간은 전부 이관한다.

기본 저장 변수로 새 필드와 연락처 기본값을 제공한다. 메시지 선택 전 저장/복원·중복 방지·본편 경로를 검증하되, 대본을 수정한 구간에 걸친 과거 버전의 모든 중간 저장 위치를 보증하지 않는다. 기존 저장은 삭제하지 않는다. GitHub 원격은 이 작업에서 자동으로 갱신하지 않는다.

실제 식탁 사진과 다른 히로인 루트 전체 메신저 대본은 후속 작업이다. 리아 표정 차분은 이번 변경과 별개로 최종 검수가 필요하다.
