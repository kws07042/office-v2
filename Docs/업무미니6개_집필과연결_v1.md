정답 맞히기 미니게임으로 만들지 않았다. 세 선택 모두 다음 장면으로 이어지며, 서로 다른 행동과 대사가 해당 회차의 기억에 남는다. 회의 결론을 길게 설명하는 대신 종이·컵·받침대·펜을 실제로 움직이고 서로 받아치는 장면으로 썼다.

## 읽는 순서
- C07의 기존 세 선택을 주된 업무 방식으로 이어받는다. 검증=verify, 조율=coordinate, 실행=try.
- C08에서 상대를 고른 뒤, 개인 첫 만남 전에 해당 방식의 첫 사건이 나온다.
- 네 연애 루트는 R08 뒤/R09 앞에서 두 번째 사건이 나온다.
- 동료 선택 또는 R04에서 연애를 시작하지 않은 경우도 기존 동료 결말 앞에 두 번째 사건을 연결한다.
- 한 회차에는 고른 방식의 두 사건만 나온다. 세 방식을 모두 읽으라고 강제하지 않는다.
- 본문 뒤 짧은 복도/엘리베이터 대화는 선택한 인물에게만 나온다. 첫 사건은 교제 전 말투, 두 번째는 실제 dating 상태에서만 사적 애정을 표현한다. 회의 중에 다른 사람에게 교제를 공개하지 않는다.

기존 초반·후반 대본, 갈등, 공개/비공개, 친밀한 장면의 진행·미룸 조건은 유지한다. R07/R12/R15 본장면의 생략·자리 표시는 이번 집필 대상에 포함하지 않았다.

## 실제 선택의 회수
| 방식 | 첫 사건에서 남긴 것 | 둘째 사건에서 돌아오는 것 |
| --- | --- | --- |
| 검증 | 조건을 나란히 적음 / 질문과 답 / 원본 뒤 시간표 | 같은 방법을 다시 꺼내되, 이번에는 ‘아직 모르는 것’을 표시하는 차이를 말함 |
| 조율 | 처음 읽는 사람 / 대신 옮겨 말하다 바로잡힘 / 각자 지킬 요소 | 이번 단어가 다르게 읽힌 이유를 앞 방식과 연결 |
| 실행 | 위치 / 첫 줄 문구 / 안내자 위치 중 한 요소 | 같은 요소에서 예상과 달라진 반응을 구체적으로 들음 |

앞 사건을 보지 않은 구버전 상태에서는 위 회상을 만들지 않고 독립적인 도입을 쓴다. 특히 ‘기억력이 나쁜 첫 방문객 역할’ 장난은 첫 시험을 실제로 봤을 때만 돌아온다.

## 상태와 호환
- 사건·선택·완료 여부는 기존 memory에 기록한다. affinity, trust_ria, dating, first_kiss, prepared와 기존 completed 보상 목록은 바꾸지 않는다.
- 첫 사건과 두 번째 사건의 완료 가드로 다시 호출해도 같은 대사/보상이 반복되지 않는다.
- 새 work_style 기본값은 None이다. 과거 상태에서 값이 없으면 기존 C07 방식이 유효할 때만 이어받는다. 공통 선택이 없는 단독 루트 미리보기에는 업무 사건을 임의로 배정하지 않는다.
- 이미 새 삽입 지점을 지난 세이브에 과거 사건을 소급 삽입하지 않는다. 새 사건 전체 확인은 새 회차를 기준으로 한다.
- 구버전 상태 모의 검사는 실제 과거 실행판에서 만든 모든 세이브 파일의 호환 보증이 아니다.

## 실행 소스와 배포물
실행 대본은 Source/game/work_minis.rpy이다. 연결 지점은 core.rpy와 각 루트의 진행 래퍼에 최소한으로 추가했다. 기존 C07 선택 문구와 점수는 유지하고 선택 전 안내를 덧붙였다.

새 Windows 패키지는 공식 SDK에서 소스를 새로 컴파일한 별도 검증 산출물로 만든다. 저장소 Windows 폴더의 기존 0.34.1 실행판과 새 소스/패키지를 혼동하지 않는다. 새 배포물에서는 기존 테스트 제외 규칙에 더해 개발용 renpy_agent.rpyc도 제외한다.
