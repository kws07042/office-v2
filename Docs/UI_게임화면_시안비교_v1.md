## 범위와 상태

오피스 라운드 방향 안에서 크림 라운드·네이비 글라스·살구 레터 세 안을 만들었다. 고유 팔레트를 비교하도록 게임 면의 색은 호스트 밝기 설정과 별개로 유지한다. 각 안에는 대사·선택지·호감도, 메신저·연락처·첨부 확대, 시작 메뉴, 저장 화면이 있다. 화면 네 종류×세 안으로 총 12개 예시를 보관했다. 외형·구성 비교용 초안이며 최종 사용자 승인·Windows 게임 적용·게임 저장 연결을 완료한 상태는 아니다.

리아를 포함한 인물 이미지·얼굴·몸·손·입상은 생성하거나 연결하지 않았다. 중앙의 창·책상·식물은 배경을 가정한 CSS 도형이며 정식 배경 자산이 아니다. 산책길 첨부도 사진 배치용 도형 예시로 실제 사진 파일·개인 메시지 자산을 생성한 것은 아니다. 실제 인물의 그림체·손·귀걸이·알파·잔상 검사는 이번 시안에 적용할 대상이 없다. 사건 95개·일반 CG 18개·리아 사용자 제작본 대기는 유지한다.

미리보기 대사·반응·시간·저장 슬롯은 화면 배치용 예시다. 새 본편 대사·새 사건·새 저장 규칙으로 자동 채택하지 않는다. 답장·호감도 표시를 눌러도 실제 게임의 관계·점수·세이브를 바꾸지 않는다.

## 안별 판단

| 안 | 대사·선택의 배치 | 메신저·메뉴 | 장점 | 실제 적용 전 확인할 점 |
|---|---|---|---|---|
| 크림 라운드 | 둥근 밝은 대사 카드·떠 있는 이름표·가로 선택 카드 | 넓은 연락처와 대화·왼쪽 시작 메뉴 | 오피스의 단정함과 부드러운 연애 인상을 함께 유지. 기본 추천 | 밝은 배경·옷과 대사창 경계가 흐려지는지 실제 자산으로 확인 |
| 네이비 글라스 | 하단 전체 폭 대사창·작은 이름·왼쪽 세로 선택 | 좁은 연락처·단정한 채팅·좌우 분리 메뉴 | 야간·고백·사적 대화의 분위기가 선명. 화면 중심을 넓게 비움 | 낮 장면에서 UI가 무거워 보이는지, 밝은 입상과 강한 대비가 생기는지 확인 |
| 살구 레터 | 편지 같은 대사 면·왼쪽 이름표·메모 형태 선택 | 폴더 같은 연락처·중앙 시작 메뉴·종이형 슬롯 | 초여름·장난·편한 연애의 인상이 가장 강함 | 장식과 그림체의 결이 맞는지, 편지 연출이 업무 장면까지 과해지는지 확인 |

이는 어시스턴트의 디자인 판단이며 판매·선호 조사 결과가 아니다. 배경과 캐릭터가 들어간 실제 화면을 검수한 뒤 최종 선택한다.

## 검수 기록

- 브라우저에서 세 안의 대사·메신저·메뉴·저장 전환을 확인했다.
- 메신저의 첨부 확대·대화 복귀, 두 번째 답장·반응, 연락처 변경과 짧은 입력 중 표시를 확인했다. 사진 확대 중 Escape는 대화로 복귀하도록 처리했다.
- 시작 메뉴에는 호감도·썸 표시가 나오지 않도록 수정했다.
- 1024px의 PC 비교 화면을 기록했다. 736px·320px에서 세 안×네 화면의 가로 넘침이 없는 것을 확인했다. 320px에서는 실제 버튼·대사·말풍선이 게임 면 밖으로 나가지 않는 것도 확인했다.
- 좁은 화면의 저장 제목이 한 글자만 다음 줄에 남지 않도록 단어 단위 줄바꿈을 적용했다.
- Pretendard·Gowun Dodum이 로드된 상태를 확인했다. 본문은 읽기 글꼴, 이름표·연락처·제목은 부드러운 글꼴을 사용한다.
- 실제 페이지 실행 오류 보고는 없었다. Windows Ren’Py 적용·키보드 전 조작·최종 자산·음성·모든 화면 배율 검수는 남아 있다.
