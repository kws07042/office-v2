# 시스템 후보 런타임 검사표

현재 상태: 아래 엔진 검사는 전부 미실행. 체크되어 있지 않다는 것이 실패 판정은 아니며, 실행 통과로 오해하지 않는다.

## 환경
- [ ] 공식 Ren’Py SDK 출처·버전·SHA-256 기록.
- [ ] 고정 SHA의 정상 체크아웃에 전용 브랜치 생성 및 원본 diff 확인.
- [ ] 임시 테스트 프로젝트/새 테스트 저장 경로 사용. 개인 저장·서명 키를 복사하지 않음.
- [ ] 신규 progression_model.py와 기존 RPY 정적 검토.
- [ ] 원래 게임의 이미지/폰트/JSON을 보존한 사본에서 lint/기동.
- [ ] 테스트 프로그램·개발 브리지·개인 저장이 배포에서 제외되는지 확인.

## 강리아 우선
- [ ] C01~C08의 모든 루트 선택과 미교제 경로.
- [ ] R04 수락/거절/보류, 기존 trust_ria 조건.
- [ ] R06 각 응답의 동일한 편안함 점수.
- [ ] R07 진행/미룸/대화 및 기본 이벤트 접근성.
- [ ] R09 선택과 R13 솔직/질문/덮어주기.
- [ ] R14 실제 수습 후 회복, 관계 종료/취소/보류.
- [ ] R15 생활복/특별 의상과 진행/미룸.
- [ ] R16/후일담 선택과 기존 본편/종료 결말 기록.

## 저장·재진입 — 실제 Ren’Py 필수
- [ ] 대사/선택 직전 기록을 만들고 자동 기록 켜짐/꺼짐을 각각 확인.
- [ ] 기존 수동 슬롯1~4가 자동 기록에 덮어써지지 않음.
- [ ] 퀵저장/퀵로드와 일반 저장/로드가 모든 회차 상태를 복원.
- [ ] 플로우에서 과거 선택을 불러오면 호감도·고유 보너스·memory·completed·dating·active_route·메신저·호출 스택을 복원.
- [ ] 미래 선택 플래그와 당시 없던 메시지가 남아 있지 않음.
- [ ] 다른 히로인에서 저장한 상태로 현재 루트를 오염시키지 않음.
- [ ] 롤백→다른 선택→롤포워드에서도 중복 보상 없음.
- [ ] persistent의 CG·결말 기록은 과거 회차를 불러와도 유지.
- [ ] 기존 버전 저장이 새 default를 받고, 실제 기록 없는 CG가 새로 열리지 않음.
- [ ] 재진입 저장이 없거나 빌드 표식이 다르면 비활성.
- [ ] 저장 실패 시 스토리가 계속되고 기존 정상 저장을 잘못 삭제하지 않음.
- [ ] 기존 서명 검사·알 수 없는 저장 경고가 정상 유지됨.

## CG·회상
- [ ] 파일 미제공/조건만 충족/스토리 미도달은 CG 미해금.
- [ ] 실제 등록 파일을 화면에서 확인한 뒤 진행해야 기록.
- [ ] 기본 이미지 대체 시 표정 이미지는 미해금.
- [ ] 잠금 이미지는 확대 액션을 우회해도 표시되지 않음.
- [ ] 갤러리 수집률은 실제 등록 수, 미제공 계획 수는 별도.
- [ ] 실제 감상한 회상만 실행. 회상에서 새로운 보상/결말/CG를 얻지 않음.
- [ ] 회상 종료 뒤 현재 대사·변수·화면·메뉴·음악을 복원.
- [ ] 스킵/이전 컷/저장 후 로드/재생 중 메뉴를 각각 확인.

## 네 루트 / UI
- [ ] 지현 업무 책임과 사적 성향이 분리됨.
- [ ] 유진 지원 침범→재합의→실제 수습을 정상 반영.
- [ ] 서윤 혼인 공개/계속/종료, 후일담의 기혼·배우자 동거가 보존됨.
- [ ] 회사 채널이나 새 진엔딩이 없는 상태를 완료처럼 표시하지 않음.
- [ ] 1280×720/1920×1080/창/전체화면에서 새 기록 화면과 스크롤 확인.
- [ ] 키보드·마우스·한국어 글꼴·장문·퀵메뉴·프로토타입 버튼 겹침 확인.
- [ ] 자동 진행·읽은 대사 스킵·백로그·타이핑/사진 확대를 회귀 확인.
- [ ] 실제 오디오가 등록된 빌드에서 각 볼륨 조절을 검증.
