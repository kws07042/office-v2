## 2. ria_R01 — 오늘은 동료 둘이

시점: 공통 루트에서 리아를 선택한 뒤. 장소: 회사 앞 → 선택에 맞는 가까운 장소. 연출 의도는 편한 일상 대화다. 기존 캐주얼 이미지 사용을 전제하지 않는다. 컵은 장면의 소품으로 대본에 남기되 새 사용자 제작본에 해당 포즈가 없으면 별도 소품·대사 연출로 처리할 수 있다. 아직 교제 상태가 아니다. 컵을 버리는 행동·갑자기 다른 소품을 드는 묘사를 추가하지 않는다.

아래는 반말 경로. 존댓말 경로에서는 두 사람 모두 뒤의 치환 표에 따른다.

리아: “도현아. 오늘 바로 집에 가?”

도현: “왜? 추가 현장 배정?”

리아: “퇴근했거든. 오늘은 내가 개인적으로 부르는 거야.”

도현: “그럼 내용부터 들어 보고.”

리아: “엄격하네. 잠깐 같이 들렀다 가자. 회사에서는 네가 어떤 사람인지 일 얘기밖에 못 들었어.”

도현: “리아도 현장에서랑 지금이 좀 다르네.”

리아: “어떻게?”

도현: “아까는 목적지를 정해 놨잖아. 지금은 나한테 물어보는 중이고.”

리아: “……그럼 물어볼게. 어떤 데가 좋아?”

### 선택 — 오늘의 장소

1. **“조용히 앉을 수 있는 곳.”**
   리아: “좋아. 사람 구경 코스는 다음에. 오늘은 내가 옆자리 앉아도 되는 곳으로.”
   기억 `afterwork_preference = quiet`.
2. **“일단 가볍게 밥 먹자.”**
   리아: “나도 찬성. 지금 멋있는 얘기 해도 머릿속엔 메뉴판만 떠올라.”
   기억 `afterwork_preference = meal`.
3. **“네가 가고 싶었던 데부터 들어 볼래.”**
   리아: “회사 뒤에 작은 가게 있어. 마음에 안 들면 바로 바꾸자. 내 취향 시험 아니니까.”
   기억 `afterwork_preference = suggestion`.

### 선택 직후의 짧은 장면 — 같은 R01 안의 가지

아래 세 가지 중 실제 선택한 것만 출력한다. 분기 전부터 리아가 든 컵은 계속 같은 소품이다. 식사·가게 장면에서는 내려놓고 마무리할 때 다시 들 수 있다. 기본 장소 배경과 텍스트 연출을 사용하며 새 전용 CG를 추가하지 않는다. 실제 이미지 파일은 새 사용자 제작본 확정 후 연결한다.

**quiet — 조용히 앉는 자리.** 리아가 창가의 두 자리를 보고 맞은편을 가리킨다.

리아: “여기면 조용하겠다. 난 저쪽 앉을게.”

도현: “옆자리도 있는데. 아까 네가 앉아도 되는 곳이라며.”

리아: “그 말 기억하고 있었어?”

도현: “내가 괜찮다고 말할 차례였잖아.”

리아는 컵을 내려놓고 옆 의자를 당긴다.

리아: “그럼 잠깐만. 나도 오늘은 질문 좀 덜 할게.”

도현: “질문해도 돼. 내가 너한테 물어볼 것도 있으니까.”

기억: `afterwork_preference = quiet`, 실제 자리는 창가 옆자리. R03에서는 조용한 자리 후보를 먼저 준비하고, R10의 지도에서는 그날 창가와 다음 조용한 장소를 구분해 회수한다.

**meal — 간단한 식사.** 두 사람이 가벼운 식사를 고른다. 리아가 메뉴를 보다가 도현 쪽을 본다.

리아: “혹시 나만 배고픈 건 아니지?”

도현: “둘 다 배고파. 네가 먼저 솔직했을 뿐이지.”

리아: “그럼 오늘은 맛있는 거 고른 사람이 이기는 걸로.”

도현: “이기면 다음에 또 같이 먹는 거?”

리아: “……네가 더 큰 걸 걸었네. 좋아.”

도현: “난 이거 먹고 싶은데, 너는?”

리아도 자기 메뉴를 고른다. 먹는 취향과 다음 만남의 작은 내기가 생긴 뒤 공통 대화로 합류한다.

기억: `afterwork_preference = meal`, 실제 고른 메뉴는 최종 집필 때 구체화. R03에서는 그날 음식 취향을 기억한 간단한 먹거리를 준비하고, R10의 지도에서는 다음 식사 후보를 함께 고른다. 승패 자체를 호감도 정답으로 만들지 않는다.

**suggestion — 리아의 제안 듣기.** 리아가 회사 뒤 작은 가게에서 자기가 좋아하는 창가 자리를 보여준다.

리아: “여기야. 퇴근하고 혼자 들를 때가 있어.”

도현: “오늘은 내가 끼어도 되는 자리야?”

리아: “내가 부른 사람이 그걸 왜 물어.”

도현: “그럼 다음에는 내가 자주 가는 데도 같이 가자.”

리아: “벌써 답례 장소 정하는 거야?”

도현: “네 취향 듣는 것도 좋지만, 내 것도 알려주고 싶어서.”

리아: “좋아. 오늘은 내 추천부터. 뭐가 궁금해?”

기억: `afterwork_preference = suggestion`, 리아가 실제 추천한 장소, 도현이 다음 장소를 제안한 약속. R03에서는 리아가 후보를 보여주고 다시 함께 고르며, R10에서는 어느 쪽이 준비할지 약속을 회수한다. 이 선택을 앞으로 모든 계획을 리아에게 맡기겠다는 의미로 기록하지 않는다.

### 공통 합류와 첫 만남의 회수

짧은 가지 후 편히 대화하는 공통 구간으로 합류한다. 식사 경로는 식사를 마친 뒤 같은 테이블에서, 나머지는 선택한 자리에서 진행한다. 장소·방식의 기억은 남는다. C06·C07에서 이미 나눈 사적 화제가 있으면 한 번만 짧게 회수한다. 없으면 C01의 `first_approach`에 따라 아래 중 하나를 사용한다.

- observe: 리아 “처음에 사람들 움직이는 걸 끝까지 보고 있더라. 원래 궁금한 건 직접 확인하는 편이야?”
- listen: 리아 “처음에 직원분한테 먼저 물어봤잖아. 나도 그게 빠르다고 생각했어. 오늘은 나한테도 물어봐.”
- coordinate: 리아 “첫날부터 나한테 역할 나눠 줬잖아. 오늘도 잘하는 걸 나눌까? 메뉴는 내가 고를까, 네가 고를까?”

도현: “오늘도 면접 보는 기분인데.”

리아: “아, 내가 또 질문부터 했네. 미안. 정답 없는 걸로 바꿀게.”

도현: “그럼 틀리면?”

리아: “내가 모른 척해 줄게.”

도현: “리아도 계속 재미있게 해 주려고 안 해도 돼.”

리아가 바로 말을 잇지 않는다. 컵을 내려다봤다가 도현을 본다.

리아: “……그렇게 보였어?”

도현: “그냥. 잠깐 말 없어도 괜찮을 것 같아서.”

리아: “좋네. 그럼 잠깐만 쉬자.”

짧은 간격. 리아가 먼저 작게 웃는다.

리아: “다음에는 오늘 못 간 데 가 볼래?”

도현: “좋아. 날짜는 같이 정하자.”

리아: “응. 내가 혼자 일정표 만들어 오진 않을게.”

## 3. 리아 호감도 기준 경로

v2.56의 후속 집필 기준: R05·R06은 짧은 데이트·장난으로 연인이 된 변화를 보여준다. 기록 시간 조정·작은 부탁·쉬고 싶은 마음과 실제 연락·비공개 합의를 대화 안에 넣고 고백 내용을 반복하지 않는다. 첫 입맞춤의 발생·미룸과 실제 도움 기록은 유지한다. 이 부분은 아직 작성하지 않은 후속 사건의 기준이며 현재 C01·R01 시험 대본을 전체 루트로 간주하지 않는다.

선택적 일상과 공통 개인 만남의 보너스가 없는 참고 점수 경로다. 통합 기획서 v2.41에 따라 교제는 핵심 이해 사건과 상호 의사 확인으로 결정하고 호감도 30을 필수 문턱으로 쓰지 않는다. 아래 30·35 등의 숫자는 이 참고 경로의 누적 계산이며 교제 허용 조건이나 모든 경로의 동일한 도달값이 아니다. 실제 밸런스는 아직 시험 전이다.

| 사건 | 변화 | 누적 호감도 | 조건과 의미 |
|---|---:|---:|---|
| C01 소개 완료 | +10 | 10 | 기본 소개와 실제 관찰 |
| R01 | +4 | 14 | 존중하며 첫 약속을 정함 |
| R02 | +7 | 21 | 데이트 계획을 함께 조정 |
| R03 | +9 | 30 | 서로의 작은 취향을 기억, 핵심 이해 사건 완료 |
| R04 | +5 | 35 | 상호 교제 의사 확인. 수치만으로 자동 교제하지 않음 |
| R05 | +4 | 39 | 생활·시간을 함께 계획 |
| R06 | +6 | 45 | 편한 표현과 속도를 대화 |
| R07 | 0 | 45 | 친밀한 전환을 진행하거나 미뤄도 점수 차이 없음 |
| R08 | +4 | 49 | 새로운 평소 대화 |
| R09 | +6 | 55 | 업무의 구체적인 매력을 인정. 전환 분기에는 추가 점수 없음 |
| R10 | +4 | 59 | 취향과 개인 목표 공유 |
| R11 | 0 | 59 | 전환의 진행 여부는 별도 기억 |
| R12 | +4 | 63 | 재회와 다음 약속. 전환 분기와 독립 |
| R13 | 0 | 63 | 갈등 상태·신뢰를 사건에 맞춰 기록 |
| R14 | +8 | 71 | 실제 행동으로 약속을 조정 |
| R15 | +5 | 76 | 미래 계획의 대화. 전환 분기에는 추가 점수 없음 |
| R16 | +4 | 80 | 관계와 개인 목표의 결말 |
| E01 | +8 | 88 | 후일담의 일상 대화. 전환 분기와 독립 |

공통 개인 만남 C06·C07은 각 +1~3, 기본 선택적 일상 O01~O03도 각각 +1~3의 보조 증가로 시험한다. 같은 사건 반복으로 추가 점수를 얻지 않으며 100을 넘으면 제한한다. 기준 경로의 좋은 결말은 100이 없어도 가능하다.

R04는 도현이 먼저 고백하며 준비 대화를 고르면 같은 장면 안에서 이야기한 뒤 다시 선택한다. 상호 교제를 확인한 경로에만 참고 보상 +5를 한 번 적용한다. 위 경로에서는 30→35지만 다른 진입값을 30·35로 강제 맞추지 않는다. 준비 대화에는 별도 보상·벌점이 없고 교제 확인 전에는 R05로 진행하지 않는다. 동료 관계는 기존 END_COMMON으로 이어져 위 연인 경로 누적표를 계속 적용하지 않는다. R04의 연결 집필본은 별도 문서에 작성했으며 실제 게임 연결·실행 검증은 미완료다.

신뢰 시험안: 최초 0 → R01의 약속 +1 → R03의 신뢰 +1 → R06의 상호 대화 +1. R13의 -1·R14의 +1은 실제 약속 훼손·수습 행동이 있는 경로의 시험 가설이며 사건에 진입할 때마다 고정 적용하지 않는다. 모든 변화는 사건과 대사로 설명하고 범위는 0~3으로 제한한다. 신뢰는 남은 실수 횟수가 아니고 0에서 자동 게임오버하지 않는다. 다른 의견이나 친밀한 장면을 미루는 선택에는 자동 감소를 붙이지 않는다. 리아의 일정 변경에 도현이 정당한 서운함을 말하는 것을 오답으로 처리하지 않으며 실제 책임과 합의 상태를 구분한다. 2026년 10월 14일 보강 근거: [생명력·선택 결과 검토](<선택실수_생명력시스템_필요성검토_v1.md>). 후반 신뢰 변화의 실제 구현은 미완료다.

### 확인할 경로

핵심 사건을 경험하고 교제에 서로 동의한 경로가 호감도 30 미만에서도 진행되는지 확인한다. 높은 수치만으로 자동 교제하지 않는지, 공통 개인 만남·선택적 일상 없이도 가능한지, 친밀한 전환을 모두 미뤄도 좋은 결말이 가능한지, 저장·되돌리기·회상에서 결과가 중복되지 않는지도 확인한다. 표의 참고 누적 계산과 실제 진입 조건은 분리한다. 현재는 명세이며 실제 실행 검증은 아니다.
