# 〈퇴근 후, 우리〉 스토리 바이블 v003

v002(갈등 즉시 해소·상담식 대화) → v003(상업용 긴장 구조). 대본의 장면·선택지·기억 키·호감도 구조는 유지하고, 그 안의 사건과 대사를 바꾼다.

## 1. 공통 압박 — "가을 피칭"
- 도현이 합류한 캠페인 TF는 **가을 브랜드 피칭 한 건으로 존속이 결정**된다. 지면 TF 해체, 인원은 흩어진다.
- 첫날 지현이 이 사실을 짧게 못 박는다. 이후 업무 장면은 전부 이 피칭을 향한다.
- 사내연애 규정은 없지만, 피칭 직전 TF 안 연애가 알려지면 "공정성" 얘기가 나온다 → **숨겨야 할 이유**.
- 피칭 상대(클라이언트) 담당자: **정민재**. 서윤의 전남편.

## 3. 장면 규칙
1. **갈등은 바로 풀지 않는다.** 사과는 하되 서운함은 남기고, 다음 장면(메신저·출근)에서 온도 차로 이어 간다.
2. **들킬 뻔한 순간**: 엘리베이터·회의실·회식에서 최소 루트당 1회.
3. **질투**: 다른 히로인이 둘 사이를 눈치채고 떠보는 대사를 업무 장면에 심는다.
4. **스킨십은 한 번 미룬다.** 첫 키스는 방해받거나 한쪽이 피했다가 다음에 성사. 동의는 "해도 돼?" 질문 대신 시선·거리·손 같은 행동과 반응으로 보여 준다(대답 선택지는 유지).
5. **상담체 금지**: "범위를 나누자", "먼저 물어볼게", "같이 정하자", "역할 확인" 류 대사는 사건이나 감정으로 바꾼다.
6. **생활 디테일 유지**: 냅킨 간판, 두부 반쪽, 컵받침 데이지 같은 작은 장면은 살린다.
7. 성인 장면 본문은 별도(외부 작성). 대본에는 "(장면 생략 · 시간이 흐릅니다.)"만 둔다.

## 4. 서윤 설정 변경
- 자녀 설정 삭제. "이혼했어. 3년 됐고, 혼자 살아."
- R13 갈등: 아이 소개 문제 → **전남편이 피칭 상대로 나타나 서윤이 도현을 밀어냄**.
- 후일담: 소개 고민 → 주변(팀·친구)에게 공개할지, 같이 살지.
- 개인 작업실 설정 유지(혼자 사는 집과 별도).

## 5. 엔딩 축
- 피칭 결과(팀 존속)는 공통 결말에서 확정: **TF 존속**. 루트별로 그 과정에서 히로인의 비밀이 어떻게 정리됐는지가 엔딩 차이.
  - 리아: 이직 제안을 거절하고 남는다 / 관계 종료 시 떠난다.
  - 지현: 해체 예고를 팀에 공개하고 같이 막았다.
  - 유진: '창가'와 회사 작업을 둘 다 자기 이름으로 정리.
  - 서윤: 전남편과의 일을 공적으로 선 긋고, 도현을 고른다.
