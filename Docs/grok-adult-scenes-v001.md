# Grok 작업 파일 · 성인 장면 본문 v001

> 이 파일을 통째로 Grok에 붙여 넣고 "아래 규칙대로 전부 채워 줘"라고 하면 된다.
> 너무 길면 `# 리아`, `# 지현`, `# 유진`, `# 서윤` 단위로 나눠 넣고, **맨 위 규칙(여기부터 '작성 규칙' 끝까지)은 매번 같이** 넣는다.
> 이 파일 자체에는 노골적인 내용이 없다. 맥락·말투·앞뒤 대사·반환 형식만 담았다.

## 너(Grok)에게 맡기는 일

한국어 성인 연애 비주얼노벨 〈퇴근 후, 우리〉. 각 장면은 이미 **앞 대사 → 도입 3컷**까지 있고, **본장면 3컷(CG1·CG2·CG3)**이 비어 있다. 비어 있는 본장면 대사를 모두 써 준다. 각 장면의 **뒤 대사**는 이미 있으니 본장면 끝이 그 대사로 자연스럽게 이어지게 쓴다.

채울 곳: **25장면 × CG 3컷 = 75컷**
- 히로인 4명 × (R07 첫 밤, R12 데이트 후, R15 생활복, R15 코스프레 3종) = 24
- 리아 일상 장면 '역 앞 모텔' 1

## 작성 규칙

**인물·동의**
- 모두 성인: 주인공 28, 리아 28, 유진 27, 지현 30, 서윤 32. 서윤은 이혼(자녀 없음). 아이·가족 얘기는 하지 않는다.
- 동의는 앞 대사에서 이미 말로 주고받았다. 본장면에서도 시선·손·짧은 물음으로 계속 확인되는 흐름. 한쪽이 멈추면 멈춘다. 다만 상담처럼 "괜찮아?"만 반복하지 않는다.
- 술은 마셔도 취하지 않은 상태(모텔 장면은 소주 한 잔씩).

**이름·호칭**
- 주인공 이름은 플레이어가 정한다. 대본에는 무조건 **`도현`**으로 쓴다. 게임이 화면에 띄울 때 바꿔 준다.
- 조사는 이것만 쓴다: `도현이` `도현은` `도현을` `도현과` `도현아` `도현으로` `도현이었`, 그리고 `도현 씨`. (`도현이가` `도현이는`처럼 '이'를 덧붙이지 않는다.)
- 히로인 → 주인공
  - 리아: 반말이면 "너/도현아", 존댓말이면 "도현 씨".
  - 지현: 둘이 있을 땐 "도현아".
  - 유진: "도현 씨".
  - 서윤: 둘이 있을 땐 "도현아".
- 주인공 → 히로인
  - 리아: 반말이면 "리아야/너", 존댓말이면 "리아 씨".
  - 지현: 플레이어가 고른 호칭이라 이름을 직접 부르지 말 것. 존댓말.
  - 유진: "유진 씨", 존댓말.
  - 서윤: 플레이어가 고른 호칭이라 이름을 직접 부르지 말 것. 존댓말.
- 회사 이름은 GY브랜딩(필요할 때만).

**말투**
| 히로인 | 평소 | 이런 순간 |
|---|---|---|
| 리아 (28, 마케팅) | 밝고 빠른 말끝, 장난, 물결(~)·느낌표 | 장난으로 긴장을 풀다가 결정적인 순간엔 농담이 뚝 끊긴다. 솔직해지면 문장이 짧아진다. |
| 지현 (30, 팀장) | 짧고 결론부터, 반말 | 원하는 걸 짧고 직접 말한다. 칭찬·다정한 말에는 약해서 말을 잃는다("...그런 건 기억 잘하네"). |
| 유진 (27, 디자이너, 안경) | 존댓말, 말끝을 흐림, 비밀 그림 계정 '창가' | 머뭇대다 갑자기 직구. 빛·색·창가 같은 시각적인 표현. |
| 서윤 (32, 외주 실장, 개인 작업실) | 여유로운 반말, 떠보는 장난 | 진심일 땐 장난을 완전히 멈춘다. 과거(전남편)를 덮어쓰고 싶은 마음, R15에선 가장 편안함. |
| 도현 | 다정하고 차분, 서두르지 않음 | 상대 말을 받아 주고, 묻고, 웃긴다. 혼자 흥분해 떠들지 않는다. |

**리아 반말/존댓말 두 벌 (필수)**
- 리아 장면은 플레이어 설정에 따라 반말판과 존댓말판이 따로 나온다.
- 그래서 리아 장면의 **리아 대사와 도현 대사는 반드시 `["반말", "존댓말"]` 두 벌**로 쓴다. 뜻·감정은 같고 어미만 다르게.
- 다른 히로인 장면은 한 벌만 쓰면 된다.

**분량·구성**
- 컷당 8~14줄, 장면당 25~40줄.
- CG1 = 시작(옷이 흐트러지고 첫 접촉), CG2 = 절정, CG3 = 여운(끝난 직후 같은 자리).
- 줄 종류는 셋: 지문(narration), 히로인 대사, 도현 대사. 지문은 1~2문장, 현재형.
- 의상·속옷은 각 장면의 '의상·속옷' 항목을 따른다. 코스프레 장면은 그 의상만의 특징(바니 귀, 간호사 캡, 치파오 트임, 메이드 머리띠, 경찰 모자 등)을 대사나 지문에 한두 번 살린다.
- CG3 마지막 2~3줄은 **뒤 대사 첫 줄**의 감정과 소재로 넘어가게 한다. 뒤 대사를 그대로 반복하지는 않는다.
- 같은 히로인의 R07 → R12 → R15는 관계가 깊어지는 순서다. 말투와 거리감에 그 차이가 보이게 쓴다(R07 서툼, R12 그리움, R15 편안함).

## 반환 형식 (꼭 이대로)

장면마다 JSON 한 덩어리를 코드블록으로 준다. `id`는 각 장면 제목의 백틱 안 값을 그대로 쓴다.

```json
{"id": "ria_r07:casual",
 "main": [
  {"cg": 1, "lines": [
    ["narration", "지문"],
    ["heroine", ["반말 대사", "존댓말 대사"]],
    ["dohyun", ["반말 대사", "존댓말 대사"]]
  ]},
  {"cg": 2, "lines": [ ... ]},
  {"cg": 3, "lines": [ ... ]}
 ]}
```

- 리아가 아닌 장면은 `["heroine", "대사"]`, `["dohyun", "대사"]`처럼 문자열 하나.
- 리아 장면의 지문은 문자열 하나(지문은 반말/존댓말 구분 없음).
- 설명이나 머리말 없이 JSON 블록만 연달아 준다.
- 받은 JSON은 `Source/game/event_story.json`에 넣고 게임에서 확인한다.
