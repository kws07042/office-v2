# 플레이 흐름과 재미 보강

기준: main `44ba86ad5aa7cef83d68abd0be261964df74a937` (PR #3 병합). Source `0.35.2-player-flow`.

## 고친 장면

- **유진 R14**: 발표 직전에는 퇴근 후 관계 대화를 예약한다. 실제 관계 종료/애정 표현/남은 고민 선택은 검토를 마친 뒤 벤치에서 한다. 관계 종료는 여전히 가능하며, 선택하기 전 이별 통보를 강제로 발화하지 않는다. 앞서 설명을 대신한 경로와 유진을 존중한 경로의 고민 대사를 나눴다. 계속 만나겠다는 애정 표현을 이별 철회로 처리하지 않는다.
- **서윤 R15**: 혼인·배우자 동거 공개 뒤 첫 저녁에 외투를 못 벗는 도현, 멎는 대화와 어색하게 나온 음식 농담을 넣었다. 도현이 작은 웃음을 보이는 것이 곧 신뢰 회복을 뜻하지 않는다. 작업실에서도 두 사람이 가까워지는 행동을 천천히 이어 간다. 혼인·동거·숨김의 책임과 종료 선택, 이혼 약속을 하지 않는 기존 설정은 유지했다.
- **지현 R10**: 작은 문손잡이를 떨어뜨리고 함께 조립하는 행동을 넣었다. 지붕은 아직 붙이지 않는다. 기록집 감상은 짧게 압축하고 기존 세 소재·감상 기억과 후일담을 유지했다.
- **지현 R13~14**: 역할·비용 설명을 줄이고, 말할 차례를 빼앗긴 서운함과 지현이 펜을 내려놓고 기다리는 행동에 초점을 뒀다. 한 장소만 시험 승인받는 업무 결과는 같다.
- **유진 O02**: 감상문 세 답 대신 빛 가리기/물을 마신 뒤 컵 그리기/사진과 빠른 스케치 비교를 선택한다. 그림자에 가려진 노트, 오리 같은 컵, 잘생긴 손잡이 장난이 각각의 행동에서 나온다. 선택 기억·보상, 기존 집에서 그린 컵 소재와 후일담 회수는 유지했다.
- **리아 R14**: 약속을 지킨 다음 만남의 끝을 노트 제목 논쟁에서 첫 데이트의 거품 장난을 서로 되돌려 주는 장면으로 교체했다. 반말/존댓말, 시간 약속과 종료·계속 분기는 유지했다.

## 보존과 달라지는 동작

95개 사건 슬롯, 기존 jump label, 친밀한 본장면의 생략 위치, 이벤트 JSON·이미지 계획, 네 루트의 교제 종료 가능성을 유지한다. 유진 R14는 관계 결정을 내리는 시점을 업무 뒤로 옮기는 의도적인 제어 흐름 변경이다. 새 readiness 값은 `relationship_talk`, `reassured`이고, 앞으로 새 선택에서 `reconsidered`를 만들지 않는다. 기존 R15의 `reconsidered` 읽기는 남겨 이전 상태의 후속 처리를 보존한다. 유진 관계 종료는 R14 보상을 주지 않으며 계속하는 경로는 기존 보상을 한 번만 준다.

Windows 폴더는 바꾸지 않는다. 이전 퇴고의 검증 문서는 당시 버전 기록으로 남긴다. 이번 구조 검사는 `Source/tests/player_flow_contract.py`, 실행 검사는 `.github/workflows/player-flow.yml`이 담당한다.

## 검증 상태와 한계

- 로컬 정적 비교: 기준 Git blob SHA-1과 캐시 33파일 일치, 런타임 30파일 비교, 변경 7파일, 사건 95개 확인.
- 새 자동 사례 14개: 관계 결정 순서·과거 행동 두 경로·종료/계속, 결정 전후 저장/불러오기, 서윤 의상/친밀도 속도와 기혼 상태, 스케치 세 행동/건너뛰기.
- 최종 소스 `315dc14b6a363ab5ebacb8dbba3520cb3b4a9c0b`에서 구조·Ren’Py lint와 Linux 실행 147사례·2,072항목을 통과했다. [최종 검증 기록](validation/player-flow-2026-11-02.md)에 9개 검사 묶음과 한계를 적었다. [대사 미리보기](재미보강_장면미리보기.md)에서 발췌 장면을 읽을 수 있다.
- 자동 진행 대사를 재독해 지현의 반복 문구와 유진의 새 종이를 꺼내는 연결도 마지막으로 정리했다.
- 실제 Windows EXE 실행, 수정된 문장 한가운데의 구버전 세이브 이전, 사람 대상 재미·플레이 시간 측정은 하지 않았다. 자동 회귀 검사는 재미를 증명하지 않는다.
