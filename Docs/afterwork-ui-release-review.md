# 상업용 UI 검수 기록

## 범위

기준 GitHub 커밋은 `7fc1d8301e2470cb97f2ef412e6403e821b159fa`다. 소스·GUI 에셋은 Git blob 해시를 대조해 별도 사본을 만들었다. 보관 중인 0.35.7 테스트 사본은 입상이 있는 화면의 배치를 확인하는 데 사용했다. 이 사본의 대본과 입상은 PR에 포함하지 않는다. 두 테스트판은 독립된 저장 경로를 사용했다.

## 화면별 점검과 수정

| 화면 | 검수 및 반영 |
|---|---|
| 메인 | 사원증 윤곽을 워드마크에 한 번만 썼다. 시작, 이어하기, 불러오기, 갤러리, 환경설정, 종료를 하단에 분리했다. 저장이 없으면 이어하기를 비활성화한다. 키 비주얼 왼쪽의 명암은 로고 가독성에만 사용한다. |
| 대화·이름 | 배경은 유지하고 하단만 어둡게 했다. 대사, 화자, 빠른 조작의 글자 크기와 위치를 구분했다. 이름색은 대사와 밝은 기록 화면에서 각기 다른 밝기를 쓴다. |
| 선택지 | 중앙의 가로 정렬과 왼쪽 글줄을 유지했다. 항목이 많거나 길면 스크롤 영역을 사용한다. 실제 3지선다를 선택해 결과 변수를 확인했다. |
| 메신저 | 화면 가운데 기기, 상태 표시줄, 빈 원형 프로필, 발신·수신 말풍선, 답장 목록을 확인했다. 연락처를 전환했다가 진행 중인 대화로 돌아와 답장했다. |
| 설정 | 인물 없이 평면 배경과 탐색으로 구성했다. 메신저 입력 표시와 글자 속도, 스킵 옵션을 전환했다. 오디오 옵션은 실제 게임 설정이 오디오를 제공할 때만 보인다. |
| 저장·확인·대화 기록 | 네 슬롯의 기존 저장 이름과 Ren’Py 저장 서명 동작을 유지한다. 저장 → 슬롯 불러오기 확인 → 대화 복원 → 메인 이어하기를 검사했다. 대화 기록의 인물 이름과 본문을 두 열로 나눴다. |
| 관계·갤러리·회상 | 인물 배경을 걷고 탭과 등장인물 필터를 유지했다. 등록 CG가 없는 분류의 반복 카드 대신 한 번만 안내한다. 실제 등록 CG는 해금 상태에 따라 목록과 감상 화면에 연결된다. 기존 회상 호출과 해금 조건을 유지한다. |
| UI 숨기기 | Ren’Py의 HideInterface 동작으로 대화·조작·상태표시를 숨긴다. 입상과 배경은 남는다. 최초 검수에서 UI를 숨기면 입상의 잘린 하단이 떠 보였고, 화면 하단에 맞춰 보정했다. |

## 확인한 수치와 실행

- Windows, Ren’Py 8.5.3.26051504. 검증에 사용한 공식 Windows SDK ZIP의 SHA-256은 `ff57648f9c04f27e381c48af6d8e3ee3cdec296bed4d3831f47f09b0a71b505e`다.
- `lint --error-code`와 `test badge_ui_smoke`가 두 사본 모두 통과했다. 최종 UI 테스트는 각 사본에서 1개 케이스와 24개 확인 항목을 통과했다. 회귀 테스트를 재실행할 때는 게임 프로젝트와 저장 경로가 모두 비어 있는 검증용 사본을 사용한다.
- 960×540 창 크기를 확인하고 방향키와 Enter로 타이틀에서 갤러리에 진입했다. 전용 레이아웃 검사 4개 확인 항목을 통과했다.
- 기존 `test_progression_model.py` 39건이 통과했다.
- 정적 명암비는 종이색 위 본문 13.15:1, 종이색 위 코발트 7.21:1, 코발트 위 흰 글자 7.86:1, 종이색 위 보조 글자 5.95:1이다. 이미지가 깔린 화면은 렌더된 프레임에서 확인했다.

## 제작 에셋과 출시 전 확인 범위

- `gui/badge/office-id.svg`는 새로 그린 96×91 투명 아이콘이다. `gui/badge/title-wash.png`와 `gui/window/dialogue_scrim.png`는 늘려 표시하는 투명 명암 램프다.
- `gui/badge/title.png`는 이미 저장소에 있는 v002 키 비주얼의 동일 Git blob이다. 그림 자체와 외형 기준 문서는 그대로이며 향후 교체할 임시 런타임 에셋이다.
- 현재 GitHub 기준판에는 출시용 개별 입상과 등록 CG가 없다. CG 실제 해금 후 재생, 전체 루트, 전체화면 및 Steam 배포판은 이번 검수 범위 밖이다. 현재 등록된 오디오가 없어 실음량 변화도 검사하지 않았다.
- 한국어 UI를 대상으로 구현했다. 해외 출시 전 번역, 문자열 확장 검수, 최종 아트와 제3자 자산 권리 확인, 플랫폼별 패키지 검증이 남아 있다.
