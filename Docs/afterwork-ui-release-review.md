# 저녁의 문턱 UI 검수

- Windows Ren’Py 8.5.3.26051504에서 `lint --error-code` 통과. PR 기준 소스와 입상이 있는 로컬 사본 모두 UI 실행 검증의 확인 항목 25개를 통과했다.
- 타이틀 메뉴, 설정 전환, 관계·이야기·갤러리·결말 탭, 메신저 연락처·사진 화면·답장, UI 숨김, 수동 저장·불러오기 확인·이어하기, 선택지 분기를 확인했다. 테스트 저장은 별도 경로에 만들었다.
- 16:9 실행 캡처에서 타이틀 원화와 메뉴의 경계, 화자 열과 대사 폭, 선택지의 정렬, 메신저의 입력·답장 영역, 저장 슬롯의 읽는 순서를 확인했다. 첫 렌더에서 아래 조작 영역의 좁은 틈을 제거하고, 화자에 독립된 열을 주고, 시스템 탐색의 명암을 높인 뒤 재실행했다.
- 강리아가 보이는 플레이 캡처는 로컬 입상 사본의 배치 확인용이다. 게임 대본, 장면 배경과 원화 파일은 교체하지 않았다.
- 등록 CG 실감상 및 회상 재생, 전체 루트, 번역 및 Steam 패키지 검증은 이번 실행 범위 밖이다.
