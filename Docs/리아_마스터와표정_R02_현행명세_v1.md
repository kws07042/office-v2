# 리아 마스터·표정 레이어·R02 연출 현행 명세

2026년 10월 15일 / 기획 v2.80 / Windows 0.10.0-ria-expressions.

## 현재 구현

사용자가 확정한 exec-fc9b9512-62fa-4e1a-b8fb-c783323e1514.png를 원본 그대로 game/images/characters/ria/ui_master_v2.png에 연결했다. 기존 귀걸이가 있는 임시 리아 입상은 새 Windows 묶음에서 제외한다. 유진의 제공 참조는 캐릭터 자료에만 보관하고 게임 입상으로 연결하지 않았다.

기본 원본 + 밝은 웃음(smile) + 부끄러움(shy) + 진지한 관심(serious)을 사용한다. 생성형 도구로 320×320 얼굴 주변 크롭에서 각각 독립 표정을 만들었다. 출력은 각1254×1254 PNG RGBA이며 게임에서320×320으로 맞춘다. 전신에 다시 AI 편집을 적용하지 않는다.

게임 엔진은 원본 몸통 위에 눈·눈썹·입의 작은 마스크 영역만 표시한다. shy에만 볼 홍조를 추가한다. 원본 이마·턱·목·어깨의 피부를 넓게 덮지 않는다. 표정 주변의 일부 피부·선은 생성된 영역이므로 원본과 완전 동일하다고 주장하지 않는다. 머리 바깥 실루엣·몸·의상·손·벨트·단추3개는 원본을 공유한다.

화면은 원본(190,40,630,850)을 잘라0.95배로 중앙에 표시한다. 상체를 키우고 손은 화면 아래로 벗어나므로, 손을 수정했다고 기록하지 않는다. 기존 투명 대사·이름·구분선·오른쪽 세 선택지·호감도 UI는 유지한다.

20개 표정 지시를 삽입했다. 대사·분기·상호 합의·기억·호감도는 바꾸지 않았다. 반말·존댓말 모두 같은 감정 흐름이다.

## 행동 연출의 다음 범위

이 구현은 최종 행동 연출이 아니다. 대사에 맞춘 표정은 구현했지만 기존 정면 입상을 흔들어 걷기·손잡기·옆보기·앉기를 구현했다고 표시하지 않는다.

| 실제 대본 행동 | 후속에 필요한 자산·처리 |
|---|---|
| 안내문을 다시 읽기 | 시선 이동·옆보기 포즈 후보 |
| 휴대폰 목록을 어깨너머로 보고 가리키기 | 소품·팔 동작이 있는 별도 자세 후보 |
| 손을 내밀고 함께 걷기 | 손 내밀기·측면/POV CG 등 별도 자산, 도현 신체 제외 기준 유지 |
| 카페 또는 벤치에 앉기 | 상황 배경·앉은 자세/POV CG 후보 |

후속 자산은 현재 제작량95사건·일반CG18 안에서 우선 배분한다. 이 문서가 추가 수십 장 생성이나 전체 애니메이션 승인을 뜻하지 않는다. 이번에는 인위적인 입상 흔들기·상하 점프를 넣지 않았다.

## 피부색·검수 기준

전체 얼굴 덮기보다 표정 부위만 교체해 이마·턱·목·어깨를 보존한다. 부끄러움의 국소적인 볼 홍조는 의도된 변화다. 낮·밤1280×720 실제 화면과 얼굴 확대를 비교하고, 목·어깨의 색 변화·마스크 경계·이중 눈·흔들리는 입 위치를 확인한다. 정량 결과와 한계는 별도 검증 문서를 따른다.

구형 저장 호환 확인은 격리된 시험 저장만 사용한다. 사용자 실제 저장 파일을 수정하거나 모든 구형 저장의 호환을 보장하지 않는다. 외부 배포는 하지 않는다.
