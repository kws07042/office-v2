## 실제 확인 범위

- 리아 R02의 계획3×애정 표현3×반말/존댓말2 =18경로에서 표정·분기·기억·호감도 확인. 대사와 선택·점수 코드는 표정 대입문을 제거하면 이전 소스와 동일함을 비교했다.
- 기본·웃음·부끄러움·진지함을 낮·밤 실제1280×720 화면으로 확인. 저장 후 부끄러움 표정 복원, 메뉴 진입, 다른 화자에게 리아 입상을 표시하지 않는 규칙도 검사했다.
- 실제 렌더링에서 이마·코 아래·턱·목·왼어깨·오른팔의 지정 표본과 몸통 비교 영역이 각 표정 전후 동일함을 확인했다. 일반 볼 표본은smile·serious에서 동일하고shy의 홍조 변화만 허용했다. 이는 얼굴 전체 모든 픽셀의 피부색이 동일하다는 판정이 아니다. 눈·입·볼 주변 일부는 생성된 표정 영역이다.
- 생성 원본의 피부 샘플에는 미세 차이가 있어 얼굴 전체 마스크를 폐기하고 부위별 마스크를 사용했다. 보간·색 보정으로 얼굴 전체를 강제 일치시켰다고 설명하지 않는다.
- 원본 마스터의 SHA256은 선택 파일과 동일하다. 새 패키지의 변경 불가 게임 파일35개가 소스와 일치하며 ZIP CRC도 통과했다. 엔진 캐시는 실행으로 변할 수 있어 별도 기록한다.
- 이전0.9.1에서 만든 격리된 시험 저장2개(선택지·이벤트 도입)를 불러와 진행했다. 실제 사용자 저장에 접근하지 않았으며 모든 구형 저장의 호환을 보장하지 않는다.
- 손 내밀기·옆보기·걷기·앉기·입 모양 연속 애니메이션은 미구현. 최종 배경·CG·음성·메신저 UI·다른 개인 루트는 미완료다. 현재는 표정과 한 장면 연결 검증이다.
- 외부 공개·Steam 업로드·배포 없음.
