# 친밀 장면 작성 브리프 v001 (외부 작성자용)

대본에는 친밀 장면 본문이 없다. 플레이어가 동의 선택지를 고르면 `call event_sequence("<ID>", <의상>)`이 `Source/game/event_story.json`의 해당 장면을 재생하고, 본문이 없으면 "(장면 생략 · 시간이 흐릅니다.)"가 나온다. 이 문서는 그 본문을 쓸 사람에게 넘기는 **맥락·감정·연결 조건**만 담는다. 노골적인 묘사는 포함하지 않는다.

## 공통 원칙
- 등장인물은 모두 성인이다: 도현 28, 리아 28, 유진 27, 지현 30, 서윤 32.
- 동의는 직전 대본에서 이미 말로 주고받았다. 본문에서도 시선·손·거리로 계속 확인되는 흐름을 유지한다. 한쪽이 멈추면 멈춘다.
- 장면이 끝나면 반드시 아래 **직후 대사**로 이어진다. 그 대사와 감정 온도가 맞아야 한다.
- 히로인 말투는 본편과 같게 유지한다(아래 표). 상담처럼 확인만 반복하는 말투는 피한다.
- 서윤은 이혼(자녀 없음)이다. 아이·가족을 언급하지 않는다. 장소는 서윤의 **개인 작업실**이다.
- 길이 기준: 본문 20~40줄. 끝은 조용한 여운으로 닫는다.

| 히로인 | 이런 순간의 말투 |
|---|---|
| 리아 | 장난으로 긴장을 푸는데, 정작 결정적인 순간엔 농담이 끊긴다. 반말/존댓말은 `ri()` 설정을 따른다. |
| 지현 | 원하는 걸 짧고 직접 말한다. 대신 칭찬이나 다정한 말에는 약해서 말을 잃는다. |
| 유진 | 말끝을 흐리다가 갑자기 직구를 던진다. 빛·색 같은 시각적인 걸 말한다. |
| 서윤 | 여유롭게 떠보다가, 진심일 땐 장난을 완전히 멈춘다. "도현아"라고 부른다. |
