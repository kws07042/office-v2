# 메신저 Windows 검증 결과

소스 회귀검사 110개 경로·1290개 단언 통과. 최종 Windows 패키지에서 메신저17·기본UI6·구버전 저장샘플2, 총25개 검사·259개 단언 통과. 두 구버전 저장 샘플만 검사했으며 모든 사용자 저장 위치의 호환을 보증하지 않는다. 최종 패키지 검사는 입력 중 설정의 새 회차 유지 검사 3개 단언을 추가했다.

실제 Windows 화면에서 연락처·세 답장·기록·사진 확대·입력 중 표시와 글자 겹침을 확인했다. QA 이미지 로더 검사는 기존 마스터를 격리된 검사 자료로 사용했으며 이야기 속 사진이 아니다. 사진 준비 중을 감상 완료로 기록하지 않는다.

캐릭터·리깅 자산 수정 없음. Windows 패키지는 소스·테스트·저장 파일을 제외했고 현재 런타임 파일36개의 바이트를 대조했다.
