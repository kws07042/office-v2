# 한서윤 · 이혼 후 자녀 양육 루트 v002

2026-11-05 사용자 승인 방향에 따른 현행 후보. 실행 대본과 함께 검토 브랜치에서 관리한다. 기존 기혼·배우자 동거·불륜 설정을 대체한다.

## 인물과 유지 기준

한서윤은 32세 브랜드전략팀 선임이다. 여유 있는 반말, 관찰과 장난, 브랜드 업무의 능력, 책·카페·산책·케이크 취향과 성인 외형을 유지한다. 도현은 28세, 다정하고 적극적이며 자신의 필요를 늦게 말하는 첫 연애의 주인공이다.

이혼은 이미 끝났고 아이 한 명과 지낸다. 아이 아빠와 필요한 돌봄 일정을 조율하며 재결합을 기다리는 관계가 아니다. 아이의 이름·나이·성별·외형, 이혼 사유·시점, 세부 양육 조건은 확정하지 않았다. 이 버전은 아이가 아빠와 보내는 날도 있다는 생활 일정을 대본 기본값으로 사용한다.

서윤은 자기 생활을 책임지면서 도현을 만나고 싶어 한다. 도현은 곧바로 부모 역할을 맡겠다고 약속하지 않으며 자기 바람과 어려움도 말한다. 아이 소개는 양쪽 성인과 아이의 준비를 확인할 별도 일이다. 아이가 있는 집과 둘만의 개인 작업실은 구분한다.

## 서사의 핵심

**좋아하는 마음을 말하고, 각자의 생활을 지키며 어디까지 함께할지 같이 고르는 연애.**

R02에서 가족 상황을 공개한다. R04의 교제 선택보다 앞이다. 후반 갈등은 숨긴 가족을 들키는 반전이 아니라, 도현이 힘들 것이라고 짐작해 관계의 범위를 혼자 정하려는 서윤과 자기 몫의 대답을 하고 싶은 도현의 충돌이다.

## 상태와 분기

- 사건 ID R01~R16·O01~O03·E01, 기존 성인 이벤트 3회와 R15 의상 대안, 원래 호감도 보상을 유지한다.
- `seoyun_family_disclosed`, `seoyun_family_state="divorced_parent"`는 실제 공개 대화 뒤에 기록한다. R04에는 공개를 놓친 이전 진입 경로를 위한 대화 확인을 둔다.
- R13 open → discussing → R14 agreed_pending_action → 실제 대면 → 지속 선택 뒤 resolved.
- R14에는 대화 전·대화 후 두 종료 출구가 있다. 종료 확정 뒤에는 R15·R16·E01로 강제 진행하지 않는다.
- 친밀한 선택을 미뤄도 관계 수습과 결말을 읽을 수 있다. 아이 소개를 미뤄도 벌점이 없다.
- 관계 수치는 이혼·자녀 공개·소개 약속 자체를 점수화하지 않는다. 실제 대화와 합의 확인만 반영한다.
- 내부 완료 ID `seoyun_good`을 유지하고 표시 제목을 ‘함께 고르는 다음’으로 바꾼다.
- E01은 소개의 의향이나 보류를 기록한다. 아이를 이미 만났거나 결혼·동거·부모 역할을 맡았다고 자동 기록하지 않는다.

## 그림과 목록

기존 일반 CG 34장 제안에서 서윤 R13 반지 공개를 **수첩을 덮고 서로의 바람을 말하는 장면**으로 교체한다. E01은 씁쓸한 갈라섬 대신 **기록집을 읽고 함께 걸어 나오는 장면**이다. 기본 수량은 유지한다. 아이를 새로 그리거나 입상·성인 이벤트 자산을 추가하지 않는다. 이전 반지 그림은 보관 이력으로 남긴다.

## 이전 저장과 검증

기존 수동 저장이나 서명을 지우지 않는다. 스토리 자동 기록의 빌드 식별자를 갱신해 이전 대본의 자동 재진입을 새 이야기의 기록으로 취급하지 않는다. 이전 혼인 설정이 들어 있는 수동 저장을 불러오면 한 번 안내하며, 새 이야기는 R02 또는 새 회차부터 읽는 것을 권한다. 과거 메시지·선택 기억을 임의로 새 경험으로 바꾸지 않는다.

모델 테스트와 대본 정적 검사를 수행한다. 기존 Ren’Py 네이티브 검사 파일의 선택 문구·상태 기대값도 갱신한다. 실제 엔진 Lint, 전체 분기 플레이, 저장/불러오기/롤백, 화면 렌더링은 이 작업 환경에서 실행하지 않았으며 별도 검증 대상이다.
