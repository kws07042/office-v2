# Grok 수정 요청 · 성인 장면 v002 → v003

> 사용법: Grok 대화창에 아래 순서로 넣는다.
> 1. 이 파일 전체
> 2. 지난번 결과 `grok-adult-scenes-v002-explicit.json`
> 3. (Grok이 맥락을 잊었으면) `grok-adult-scenes-v001.md`의 해당 히로인 부분
>
> 길면 히로인 단위로 나눠서 "리아 6장면만 먼저" 식으로 시킨다.

## 요청

네가 준 v002를 고쳐서 **v003 전체(25장면)**를 다시 줘. 노골적인 수위는 v002 그대로 유지해도 된다. 대신 아래 여섯 가지를 고친다. 반환 형식은 지난번과 같다. JSON 블록만 주고, `dual` 같은 새 필드는 넣지 마.

### 1. 히로인마다 다른 사람처럼 쓴다

다른 히로인 장면에 이미 나온 대사는 다시 쓰지 않는다. 특히 "아침까지 ~ 있고 싶어", "안 뺄게", "이렇게?", "알겠어요"를 여러 장면에 돌려쓰지 마.

| 히로인 | 이 장면에서의 모습 |
|---|---|
| 리아 | 장난스럽고 말이 빠르다. 장난으로 먼저 끌어당기지만, 결정적인 순간엔 농담이 끊기고 문장이 짧아진다. 부끄러우면 웃음으로 덮으려다 실패한다. |
| 지현 | 원하는 걸 짧게, 명령문처럼 말한다. 칭찬이나 다정한 말을 들으면 말을 잃고 "...그런 건" 하고 끊는다. 주도권을 쥐는 쪽. |
| 유진 | 존댓말. 머뭇대고 말끝을 흐리다가 갑자기 직구를 던진다. 빛·색·그림 같은 시각적인 비유를 쓴다("지금 이 색 기억해 둘래요"). 명령조는 쓰지 않는다. R15에서는 연습한 말을 하다가 중간에 잊는다. |
| 서윤 | 여유롭게 떠보는 반말. 진심일 땐 장난을 완전히 멈추고 조용해진다. R07은 과거를 덮어쓰고 싶은 절실함, R15는 숨길 게 없는 편안함. |

### 2. 도현이 대답만 하지 않게

"네.", "응.", "저도요.", "맘대로 하세요."만 반복하지 않는다. 도현도 먼저 묻고, 칭찬하고, 속도를 정하고, 농담한다. 다정하고 차분하지만 수동적이지는 않다.

### 3. 확인하는 순간을 넣는다

CG1과 CG2에 한 번씩 짧게 넣는다.
- 시선, 손, 짧은 물음 정도면 된다("여기 괜찮아?", "천천히 할까?").
- 상대가 웃으며 답하고 바로 이어 간다. 상담처럼 길게 끌지 않는다.
- 한 장면에 한 번은 히로인 쪽에서도 묻는다.

### 4. 분량

- 컷당 10~14줄, 장면당 30~40줄.
- 늘어난 분량은 대사로 채운다. 감정, 장난, 그날 있었던 일 이야기 같은 것들이다. 지문은 1~2문장 그대로.

### 5. 호칭

- 도현은 지현과 서윤의 이름을 직접 부르지 않는다. "지현 씨", "서윤 씨", "팀장님", "누나", "선배" 모두 금지다. 이 둘의 호칭은 플레이어가 고른다.
- 도현 이름은 `도현`, `도현아`, `도현 씨`만 쓴다.

### 6. R07 → R12 → R15가 다르게, 마무리는 장면마다 다르게

**관계 단계**

| 단계 | 분위기 |
|---|---|
| R07 | 첫 밤. 서툴고 웃음과 긴장이 섞인다. |
| R12 | 그리움. 각 히로인이 숨기는 고민이 살짝 비친다. |
| R15 | 화해 뒤의 편안함과 장난. |

**마무리 지문**
- "두 사람이 이불을 끌어올린다"를 돌려쓰지 않는다.
- 그 장면의 소품으로 끝낸다. 예: 리아의 찻잔·빗소리, 지현의 미니어처 집, 유진의 커튼과 아침 빛, 서윤의 작업실 조명, 코스프레 장면의 벗어 둔 의상.
- CG3 마지막 2~3줄은 원래 파일에 있는 **뒤 대사 첫 줄**로 자연스럽게 넘어가게 쓴다.
