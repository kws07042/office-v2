## 재독에서 정리한 부분

첫 실행 통과 뒤 실제 진행 기록에서 지현의 가까운 대사에 반복된 ‘고르는 건 네가 해’를 줄였다. 유진 스케치에는 빈 종이와 펜을 꺼내는 지문을 추가해 그림을 끼워 두는 동작의 출처를 보였다. 서윤 검사는 실제 혼인 공개·신뢰 상태 키를 확인하도록 명확히 했다. 이 문서의 소스 커밋은 이 정리 이후의 버전이다.

## 범위와 한계

선정한 회귀 검사 9개 묶음의 147사례이며 저장소의 모든 과거 테스트나 모든 선택 조합을 실행했다는 뜻이 아니다. 이전 문구/메뉴를 전제로 하는 과거 검사에는 낡은 기대값이 남아 있으며, 이번 작업의 통과 주장에 포함하지 않았다.

자동 진행과 새 테스트 내 저장/불러오기는 확인했지만, 실제 Windows EXE 실행·Windows 폴더 갱신·구버전 대본 중간 세이브의 완전한 이전·Windows ZIP 빌드는 하지 않았다. Windows 폴더는 기존 `0.34.1-dialogue-style` 그대로다.

진행 대사를 플레이어 관점으로 읽고 장면을 보강했지만, 사람 대상 재미 평가나 실제 독자의 플레이 시간 측정은 하지 않았다. 이번 수정은 중후반의 반복을 줄이는 편집이며 네 루트의 모든 공통 구성까지 새로 설계한 작업은 아니다.
