## 최초 실패와 수정

최초 CI에서 게임 빌드는 성공했지만, ZIP 경로 어디든 /tests/가 있으면 실패시키는 검사가 공식 Python 런타임의 future/tests 디렉터리와 pyc 두 개까지 잡았다. 산출물의 파일 목록을 직접 읽어 이 세 항목이 공식 라이브러리 경로임을 확인했다. 검사를 프로젝트 루트와 game 안의 검사/저장 경로로 한정한 뒤 다시 빌드·검사해 통과했다. 런타임 라이브러리 파일을 삭제하거나 바꾸지 않았다.

최초 실행의 이야기 검사 두 작업은 모두 성공했고, 수정 뒤 게임 소스가 같아 이야기 검사 반복은 생략했다. 실행 파일에 대한 새로운 악성코드 검사나 현재 PC의 무감염 판정을 수행한 기록도 아니다.

## 읽기 시간과 남은 범위
