# 메신저 디자인 정합 v2

기존 오피스 라운드 웹 시안의 색상과 글꼴을 Windows Ren’Py에 적용했다. 1280×720 게임 비율에 맞춰 재배치했으며 샘플 대사의 별도 대사 상자는 복제하지 않았다.

- 실행: 오피스 V2를 다시 실행 → R08 메신저 확인.
- 본문 Pretendard, 이름·연락처 Gowun Dodum. 글꼴과 OFL 원문을 로컬 동봉.
- 실제 R08 사진은 아직 준비 중 카드다. 다른 히로인의 대화는 구현하지 않았다.
- 캐릭터·표정·리깅·저장 파일은 수정하지 않았다.
- 소스 메신저 검사: 17개 사례·210개 assertion 통과, 엔진 lint 통과.
- Windows 패키지 검증과 설치 결과는 별도 JSON 및 로그 참조.

최종 Windows 패키지: 메신저 17개 사례·210개 assertion 통과. CRC·동봉 파일 40개 원본 대조 통과. 실제 게임 캡처에서 답장 3개·기록·입력 중 화면을 시각 확인했다.
