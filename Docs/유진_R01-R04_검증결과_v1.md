# 차유진 초반 구현 검증

- 소스: 유진 15개 사례·232 assertion, 기존 메신저 17개·210 assertion, UI 6개·35 assertion, 리아 전체 본편 8개·99 assertion 통과. 총 46개 사례·576 assertion.
- 최종 Windows 패키지: 유진·메신저·UI 총 38개 사례·477 assertion 통과. 대사 마지막 문장 편집 후의 패키지로 새 루트를 다시 검사했다.
- 공통 C08에서 유진 선택→R04 확인, 직접 확인 진입, 접촉 수락/미루기/이야기, 공통 디자인 질문 세 경로와 세부 기억 없는 경우, 바로 교제/준비 후 교제/동료/결정 취소를 검사했다. 모든 선택 조합을 전수 검사한 것은 아니다.
- 호감도 30 미만에서도 R03 이해와 상호 동의를 통해 교제 가능하다. 준비 대화에 추가 점수를 지급하지 않는다.
- 답장 선택 전 저장/복원, 손잡기 선택 전 저장을 불러와 다른 행동을 고른 뒤 회상도 달라지는지, 타 연락처의 기록 분리를 검사했다.
- 패키지 게임 파일 41개를 원본과 대조했다. 테스트·소스·저장 데이터는 실행 배포본에서 제외했다.
- 실제 캡처에서 유진 이름·교제 전 관계 표시·고백 선택지·개인 메시지 표시와 레이아웃을 확인했다. 현재 그림이 없으므로 임시 배경만 나오는 것이 의도한 상태다.
- 이미지·영상·음성·리깅을 제작하지 않았다. 유진 R05 이후, 최종 아트, 실제 읽기 시간 목표는 미완료다. 과거 버전 대본 중간 저장의 모든 위치 호환을 보증하지 않는다. GitHub 원격은 갱신하지 않았다.
