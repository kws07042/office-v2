# 실크와 립스틱 UI v001 (E안) — 게임 적용 기록

2026-11-12 · 작업 브랜치 `claude/silk-ui` · 표시만 변경. 대본·분기·점수·저장 변수·메신저 데이터는 건드리지 않았다.

## 바뀐 화면

- 대화창: 레이스 가장자리가 달린 불투명 종이 면, 점선 한 줄, 화자마다 색이 바뀌는 기울어진 이름표, 다음 표시.
- 선택지: 화면 가로 중앙의 알약형 버튼과 딱딱한 그림자. 초점이 가면 짙은 색으로 채운다. 문구가 ` — 친밀한 장면으로 이어짐.`으로 끝나면 그 부분을 꼬리표로 떼어 보여 주고, 아래에 "친밀한 장면을 미루는 선택에는 정답이 없어요."를 표시한다.
- 상단: 장 번호 배지와 장 제목·장소, 오른쪽에 이름·하트 다섯 칸·관계 상태·수치.
- 빠른 메뉴: 대화창 안 오른쪽 아래. 아이콘과 글자.
- 처음 화면: 실크 바탕, 대각선 띠, 기울어진 제목, 아래쪽 다섯 메뉴. 개발 확인용 진입 버튼 여섯 개는 오른쪽 위로 옮기고 이름·id·동작을 그대로 두었다.
- 설정·저장·불러오기·대화 기록·확인 창: 같은 종이 면과 버튼으로 바꿨다. 구성은 그대로다.

메신저(`office_phone.rpy`)와 우리의 기록(`progression.rpy`), 이벤트 컷 화면은 기본 버튼 모양만 따라 바뀌고 자체 배치와 색은 그대로다.

## 파일

- `Source/game/silk_ui.rpy` (신규): 색, SVG 그리기 도구, 화자 색·장 제목·선택지 꼬리표 판별 함수, 스타일.
- `Source/game/screens.rpy`: 위 화면의 모양.
- `Source/game/cream_ui.rpy`: `cream_round` 색 여섯 개만 새 색으로 교체.
- `Source/game/cream_tests.rpy`: `transparent_text`의 글자색·외곽선·이름색 기대값 세 줄을 새 대화창에 맞게 수정.
- `Source/game/fonts/`: 아래 글꼴과 `Jua-hangul-coverage.txt`.

## 판단이 들어간 부분

- 이름표 색은 `독백과_이름색_현행규칙_v1.md`의 짙은 쪽 값(리아 `#93600f`, 지현 `#32668e`, 유진 `#98516c`, 서윤 `#78549a`)을 썼다. 캔버스 시안의 임의 색(리아 파랑 등)은 쓰지 않았다. 바꾸려면 `silk_tag_color`만 고치면 된다.
- 이름표의 영문 표기(Kang Ria 등)와 메뉴의 영문 보조 라벨은 시안의 제안을 옮긴 것이며 공식 표기로 확정된 것이 아니다. 처음 화면의 영문 줄은 기존 화면에 있던 "After Work, With You"를 그대로 썼다.
- 대화창은 불투명이다. 투명 대화창을 전제로 한 `UI_투명대화_구분선_현행명세_v1.md`와 다르다.
- 대사는 세 줄까지 들어간다. 네 줄이 되면 빠른 메뉴 줄과 겹칠 수 있다.
- Jua 글꼴은 한글 2,367자만 담고 있다. 장 제목이나 화자 이름에 없는 글자가 섞이면 고운돋움으로 자동 대체한다(`silk_title_font`).

## 엔진에서 확인한 것 (2026-11-12)

공식 배포 SDK가 아니라 **Ren'Py 공식 GitHub 저장소의 `8.5.3.26051504` 태그 소스를 리눅스에서 직접 빌드한 엔진**으로 실행했다(엔진이 스스로 표시한 버전은 `8.6.0.26051501+unofficial`). 저장소가 고정한 SDK 8.5.3 해시로 검증한 실행이 아니므로 배포 전 검증을 대신하지 못한다. 실행 조건은 `xvfb`, `RENPY_RENDERER=sw`, 작업마다 새 저장 폴더.

| 검사 | 결과 |
|---|---|
| `lint` | 통과 (오류 없음) |
| `silk_ui_checks` (신규) | 7건 통과, 단언 12개 통과. 처음 화면·긴 대사·친밀한 선택지·화자 다섯 명 이름표·지문·저장·설정·대화 기록 캡처 |
| `common_romance` | 21건 통과, 단언 344개 통과 |

| `cream_ui_checks` | 8건 중 1건 통과, 5건 실패, 2건 건너뜀. 실패 다섯 건은 모두 `cream_ria_visible() is True` 단언이다. 리아 입상 그림이 2026-11-06에 삭제되어 생긴 기존 실패이며 이번 UI 변경과 무관하다 |

실행 중에 고친 것:

- `vscrollbar_style`은 viewport에서 쓸 수 없는 속성이라 게임이 아예 읽히지 않았다. `screens.rpy`(3곳)와 `office_phone.rpy`(2곳)에서 `vscrollbar_xsize`·`vscrollbar_base_bar`·`vscrollbar_thumb`·`vscrollbar_unscrollable`로 바꿨다. 이 오류는 이번 작업 이전의 main에도 있었다.
- 긴 대사가 다음 표시와 겹쳐서 글줄 폭을 줄이고 다음 표시를 오른쪽 아래로 옮겼다.
- 한글이 낱말 중간에서 끊겨서 대사·선택지·대화 기록에 `language "korean-with-spaces"`를 적용했다.
