## 11. 구현·집필 검증의 기준

- 본문 표의 사건 수는 95개이며 일반 CG 배정 18개는 별도 자산 목록이다.

통합 기획서 28절에 따라 각 인물의 R08과 O03, 기존 8개 사건 안에 짧은 조건부 대사 분기를 둔다. 추가 사건으로 세지 않는다. 실제 친밀한 밤의 기억, 교제 확인, 사적 장소·개인 채널, 갈등 상태, 이전 농담에 대한 반응을 확인하고 한 번의 장난 뒤 원래 사건의 화제로 복귀한다.

- 리아: R08의 편한 개인 연락, O03의 함께 쉬는 방식 안에서 가벼운 장난.
- 지현: R08의 개인 채널, O03의 둘만 있는 부탁에서 짧고 직접적인 장난.
- 유진: R08의 다음 만남 제안, O03의 준비한 데이트에서 존댓말을 유지하는 작은 장난.
- 서윤: R08의 ‘보고 싶다’는 직접적인 표현 이후, O03의 사적인 반복 방문 기억에서 장난. 직원·손님이 있는 자리에서는 사용하지 않음.

R08은 R07의 실제 발생 여부를 따른다. O03은 그 시점까지의 실제 기억과 갈등 상태를 확인한다. 표시만 스킵한 사건과 사건 자체를 미룬 경우를 구분하고, 다른 인물의 기억이나 회상 열람을 현재 관계 기억으로 처리하지 않는다. 농담을 중단한 기억이 있으면 일반 일상·애정 대사로 대체한다. 이 반응 자체에는 호감도·신뢰 가감점을 주지 않는다.

R13·R14의 갈등과 행동 확인을 농담으로 수습하지 않는다. 모든 루트의 기존 사건 목적·교제 확인·엔딩 조건과 선택적 일상의 성격을 유지한다. 리아의 새 이미지 전달 전에도 대사 분기 명세를 작성할 수 있으며, 현재는 코드 구현·플레이테스트 전이다.

## 13. 대표 선택의 세 단계 효과

통합 기획서 30절과 [선택 분기·기억 회수 명세](<선택_분기와기억회수_명세_v1.md>)를 따른다. 리아 R01 → R03 → R10, 지현 R02 → R05 → R10, 유진 R02 → R05 → R10, 서윤 R02 → R03 → R10의 첫 대표 사례를 작성했다. 기존 사건 안에서 선택한 행동·상황과 후속 반응을 달리 쓰고 필수 진행으로 합류한다.

각 루트의 대표 선택 3개에 가까운·후반 회수를 두어 최소 6회 기억 회수 기준을 충족하는 것을 집필 목표로 한다. 현재는 인물당 첫 대표 사례와 리아 R01의 짧은 대사 가지를 작성한 상태이며, 전체 선택 대본이나 코드를 완성한 것은 아니다. 취향 선택의 차이를 오답 점수로 만들지 않고 과거 행동과 현재 선호, 계획과 실제 방문을 구분해 기록한다. 사건 95개·일반 CG 18개에 추가로 중복 집계하지 않는다.

## 14. 공개 범위와 큰 결정의 안내

교제 초반은 둘만 아는 상태다. R06에서는 사적인 호칭·표현·속도와 우선 비공개로 두는 합의를 확인한다. R10의 소품·개인 취향·목표 대화를 마친 뒤 사적인 자리에서 친한 동료에게 알릴지 함께 고르고, 합의한 경우 R11의 짧은 회사 대화·개인 메시지에서 실제 공개와 동료 반응을 확인한다. 비공개는 같은 위치에서 둘만의 약속을 회수한다. R11은 공동 활동과 일정 예고로 마무리하며 친밀한 이벤트를 추가하지 않는다.

공개 합의와 실제 공개, 실제로 알게 된 동료 명단은 각각 기록한다. 동료 반응은 그 동료가 알고 있는 정보만 따른다. 비공개도 같은 좋은 결말과 기본 분량이 가능하다. 공개 선택을 별도 기본 사건으로 집계하지 않으며 일반 CG나 새 등장인물을 요구하지 않는다.

통합 기획서 v2.30 기준으로 공개 상대는 다른 히로인 한 명이다. 집필 기본값은 리아→서윤, 지현→리아, 유진→지현, 서윤→유진이다. R10에서 합의하고 R11의 실제 전달 뒤 해당 인물만 교제를 아는 상태로 갱신한다. 짧은 축하·장난과 비공개 대체 대화는 기존 R11 안에서 처리한다.

선택 전에는 숨은 점수·정답 힌트를 표시하지 않는다. 교제 시작·준비 대화·관계 정리·교제 사실 공개의 뜻은 선택 문장과 대화로 명확히 구분한다. 애매한 선택 문장으로 갑자기 종료 경로에 보내지 않는다. 큰 결정의 의미를 알리는 것과 후반 결과를 미리 공개하는 것을 구분한다.

## 15. 이전 연애와 고백의 주도

사용자는 도현의 첫 연애, 히로인마다 다른 이전 연애 경험, 루트마다 다른 고백 주도를 선택했다. 개별 배정은 통합 기획서 32·33절의 집필 기본값이다. 리아는 연애 경험이 있고 지현은 적으며 유진은 첫 연애, 서윤은 여러 경험이 있다. 횟수·기간·이전 상대의 세부 설정은 확정하지 않는다. 기존 R04·R06·R10의 짧은 대화로 현재 원하는 관계를 드러내고 이전 상대의 등장·새 회상 사건·전용 CG를 추가하지 않는다.

리아·지현 루트는 도현이 먼저, 유진·서윤 루트는 히로인이 먼저 고백한다. 도현이 먼저인 경우 플레이어의 의사 선택 뒤 고백 가지로 진입한다. 히로인이 먼저인 경우 상대의 고백을 들은 뒤 응답을 선택한다. 준비 대화는 교제 확정이나 관계 정리가 아니며, 명시적인 상호 의사 확인 뒤에만 교제 상태를 기록한다. 준비 대화를 이어갈 위치와 재확인 조건은 대본·진행 명세에서 함께 검증한다.

첫 연애의 서툼은 R04~R06의 호칭·연락·표현에 작은 긴장으로 드러내되 도현과 유진의 적극성을 지우지 않는다. R13의 고유 갈등을 모두 경험 부족 때문으로 바꾸지 않는다. 과거 연애 경험은 성적 경험을 자동 확정하는 값으로 사용하지 않는다. 이 변경은 기존 사건 내부의 집필 기준이며 사건 95개·일반 CG 18개를 유지한다.

## 16. 초반 시간 목표와 같은 R04 안의 재확인

시간 배분과 재확인의 최신 기준은 통합 기획서 v2.22다. C01~C08과 선택 루트 R01~R03의 기본 경로를 측정하며 자발적 선택 일상·로그 재독·장시간 일시정지는 따로 기록한다. 선택 일상과 업무 미니 사건은 R04의 필수 점수 확보 수단으로 만들지 않는다. 한 회차에서 고른 짧은 가지의 시간을 포함하고 모든 가지의 합계를 플레이 시간으로 세지 않는다.

R04에서 준비 대화를 고르면 같은 장면 안에서 걱정·원하는 관계를 이야기한 뒤 교제 의사를 다시 선택한다. 처음부터 합의하거나 준비 후 합의한 경로만 R04의 공동 마무리와 R05로 이어진다. 준비 대화에는 별도 점수 보상·벌점을 붙이지 않고 기본 교제 보상을 중복 적용하지 않는다. R05 이후의 연인 대사는 교제 확정 상태를 확인한다.

재선택에서도 교제를 시작하지 않기로 한다면 ‘이번 회차는 연애를 시작하지 않고 동료로 지낸다 — 동료 결말로 이어짐’처럼 결과가 명확한 선택으로 기존 END_COMMON에 연결한다. 처음 준비 대화를 골랐다는 이유만으로 이 경로로 보내지 않는다. END_COMMON에는 실제 대화 기억을 반영한 짧은 도입을 두며 새 사건·엔딩으로 세지 않는다. 구체적인 분기·상태·대사 초안은 선택 분기 명세 8절을 따른다.

## 17. 썸 단계의 가벼운 애정 표현

통합 기획서 v2.23의 35절을 따른다. 서로 관심이 드러난 썸에서 손잡기·가벼운 포옹을 선택할 수 있다는 사용자 확정에 따라, 집필 기본 배치는 리아 R02의 손잡기, 지현 R02의 팔짱 제안, 유진 R02의 손잡기 제안, 서윤 R03의 짧은 포옹 인사로 둔다. 기존 사건 안에 넣고 주요 선택 1~2개 기준과 초반 시간 목표 안에서 조정한다.

접촉을 미루는 가지도 서로에 대한 관심과 다음 약속으로 이어진다. 접촉 여부에는 차등 호감도·신뢰 보상이나 교제 해금 조건을 붙이지 않는다. 제안·수락·실제 발생과 현재 선호를 구분해 기억하고 다음 기존 사건에서 실제 경험만 회수한다. 애정 표현만으로 R04 이전의 교제를 확정하지 않는다.

새 사건·전용 CG·도현의 신체 자산을 추가하지 않는다. 리아 R02의 짧은 대사 샘플은 선택 분기 명세 9절에 작성했으며 전체 R02~R04 대본이나 게임 코드 완성은 아니다. 개별 사건표와 연출 표에는 전체 대본 작성 때 실제 가지·회수 조건을 연결한다.

## 18. 화제 하나의 진행과 첫 입맞춤 배치

통합 기획서 v2.24의 9·36절과 선택 분기 명세 10·11절을 따른다. 화제를 하나 고른 뒤 대화·후속 반응으로 진행하고, 다음 사건에 필요한 정보는 어느 가지에서도 전달한다. 고르지 않은 개인 화제를 이미 이야기한 것으로 기록하지 않는다. 사건의 화제 메뉴를 전부 읽게 하는 반복 진행은 두지 않는다.

첫 입맞춤의 집필 기본값은 리아 R04·지현 R05·유진 R05·서윤 R04다. 실제 교제를 확인한 뒤 선택 가능하게 하고, 미루는 경우에도 같은 연인 경로로 이어진다. 실제 발생 여부·위치와 제안만 했던 기억은 분리한다. 다음 기존 애정 표현 대화에서 플레이어가 원할 때 재제안할 수 있지만 자동 발생시키지 않는다. 사건·전용 CG·도현 신체 자산은 추가하지 않는다.

## 19. 짧은 독백과 후일담의 미래 선택

도현의 독백은 긴장·설렘 순간에 짧은 1~2문장으로 쓰며 대사를 반복 해설하지 않는다. 히로인 속마음을 확정하거나 플레이어 선택을 뒤집는 독백은 쓰지 않는다. 실제 응답·제안·행동으로 이어지는지 대본에서 확인한다. 도현 대사·독백은 텍스트로 유지한다.

E01의 개별 관계 도달점은 위 사건표와 통합 기획서 37절의 집필 기본값을 따른다. 동거 논의·준비는 두 사람이 실제로 합의한 경우에만 기록하고, 아직 각자 살기를 원하면 같은 E01 안에서 안정된 교제와 구체적인 만남 약속으로 대체할 수 있다. 계획·합의·실제 실행을 섞지 않는다. 개인 엔딩을 새로 나누거나 사건·CG 수를 늘리지 않는다.

## 20. 유진의 선택별 갈등과 음성 대상

통합 기획서 v2.26의 38절과 선택 분기 명세 13절을 따른다. 유진의 지원 선택은 R09에서 실제 행동으로 기록하고 R12~R14에서 현재 합의·수습 상태와 함께 읽는다. R02 전시 취향이나 호감도만으로 지원 행동을 추정하지 않는다. 선택 기억이 없으면 지금 원하는 도움을 묻는 대체 대사를 사용한다. 별도 사건·CG를 추가하지 않고 기존 R13·R14 내부 변형으로 관리한다.

핵심 소개·고백·갈등·엔딩의 히로인 줄만 음성 대상이다. 도현 대사·독백에는 음성 파일을 배정하지 않는다. 유진 R13의 변형은 실제 고정된 히로인 대사별로 관리하고 공통 줄을 재사용하더라도 다른 경로의 사과·조율 대사를 잘못 연결하지 않는다. 현재는 명세이며 음성 생성·게임 실행 검증 결과가 아니다.

## 21. 갈등 대응의 만회

통합 기획서 v2.27의 39절을 따른다. R13에서 한 번 서툰 대응을 골라도 그 회차의 좋은 결말을 자동으로 잠그지 않는다. 상대의 구체적인 반응 뒤 같은 R14 안의 확인 대화로 원하는 방식을 다시 묻고 기존 실제 수습 행동으로 이어진다. 처음부터 잘 대응한 경로에는 불필요한 재시험을 붙이지 않는다.

확인·합의·실제 행동을 기록하고 R15 이후에 올바른 조율·수습 기억을 회수한다. 사과 한 줄·호감도·친밀한 장면만으로 갈등을 해결하지 않는다. 추가 사건·CG·엔딩·반복 선물·선택 일상 해금은 요구하지 않는다. 실제 갈등 대본·진행 상태의 실행 검증은 제작 단계다.

## 22. 공동 활동 중심의 R11

통합 기획서 v2.28의 40절과 선택 분기 명세 15절을 따른다. 네 R11에서 공동 활동·작은 선택·장난으로 일상의 차이를 보여준다. 실제 음식·놀이 방식·음악 이야기·길을 기록하고 R12와 E01의 기존 대사에서 회수한다. 미선택 가지의 경험은 생성하지 않는다.

## 23. 도현의 취미 기록집
