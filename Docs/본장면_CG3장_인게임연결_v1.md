# 선택지 3개와 장면 흐름 — 현행 명세 v1

## 이번에 실제 바꾼 범위

구현된 공통 구간·리아 루트의 두 개짜리 이야기 선택 32곳을 세 가지로 늘렸다. 각각 다른 반응·행동과 기억을 기록한다. 기존 세 개 이상인 메뉴는 그대로다. 다른 세 히로인의 미구현 개인 루트에 대사를 연결했다고 표시하지 않는다. 이후 집필에도 같은 기준을 적용한다.

| 상황 | 세 번째 선택 예시 | 후속 처리 |
|---|---|---|
| 말 놓기 | 서로 이름을 불러 보며 함께 연습 | 반말 합의, R02에서 연습했던 일을 회수 |
| 첫인상·업무 | 예상 비교 / 작업 고민 묻기 / 답장 초안 함께 수정 | 해당 인물 고유 반응과 기억. 업무 설명을 길게 늘리지 않음 |
| 데이트 | 사진 한 장과 제목을 함께 정하기 | 식당에서 제목을 다시 말하고 R07에서 기억. 두 장 찍었다고 하지 않음 |
| 애정 표현 | 손 잡고 기대기 / 정류장에서 함께 기다리기 | 입맞춤과 별개의 기억. 첫 입맞춤을 자동 기록하지 않음 |
| 연락 | 어제 좋았던 작은 순간 보내기 | 메시지 고유 대사. 답장 속도 벌점 없음 |
| 갈등 | 내 필요와 연락 방식을 함께 정하기 | R14의 실제 약속 이행을 거친 뒤 해결. 말 한 줄로 즉시 해결하지 않음 |
| 선택 일상 진입 | 방문·산책 대신 짧은 안부 | status=brief. 일상 완료·방문·장소 발견·완료 보상은 주지 않음 |
| 가까워지는 속도 | 마음을 이야기하고 오늘은 각자 귀가 | deferred. 이미지 화면 진입·복장 선택·감상 기록 없음, 연애는 계속 |

‘다정한 직구 / 장난으로 표현 / 함께 방법 고르기’ 등을 장면에 맞게 나눈다. 모든 메뉴를 정답·중립·오답으로 만들지 않는다. 새 선택에 별도 호감도 보너스나 생명력 벌점을 넣지 않았다. 선택별 즉시 반응과 해당 행동의 기록을 우선하고, 모든 선택이 별도 엔딩을 만든다고 설명하지 않는다.

기능이 명확한 **동료 결말 확인, 고백 거절 재확인, 후일담 열기**는 두 항목을 유지한다. **R15 의상 결정**도 기존 두 의상 세트를 유지한다. 세 번째 의상을 새로 요구하지 않는다. 이전 두 항목은 순서를 보존하고 새 항목을 뒤에 붙였다. 고백의 준비 대화 뒤에는 기존처럼 같은 자리에서 관계를 다시 확인한다.

전체 95개 사건·일반 CG18개·3회 이벤트·생활복/특별 의상 대안 구조는 유지한다. 짧은 안부는 기존 선택 일상의 생략 가지이며 96번째 사건이 아니다. 새 선택의 실제 읽기 시간 증가는 아직 측정하지 않았으므로 초반 고백 60~90분은 검증 전 목표다.

## 이미지가 들어가는 화면 흐름

| 순서 | 대본 페이지 수 | 사용하는 이미지 |
|---|---:|---|
| 도입 대화 | 3 | 같은 기본 이미지 재사용. 마지막 대화에서 부끄러운 표정 차분으로 전환 |
| 본장면 이미지 자리 | 3 | 기본 CG01 → 02 → 03 |
| 이후 대화 | 1 | 도입 기본 이미지 재사용. 새 여섯 번째 이미지 불필요 |

따라서 **이미지는 총5버전, 대화와 이동 화면은 총7페이지**다. ‘표정 전 한 장＋표정 후 한 장’은 같은 구도·의상·머리·인물의 표현 차이를 뜻하며 독립 원화 두 장을 요구하지 않는다. 도입은 기본1＋표정 차분1, 본장면은 기본3이다. 기존 본장면 차분2는 제거했다. 구체적인 행위·자세·이미지 제작 지시는 이 명세에 추가하지 않았다.

도입 마지막 페이지에서 0.65초 뒤 표정이 바뀐다. 다음 버튼은 즉시 사용 가능하며 기다리도록 강제하지 않는다. 다시 이전 페이지로 가면 기본 표정, 표정이 바뀐 마지막 도입으로 돌아오면 바뀐 상태를 보여 준다. 저장·복원 시 상태를 보존한다. 이후 대화는 기본 표정으로 돌아간다. 그림이 없으면 솔직한 준비 중 안내만 표시한다.

‘불빛이 잦아들고’ 별도 카드를 제거했다. 본장면 이후에 다시 함께 밤을 보낼지 결정하는 중복 설명은 없다. 본장면에 들어가기 전에 연출을 건너뛰면 짧은 시간 경과 표기 한 번만 사용한다.

현재 R07·R12·R15 두 의상 가지, 리아 네 세트에 화면 연결했다. 나머지 세 히로인의 동일 배치는 JSON에 계획만 등록했다. 실제 그림·동영상 파일은 전부 미제공이며 영상 재생기는 이번 변경에 추가하지 않았다. 리아 이미지 제작 보류·새 마스터 대기·전원 귀걸이 없음·CG에서 도현 얼굴을 보이지 않는 규칙은 유지한다.

## 기록과 파일

game/event_cg_plan.json과 story/adult_event_cg_plan_v1.json은 같은 자료다. 16개 세트에 도입 기본16＋도입 차분16＋본장면48=80개 경로가 등록되어 있다. 이는 양쪽 의상 대안을 모두 준비할 때의 값이다. 한 히로인 한 회차는 3회×5=15버전, 모든 의상 대안 포함 준비량은20버전이다. 실제 원화·파일 납품 완료 장수가 아니다.

event_presentations의 layout_version=3. visited_slots는1~7 위치, main_frames_seen과 base_slots_seen은1~3 위치 방문 기록이다. 이 값으로 이미지를 감상했다고 판단하지 않는다. loaded_asset_ids는 실제 표시한 파일만 기록한다. 차분이 없고 기본 그림이 있으면 기본으로 대체하되 차분은 missing_asset_ids에 남긴다. 이미지가 하나도 없을 때 감상 완료 ID는 비어 있다. 갤러리와 Steam 업적은 아직 연결하지 않았다.

변경 선택·실제 대사는 [선택지 증설 목록](선택지3개_변경목록_v1.md), 모든 현재 대본은 ‘현행대본’ MD를 본다. 기존 저장 전체의 호환성은 미검증이므로 이번 개발판 확인은 새 회차를 권장한다. 실제 검사 결과는 별도 검증 보고서에 기록한다.
