# Grok 히로인별 수정 요청 (겹치는 줄 없애기)

> 사용법
> 1. Grok 새 대화창에 **[공통]**과 `grok-adult-scenes-v003b.json`을 먼저 넣는다.
> 2. 이어서 **[1. 리아]**만 넣고 답을 받는다.
> 3. 받은 답은 저장해 두고, 같은 대화창에 **[2. 지현]**을 넣는다. 유진, 서윤도 같은 방식으로 이어 간다.
> 4. 결과 네 개를 Claude에게 가져온다. Claude가 다시 점검해서 겹치는 줄이 남았으면 알려 준다.

## [공통]

첨부한 `grok-adult-scenes-v003b.json`은 성인 VN의 본장면 대사다. 흐름·동의 확인·마무리는 다 됐다. 남은 문제는 **여러 히로인이 같은 대사를 돌려쓰는 것**이다.
이제부터 히로인 한 명씩, 지정한 줄만 새로 쓴다. 수위와 그 줄의 역할(누가 말하는지, 장면에서 어디쯤인지)은 유지하고, 그 히로인만 할 수 있는 말로 바꾼다.

**같은 문장의 기준 (이 중 하나라도 해당하면 같은 문장이다)**
- 문장부호, '…', '아/아아' 같은 감탄사만 다르다.
- 어미만 다르다. 예: "끝까지. 내가 흔들게" / "끝까지요. 제가 흔들게요"
- 핵심 단어 3개 이상이 같은 순서로 나온다.
- 지금 쓰는 히로인의 다른 장면에서 이미 쓴 문장이다.

**제출 전 자체 점검 (필수)**
1. 새로 쓴 줄을 하나씩 **금지 목록**과 대조한다.
2. 이번에 쓴 줄끼리도 서로 대조한다.
3. 앞 히로인 차례에서 네가 쓴 줄과도 대조한다.
4. 하나라도 걸리면 고친 뒤에 제출한다.

**반환 형식**
설명 없이 JSON 배열 하나만 준다. `line`은 목록의 줄 번호를 그대로 쓴다. 리아는 `["반말","존댓말"]`, 나머지 히로인은 문자열이다.
```json
[{"id": "ria_r15:home", "cg": 1, "line": 9, "text": ["반말", "존댓말"]}]
```
