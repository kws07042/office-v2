## 1. 상황과 보완점

후속 문서 — 2026년 10월 14일: 채택한 1안은 [리아 R02~R04 연결 대본 v1](<리아_R02-R04_연결대본_v1.md>)의 together·나란히 대화 경로에 유지했다. 존댓말과 다른 계획의 도입도 연결했다. 이 비교 문서의 미완료 표시는 비교 당시의 상태다.

결정 갱신: 2026/10/13 사용자는 1안 ‘장난 뒤 짧은 직구로 관심을 분명히’를 선택했다. 해당 부분을 분기 명세와 연결 대본 초안에 반영한다. 아래 두 안은 비교 이력으로 보존하며 2안의 새 생활 정보는 채택한 사실로 기록하지 않는다. 선택 범위는 이 리아 R02 부분이다.

예약하려던 가게가 닫혀 둘이 대체 장소로 걷는다. 도현은 리아의 회사 밖 모습을 더 알고 싶고, 리아도 자기 이야기만 하는 것보다 도현의 취향을 궁금해한다. 아직 교제를 확정하지 않는다. 선택한 나란히 걷기 가지에 손잡기 발생을 넣지 않는다.

기존 ‘평범한 얘기도 너한테 들으면 다를 것 같아서’는 호감은 분명하지만 칭찬이 이어지면 도현이 늘 능숙한 말을 준비한 인물처럼 보일 수 있다. 질문을 생활의 구체적인 사실로 좁히고 리아도 도현에게 묻게 한다. 아래 반말 샘플은 해당 말투 경로를 검토하는 것이며 존댓말을 선택한 플레이에 그대로 사용하지 않는다.

## 2. 안 1 — 장난 뒤 한 번의 짧은 직구

리아: “그럼 이번 코스는 어디부터야? 완벽한 계획 말고.”

도현: “일단 저쪽까지 걸어 보자. 걷다가 괜찮은 데가 보이면 들어가고.”

리아: “나보다 계획이 없네.”

도현: “오늘은 네가 퇴근하면 어떤 사람인지 좀 더 알고 싶어서.”

리아: “회사에서 보는 거랑 많이 다르면?”

도현: “그럼 내가 아는 네가 하나 더 생기는 거지.”

리아가 다음 말을 고르다 웃는다.

리아: “……좋아. 대신 네 얘기도 하나씩. 나만 취재당하는 건 싫어.”

도현: “응. 질문 하나씩 번갈아 하자.”

편집 판단: 목적이 분명하고 관심을 숨기지 않아 설렘을 만들기 좋다. 다만 ‘아는 네가 하나 더 생긴다’는 문장도 앞뒤에서 비슷한 멋있는 말을 반복하면 다시 준비한 멘트처럼 들린다. 이 부분에서는 한 번만 사용하고 리아의 실제 생활 이야기로 바로 넘어간다.

## 3. 안 2 — 생활 이야기와 짧은 받아치기 중심

리아: “가게는 바뀌어도 저녁은 먹는 거지?”

도현: “그건 지켜야지. 걷는 김에 궁금한 것도 하나 있고.”

리아: “회사 질문이면 내일 받습니다.”

도현: “집에 가면 제일 먼저 뭐 해?”

리아: “가방 내려놓고, 냉장고부터 열어. 아주 중요한 일이지.”

도현: “내 첫 질문부터 너무 쉽게 끝났네.”

리아: “아직 네 차례 남았어. 너는?”

도현: “좋아. 이번엔 내가 대답할게.”

편집 판단: 대화가 편하고 두 사람의 생활을 구체적으로 알아간다. 다만 이 말맛만 계속 쓰면 동료나 친구 사이처럼 읽힐 수 있다. 다른 실제 행동·다음 약속·서로를 고른 이유로 이성적인 관심을 보완해야 한다. 냉장고 이야기는 새 취향 대사 후보이며 전체 R02에 채택한 뒤에만 실제 들은 사실로 기록한다.

## 4. 합류와 기록

어느 안이든 실제 선택한 대체 장소로 이동해 짧은 식사·다음 약속 이야기로 합류한다. 실제 들은 습관과 도현이 답한 자기 이야기를 기록하고 R03의 가까운 회수 후보로 연결한다. 채택하지 않은 안의 대사·생활 정보를 경험했다고 저장하지 않는다. 반복 질문으로 모든 화제를 소모하게 하지 않는다.

안 1을 기본 추천한다. 직구를 한 번만 쓰고 생활 이야기로 이어지게 하면 기존 장난·빠른 템포·적극적인 도현과 잘 맞는다. 이는 어시스턴트의 편집 의견이며 사용자 선택·실제 읽기 검증 결과와 구분한다. 새 사건·CG·그림·음성은 추가하지 않고 리아 이미지 작업은 재개하지 않는다.
