## 구현

전용 로고는 AI 콘셉트에서 곡선·일몰·쉼표 모티프를 정하고, 한글과 영문을 나눔명조로 다시 조판했습니다. 투명 PNG와 밝은/어두운 색상, 등장 연출용 네 레이어를 제공합니다. [편집용 SVG](../../Source/game/gui/title/logo_editable.svg)와 글꼴 원본·라이선스도 포함합니다. AI 콘셉트는 최종 로고와 구별하여 Design에 보관했습니다.

새 카페 배경은 리아 확정 CG의 화풍을 참고해 imagegen 내장 도구로 제작했습니다. 히로인 화면은 기존 CG 네 장을 바이트 변경 없이 그대로 사용합니다. 원화의 얼굴·손을 생성 영상으로 변형하지 않고, 빛·입자·크로스페이드만 별도 레이어로 움직입니다. 반지·결말 장면은 타이틀에 사용하지 않습니다.

등장 연출은 5초이며 클릭·Enter·Esc로 생략할 수 있습니다. 메인 메뉴로 복귀할 때 다시 재생하지 않습니다. 브라우저의 '등장 연출 다시 보기'는 검토 도구입니다.

## Ren’Py 적용 파일

Source/game/screens.rpy는 현재 main의 화면 파일에서 메인·설정·저장/불러오기·확인창을 교체한 버전입니다. Source/game/title_menu.rpy와 gui/title, fonts의 새 파일을 함께 적용합니다. 기존 Source/game/options.rpy·저장 디렉터리·슬롯 1~4·대본·선택·호감도 데이터는 변경하지 않습니다. 덮어쓰기·불러오기 확인과 세이브 서명 보호도 유지합니다.

개발용 대본 바로가기는 config.developer일 때 별도 메뉴로 표시합니다. 기존 여섯 검사 파일과 두 검사 생성기의 바로가기 진입 경로도 새 개발 메뉴에 맞췄습니다. 제작 도구는 실행하지 않았습니다. 일반 배포에서 기존 *_tests.rpyc 제외 규칙을 유지해야 합니다.

## 시안과 게임의 차이

브라우저는 화면 전환을 확인하는 독립 시안입니다. '처음부터 읽기'는 기존 리아 화면 확인 대사 한 줄로 연결되며 본편을 실행하지 않습니다. 저장 슬롯은 비어 있고 실제 Ren’Py 세이브를 읽지 않습니다. 설정은 브라우저 시안 전용으로 보관합니다.

게임 소스는 Start/ShowMenu/Preference/FileSave/FileLoad에 연결합니다. CSS의 장식 클리핑·배경 블러와 Ren’Py의 페이드·반투명 면은 렌더링 방식이 다릅니다. 브라우저의 전체 화면 버튼은 미리보기 도구이고, 게임 설정에는 실제 창/전체 화면 동작을 제공합니다. 음악·효과음은 이번 버전에 추가하지 않았습니다.

## 검증과 남은 확인

브라우저에서 네 히로인 전환, 설정 토글·속도 조절, 빈 슬롯 비활성, 시작 전환, 복귀, 종료 확인, 인트로 Enter 생략과 자동 종료를 확인했습니다. 이미지 누락과 콘솔 오류도 확인했습니다. 실제 기록은 QA 아래에 있습니다.

공식 Ren’Py 8.5.3 SDK를 내려받아 공개 SHA-256과 대조했지만, 자동 승인 검토가 외부 실행 파일의 정적 검토 전제를 충분히 확인할 수 없다는 이유로 실행 검증을 차단했습니다. 따라서 Ren’Py lint·실제 시작·저장/불러오기 회귀 테스트는 미완료입니다. 검증용 프로젝트는 작업 폴더에 별도로 준비되어 있으며 기존 게임 실행 파일과 개인 세이브를 사용하지 않습니다. 실행 확인이 끝나기 전에는 적용 후보로 취급합니다.
