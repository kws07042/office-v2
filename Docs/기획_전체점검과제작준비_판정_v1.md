첫 고백 60~90분·한 루트 4~5시간·약 두 달 제작은 계획과 가설이다. 실제 대본의 읽기·선택·음성·연출·수정 시간을 재기 전 달성·출시를 보장하지 않는다. 목표를 맞추려고 같은 감정을 반복하는 대사를 늘리지 않는다.

## 5. 남은 일을 질문 대신 제작으로 해결하는 순서

1. 리아 R02의 다른 선호·재예약·손잡기·존댓말 경로를 연결하고 R03·R04를 실제 대본으로 완성한다. 미경험 대체·핵심 정보·현재 선택과의 합류를 확인한다.
2. 공통 C02~C08의 전체 대본과 선택을 연결해 네 인물 소개·C08 선택·리아 초반으로 이어지는 흐름을 검토한다. 부분 샘플을 완성 사건으로 세지 않는다.
3. 최소한의 게임 연결로 실제 읽기·선택·기억 회수·저장 복원을 시험한다. 첫 고백·첫 전환·전체 분량을 이 단계에서 측정하고 집필량을 보정한다.
4. 리아 R16·E01·선택 일상까지 한 루트를 연결하고 나머지 세 루트에 같은 제작·검수 기준을 적용한다. 갈등의 원인·수습 행동·회수 대사가 서로 구분되는지 확인한다.
5. 실제로 필요한 일반 자산·음성·음원·레이어 목록을 대본에 맞춰 고정하고 파일·사용 조건·품질을 확인한다. 리아는 사용자 제작본 대기·이미지 작업 중단을 유지한다.
6. 출시용 빌드에서 로컬 저장·Cloud·업적·UI·폰트·음향·호환성·스토어 설명의 일치를 검증한다. 가격·출시 날짜·완성도 표시는 실제 제품과 검증 근거를 마련한 뒤 결정한다.

이 목록은 현재 제작 기준이다. 별도 자동 실행·예약 작업을 만들거나 실제 게임·Steam 설정을 수행한 기록은 아니다. 단순한 미완료 작업을 새 취향 질문으로 바꾸지 않는다.
