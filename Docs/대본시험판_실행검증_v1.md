## 3. 이번 검수에서 수정한 문제

1. SDK 한글 글꼴에 빠진 중점·일부 문장부호를 DejaVu Sans 글꼴 범위로 보완했다.
2. 내부 빠른 넘김이 안 읽은 대사에서 멈추거나 기존 넘김을 취소하는 동작을 보완했다. 본편의 읽기 설계와 별개인 내부 시험 기능이다.
3. 지현에게 다음 날 확인을 약속한 가지에 C05의 실제 전달을 넣었다.
4. 리아 개인 만남이 없을 때 C05의 취미 소개까지 없었던 것처럼 말하던 도입을 고쳤다.
5. 리아 창가 취향을 들은 가지에서 도현의 현재 식사 선호와 혼동하던 문장을 고쳤다.
6. 수록 구간을 끝내면 바로 초기화되던 흐름을 종료 확인 선택으로 바꿔 상태·저장·결말을 확인할 수 있게 했다.
