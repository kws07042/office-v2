# 초반 C01~R04 연애 흐름 편집

2026-10-21 · Windows 0.33.0-opening-romance

## 이번에 한 작업

현재 설치본 0.32의 공통 C01~C08와 네 인물의 R01~R04를 기준으로 편집했다. 리아부터 선택별 경험과 고백을 연결하고 다른 세 인물도 같은 기준으로 확인했다. 업무 문답의 반복을 압축하고, 이미 예고한 작은 활동을 대화 중 실제로 진행했다.

새 사건·그림·음성·기억 변수·선택지는 추가하지 않았다. 기존 선택의 값과 조건, 보상, 고백/보류/거절 경로도 유지했다. 대사 선택 후 행동이 달라지는 기존 분기를 활용했다.

## 인물별 변화

| 구간 | 문제 | 반영 |
|---|---|---|
| 공통 C02 | 근거를 확인한 뒤 다시 확인하고, 업무 태도를 해설함 | 지현이 도현의 메모를 자기 자료 위에 올리는 행동으로 인정. 반대 의견을 말하는 도현과 그걸 반기는 지현으로 첫인상 정리 |
| 공통 C03 | 시안 설명을 반복하다 갑자기 사적인 질문으로 전환 | 작업 노트의 ‘이제 그만 고치기’를 도현이 봄 → 유진이 자기한테 쓴 말이라고 먼저 해명 → 유진이 동네 질문을 꺼냄. 적극성과 작은 빈틈을 함께 보여 줌 |
| 공통 C04 | 이미 보여 준 요청을 한 번 더 풀어 설명 | 답장 작성에 필요한 대사만 남김. 기존 커피 장난과 질문 차례는 보존 |
| 리아 R01 | 메뉴 내기를 제안한 뒤 식사를 지문으로 건너뜀 | 덮밥·국수를 한 입씩 바꿔 먹고, 내기 결과를 다음 식사 초대로 받아치는 장면. 조용한 자리 선택은 옆자리에 앉는 민망함, 추천 선택은 리아의 단골 장소를 알아가는 경험으로 구분 |
| 리아 R03~R04 | 기록집의 출연/사진 얘기로 관심이 샘. 고백의 근거가 일반적임 | 리아가 완성본의 첫 독자를 자청. 고백에서는 모든 경로가 실제로 겪은 입가의 거품 장난을 꺼내고, 오늘은 똑바로 보고 말하겠다고 연결 |
| 지현 R01~R04 | 식사 중에도 질문 차례를 정하는 인터뷰 느낌. R03 업무 내용이 공통과 반복 | 국수가 나오면 천천히 생각해도 된다는 응수로 여유를 만듦. 업무 복습은 메모를 붙이는 행동으로 줄임. 고백은 R02의 네 시 귀가 뒤 더 같이 있고 싶었던 마음으로 연결 |
| 유진 R03~R04 | 시안의 의도를 다시 설명하고, 고백도 작품 감상에 기대 있음 | 중복 설명을 덜고 ‘전시가 없어도 만나고 싶다’는 유진의 욕심을 직접 밝힘. 도현도 헤어진 뒤 또 불러 주길 기다렸다고 화답 |
| 서윤 R02~R04 | 기다려 주는 선택에서도 다시 취향 맞히기로 회귀. 약속의 의미를 원칙처럼 설명함 | 기다리는 동안 둘 다 책 읽는 척만 하게 되는 반응. R03은 눈앞의 표정을 궁금해한 마음으로 변경. 고백은 가져온 결과물보다 도현을 기다렸다는 말로 연결 |

## 실제 대사 예시

### 리아 — 내기를 건너뛰지 않기

이전에는 ‘각자 메뉴를 고르고 식사했다’는 지문으로 넘어갔다. 식사 선택에서는 이제 다음 대화가 실제로 나온다.

> 리아: 내 국수가 이겼지?  
> 도현: 응. 그러니까 다음에도 같이 먹어 줘야 해.  
> 리아: 이긴 사람이 또 데리고 가야 하는 거였어?  
> 도현: 지금 정했어.

존댓말 경로도 별도로 맞췄다. 이 반응은 식사 선택에만 나오고, 다른 선택에서 국수 내기를 회상하지 않는다.

### 리아 — 앞서 함께 웃은 일을 고백에 연결

> 도현: 그날 입에 거품 묻은 것도 모르고 네 얘기만 듣고 있었잖아.  
> 리아: ...오늘은 안 묻었어.  
> 도현: 응. 오늘은 똑바로 보고 말하려고.

이어서 원래의 ‘연인으로 만나고 싶다’와 교제 확인으로 진행한다. 입가의 거품은 R01의 공통 합류 장면이라 어떤 장소 선택에서도 실제로 경험한다.

### 유진 — 감상에서 만남 자체로

> 전시 다 보고 나서도 집에 가기가 아쉬웠어요. 다음엔 전시 없어도 같이 만나고 싶었고요.

### 서윤 — 준비물에서 사람으로

> 오늘은 네가 뭐 가져왔는지 안 물어볼 거야. 내가 기다린 건 너였으니까. 네 대답 듣고 싶어.

## 유지한 좋은 장면

- 리아 R02의 문 닫힌 가게에서 대안을 고르는 선택과, 업무 밖의 모습을 더 알고 싶다는 대화.
- 지현 R02의 차 마시기·산책·서점 선택별 다른 활동과 네 시 귀가.
- 유진 R02의 같은 그림에 대한 서로 다른 감상과 손잡기/나란히 걷기 선택.
- 서윤 R01의 설탕 취향 예측 실패, R02에서 도현의 직구에 잠시 말을 놓치는 반응.

## 편집자의 판단과 아직 남은 점

첫 소개에서 ‘괜찮은 동료임을 증명하는 대화’가 조금 줄고, 서로 어떤 사람인지 궁금해하는 반응이 늘었다. 리아 식사 선택은 예고한 내기를 회수하므로 선택 뒤의 보상이 전보다 구체적이다. 고백의 문구만 네 사람에게 바꿔 붙이는 대신 각자의 실제 만남에 근거를 뒀다.

다만 이것은 편집자의 판단이다. 처음 읽는 플레이어의 재미·설렘·중도 이탈은 측정하지 않았다. 자동 진행 시간도 실제 독서 시간으로 쓰지 않는다. 기존 목표인 고백까지 60~90분에 도달했다고 판단하지 않는다.

서윤 R03은 사진·문장 감상이 여전히 긴 편이다. 유진의 업무 지원 이야기와 도현의 기록집도 전체 작품에서 비중이 남아 있다. 이번에는 초반 리듬을 다듬었으며 소재 전체를 바꾸지는 않았다. 실제 독서에서 이 구간이 다시 늘어진다면 설명 문장 추가보다 감상 대화 자체를 더 줄이는 편이 낫다.

리아 첫 경험, 지현 사적 성향, 유진 관계 불안, 서윤 기혼·배우자 동거 등 현재 설정은 유지했다. 친밀한 본장면 자리 표시와 자산은 수정하지 않았다.
