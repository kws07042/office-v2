일반 대화에서 리아 상반신·낮/밤 임시 배경·세 선택지·긴 대사·다른 인물일 때 리아 숨김·저장/복원·기록/설정 복귀를 확인했다. 기존32개 새 선택을 두 말투 상태에서 누르고 실제 대사 출력까지 확인했다. 전용 이미지 자리와 표정 타이머의 저장·복원, 진행/보류·동료 결말·관계 정리·의상 대안·후일담 생략 등을 포함한8개 전체 경로도 통과했다.

1280×720 게임 화면의 낮·밤·선택지·긴 대사·메뉴 스크린샷을 직접 확인했다. 정수리와 얼굴이 대사창 밖에 보이고 선택지와 이름표 사이에 간격을 두었다. 이 결과는 모든 실제 모니터·해상도·이전 버전 저장의 검증을 뜻하지 않는다.

초기 화면 검사는 배치 확인 버튼에 남은 키보드 초점 때문에 검사 도구가 같은 밤 장면을 반복하는 문제가 있었다. 검사 도구의 포인터를 대화 영역으로 옮겨 정상 대화 진행을 확인했다. 배치 확인 도구와 선택지의 겹침은 도구를 왼쪽 위 작은 가로줄로 바꿔 해결했다. 최종 성공 횟수에 초기 실패나 같은 검사의 반복 실행을 합산하지 않았다.

원본 리아 그림의 픽셀·알파·파일 해시는 변경하지 않았다. 손은 기본 대화 표시 영역에 나오지 않으므로 손 디테일 검수 완료로 표시하지 않는다. 원본의 귀걸이·귀 주변 가장자리와 상단 경계, 한 가지 표정만 연결된 상태는 최종 이미지 검수 과제로 남긴다. 최종 배경·그림·음성·폰 UI·CG 전용 UI의 완성을 검증한 것은 아니다.
