이 결과는 감염 부재, 계정 안전, 과거 침해와 무관함을 증명하지 않는다. 바이너리, 난독화된 구현, 과거에 제거된 정보 등은 이 결과로 배제할 수 없다.

### 2. 배포 바이너리의 출처/대응 소스는 추가 확인 필요
Windows/에는 EXE 5개, DLL 7개, pyc 839개, rpyc 90개, rpymc 25개(합계 966개)가 있다. 개수에는 Ren'Py/번들 Python 파일이 포함된다. 바이너리가 있다는 사실 자체가 악성 지표는 아니다.

Windows/game은 컴파일된 rpyc를 사용한다. Source/game 텍스트와 배포 rpyc의 실제 대응 관계는 확인하지 못했다. 실행 파일·DLL·pyc 및 rpymc도 이번 검사에서 검증하지 않았다. 현재 Windows 빌드를 안전한 기준본으로 인증하지 않는다. 공식 SDK에서 검토한 소스를 새로 빌드하고 배포 파일 해시와 보안 제품 검사 결과를 남기는 것이 후속 조치다.

### 5. 제작 도구는 신뢰된 로컬 코드 실행/쓰기 권한을 가짐
예: Source/tools/prepare_click_interest.py:13-14는 로컬 제작 스크립트 일부를 exec(compile(...))로 실행한다. Source/tools/install_dialogue_style.py는 바탕화면의 별도 설치본에 파일을 쓴다. 해시/경로 검사와 백업이 있지만 입력과 해시 자료가 함께 변조되는 경우 진위를 보장하지 못한다. Source/tools/run_revision_tests.ps1:19는 지정된 실행 파일을 시작한다.

외부 입력을 직접 실행하는 네트워크 서비스는 발견하지 못했다. 현재 발견 내용은 도구를 실행하는 개발자가 입력 출처와 대상 경로를 확인해야 한다는 신뢰 경계다. 기존 도구를 실행하거나 수정하지 않았다. rpy 테스트의 assert eval/if eval 표기는 Ren'Py 테스트 문법도 포함하므로 문자열 검색 결과만으로 Python eval 취약점이라고 판정하지 않았다.
