## 1. 대표 선택의 공통 사양

취향 분기마다 숨은 정답 점수를 만들지 않는다. 기억과 표현은 달라도 취향 선택 자체의 기본 진행 보상은 같은 기준으로 집필한다. 약속 이행과 핵심 갈등의 실제 결과는 별도 신뢰·사건 규칙을 따른다. 대표 선택은 각 루트 3개를 우선 연결하고 가까운·후반 회수로 기존 최소 6회 기억 회수 기준을 맞춘다.

## 3. 지현 — R02의 계획 방식

**A: 도현이 먼저 구체적으로 제안한다.** 도현이 가까운 식사와 짧은 산책을 제안하고 가능한 시간을 확인한다.

도현: “밥 먹고 조금 걸을까? 오늘 네가 편한 시간 안에서.”

지현: “이미 코스를 생각해 둔 거야?”

도현: “같이 가고 싶은 건 생각해 뒀지. 시간은 네 얘기 듣고 정하려고.”

지현: “좋아. 그럼 오늘은 네 제안으로 가자.”

기억은 ‘먼저 제안하고 시간을 확인함’이다. 상대 일정 전체를 대신 결정했다는 기록이 아니다.

**B: 둘이 후보를 좁힌다.** 메뉴·분위기가 다른 두 후보를 두고 지현이 원하는 부분과 도현의 취향을 합쳐 고른다.

도현: “후보 둘만 골라 봤어. 난 이쪽이 좋은데, 넌?”

지현: “이쪽은 조용해서 마음에 드네.”

도현: “그럼 오늘은 거기 가자. 다음엔 내가 좋아하는 쪽도 같이 가고.”

지현: “좋아. 다음 약속까지 같이 정했네.”

기억은 ‘서로 취향을 말하고 공동으로 정함’이다. 도현이 모든 결정을 지현에게 맡겼다는 기록이 아니다.

합류: 함께 시간을 보내며 지현이 계획 일부를 맡기는 경험을 확인한다. R05에서는 A일 때 지현이 가능한 시간과 원하는 분위기를 말하고 제안을 기다리며, B일 때 둘이 각 후보를 하나씩 가져온다. R10에서는 A의 제안 방식과 B의 공동 선택 방식을 취미의 작업 순서에 짧게 회수한다. 맡기는 방식이 다른 것일 뿐 어느 쪽도 열등한 선택이 아니다.

## 4. 유진 — R02의 전시 코스

**A: 유진이 준비한 코스를 따라간다.** 유진이 보여주고 싶은 첫 작품 앞에 멈춰 직접 설명한다.

도현: “오늘은 네가 보여주고 싶은 순서로 볼게.”

유진: “그럼 여기부터요. 이 작품은 도현 씨한테도 보여주고 싶었어요.”

도현: “어느 부분에서 내 생각이 났는데?”

유진: “그건…… 작품부터 보고 말해도 돼요?”

기억은 유진이 고른 실제 첫 작품과 그 이유다. 최종 작품 소재가 정해지기 전 후반 대사에서 색·내용을 지어내지 않는다.

**B: 서로 보고 싶은 작품을 넣어 조정한다.** 유진의 준비를 바탕으로 도현이 궁금한 작품 하나를 추가한다.

도현: “네가 고른 것부터 보고, 이것도 같이 보고 싶어. 괜찮아?”

유진: “좋아요. 대신 보고 나서 뭐가 마음에 들었는지 알려 주세요.”

도현: “너도 알려줘. 같은 걸 봐도 다르게 기억할 것 같아서.”

유진: “그러면 오늘 코스는 둘이 고른 걸로 해요.”

기억은 도현이 실제 추가한 작품과 서로 말한 감상이다.

합류: 준비한 데이트에서 수줍음과 분명한 취향을 확인한다. R05에서는 A일 때 유진이 새 코스를 먼저 제안하고 도현이 자기 선호를 덧붙인다. B일 때 두 사람이 보고 싶은 후보를 하나씩 정한다. R10의 노트·티켓에서는 실제 함께 본 작품과 당시의 질문·감상만 회수한다. 좋아하지 않은 작품을 선택했다고 유진의 호감을 자동으로 낮추지 않는다.

## 5. 서윤 — R02의 망설이는 답

**A: 답을 기다린다.** 서윤이 개인적인 질문에 말을 고르는 동안 도현은 자리를 지키고 자기 관심은 숨기지 않는다.

서윤: “그걸 지금 물어보는 거야?”

도현: “응. 궁금해서. 지금 바로 답하지 않아도 괜찮아.”

서윤: “기다려 주면서도 물러나진 않네.”

도현: “내가 궁금한 건 네 답이니까.”

기억은 답변을 기다리겠다는 말과 그때 실제 답한 범위다. 기다림을 무관심이나 준비되지 않은 연애로 자동 판정하지 않는다.

**B: 도현이 자기 생각부터 말한다.** 도현은 왜 둘이 따로 만나고 싶은지 짧고 직접적으로 말한다.

도현: “그럼 나부터 말할게. 오늘은 네가 어떤 데서 쉬는지 궁금했어.”

서윤: “누나 취향 조사?”

도현: “같이 오고 싶은 데를 알고 싶어서.”

서윤: “……그렇게 말하면 내가 농담만 하긴 어렵잖아.”

기억은 도현이 먼저 드러낸 관심과 서윤의 실제 답이다. 진지한 관심을 아직 교제하지 않은 상대에 대한 일방적인 약속으로 기록하지 않는다.

합류: 농담 뒤의 진심을 알아가는 대화로 이어진다. R03에서는 A일 때 서윤이 미뤘던 답을 자발적으로 잇고, B일 때 도현이 말했던 관심을 기억한 실제 다음 약속을 제안한다. R10의 책 소개는 그 답·취향과 연결한다. 공통 서점이나 카페 배경을 재사용하되 기다림과 자기 노출의 차이를 잊지 않는다.

## 6. 데이터·집필 기록

대표 선택마다 선택 인물·사건 ID·선택 ID·즉시 장면·계획과 실제 행동·합류 지점·가까운 회수·후반 회수·기억 없을 때 대체 대사를 기록한다. 구현용 가지 ID는 기존 사건 안에 둔다. 별도 기본 사건 수로 집계하지 않는다.

과거 사건 기억과 현재 선호를 분리한다. 다음에 다른 장소·말투를 원하면 새 선택을 기록하되 첫날 실제 행동을 지우지 않는다. 계획한 곳이 닫혔다면 가려던 곳과 실제 방문한 곳을 각각 기록한다. 합류 후 장소명이나 소품이 다른 가지의 값으로 남지 않게 확인한다.

한 장면에서 여러 기억이 걸리면 인물의 현재 질문과 가장 가까운 기억을 우선한다. 리아 R01의 합류 구간은 C06·C07의 사적 화제가 있으면 그중 실제 대화한 하나, 없으면 C01의 접근 방식을 회수한다. 모두 한꺼번에 길게 출력하지 않는다.

## 7. 말투·검증

R04의 고백 주도는 리아·지현 루트에서 도현, 유진·서윤 루트에서 히로인이다. 도현이 먼저인 루트는 의사 선택 뒤 고백 가지로, 히로인이 먼저인 루트는 고백을 들은 뒤 응답 선택으로 구성한다. 어떤 경우에도 준비 대화만으로 교제 상태를 기록하지 않는다. 첫 연애인 유진도 먼저 고백하고 원하는 데이트를 제안할 수 있다. 경험의 차이는 말투와 작은 반응에 반영하며 숨은 정답이나 호감도 보너스로 만들지 않는다.

R01·R02의 먼저 제안하고 받아치는 대사는 첫 연애 설정과 양립한다. 연애 경험이 없어도 사람을 대하는 유머와 자기 의견은 있을 수 있다. 교제 이후의 가지에는 작은 망설임과 자기 표현을 함께 두되 히로인이 모든 진행을 대신하지 않게 한다. 첫 연애가 모든 실수의 이유나 책임 회피 대사가 되지 않는지, 초반의 작은 서툼이 후반의 실제 행동으로 달라지는지도 확인한다.

위 대사 초안은 리아·지현·서윤의 편한 대화와 유진의 존댓말을 기준으로 작성했다. 리아·도현의 존댓말 경로에는 대사별 자연스러운 별도 표현을 작성한다. 기계적인 어미 치환만으로 호칭·뜻이 맞는다고 보지 않는다. 리아 초반 대본의 새 가지에도 같은 기준을 적용한다.

모든 가지에서 행동이 실제 달라지는지, 합류 뒤 위치·컵·책·메뉴가 맞는지, 가까운 회수와 후반 회수가 같은 경험을 가리키는지 확인한다. 다른 히로인·기억 없는 경로·현재 선호 변경·저장과 되돌리기·회상에서 결과가 섞이지 않아야 한다. 반복 열람으로 호감도나 신뢰를 중복 적용하지 않는다.

이 명세의 시간 목표와 대사 품질은 실제 읽기·플레이테스트로 검증해야 한다. 현재는 대표 사례를 구체화한 상태이며 세 대표 선택씩을 포함한 전체 루트 대본 완성을 뜻하지 않는다.

## 8. R04 준비 대화와 같은 장면 안의 재선택

사용자 확정: 준비 대화는 같은 R04 안에서 걱정·원하는 관계를 나눈 뒤 다시 선택한다. 다음 날의 교제 전 R05 가지는 만들지 않는다. 준비 대화 자체는 약 2~4분의 집필 가설이며 실제 읽기 전이다. 기존 R04 배경·표정·CG를 사용하고 별도 사건·CG로 집계하지 않는다.

| 시작 경로 | 중간 행동 | 최종 관계 상태·이동 |
|---|---|---|
| 도현이 먼저인 루트에서 교제 의사 선택 | 도현의 고백, 히로인의 명시적 응답 | 상호 동의 뒤 교제 확정 → R04 공동 마무리 → R05 |
| 히로인이 먼저인 루트에서 교제 의사 선택 | 고백을 들은 도현의 명시적 응답 | 상호 동의 뒤 같은 공동 마무리 → R05 |
| 어느 루트든 준비 대화 선택 | 두 사람이 원하는 관계를 이야기하고 재선택 | 이 단계에서는 교제 미확정 |
| 준비 후 교제 의사 선택 | 루트별 고백 주도를 유지해 서로 답함 | 교제 확정 → 같은 공동 마무리 → R05 |
| 처음 또는 재선택에서 명확히 동료 관계 선택 | 상대가 의사를 받아들이고 동료로 지낼 뜻을 확인 | 교제 시작 안 함 → 기존 END_COMMON |

준비 대화는 인물마다 다른 질문·답·현재의 바람으로 쓴다. 아래는 분위기를 확인하는 짧은 대사 초안이며 전체 R04 대본은 아니다.

| 인물 | 히로인의 말 | 도현의 자기 표현 |
|---|---|---|
| 리아 | “재밌는 날만 같이 있고 싶은 건 아니야. 아무것도 안 하는 날에도 너랑 있고 싶어.” | “나도 그래. 연애는 처음이라 말이 좀 늦을 수는 있는데, 보고 싶으면 먼저 말할게.” |
| 지현 | “회사에서의 판단이랑 지금 내 대답은 따로야. 사적으로 원하는 것도 내가 직접 말할게.” | “나도 내 의견을 말할게. 일 얘기 말고 너를 더 알고 싶은 마음이 있어.” |
| 유진 | “저도 처음이에요. 그래도 만나고 싶다는 말은 제가 먼저 해도 되죠?” | “그럼요. 저도 처음이라 조금 어색한데, 다음 약속은 제가 제안하고 싶어요.” |
| 서윤 | “내가 농담을 많이 했지. 이번에는 대답을 농담으로 피하지 않을게. 네 생각도 듣고 싶어.” | “나도 좋다는 말을 장난으로 넘기고 싶지는 않아. 내 마음부터 제대로 말할게.” |

마지막 선택은 교제를 명시적으로 제안·수락하는 문장과 ‘이번 회차는 연애를 시작하지 않고 동료로 지낸다 — 동료 결말로 이어짐’으로 구분한다. 일시적인 망설임처럼 보이는 선택지로 결말을 확정하지 않는다. 결정 전 저장·로그 확인과 시간 제한 없는 선택을 지원한다. 동료를 선택한 뒤에는 조용한 확인 대화로 의도를 한 번 확인하는 기존 큰 결정 기준을 적용한다.

기록 항목은 인물별 교제 상태, 준비 대화 진행 여부, 실제 고백자·고백을 들었는지, 실제 교제 확인 시점, R04 보상 적용 여부다. 도현이 고백 전 준비를 고른 것을 ‘도현의 고백을 이미 들었다’로 기록하지 않는다. 준비 대화 전후로 같은 교제 보상을 두 번 지급하지 않는다. 동료 경로에는 준비 대화 벌점·친밀한 장면 미해금 벌점을 부여하지 않는다.

확인할 경로: 도현이 먼저/히로인이 먼저 각각 직접 교제, 준비 후 교제, 직접 동료, 준비 후 동료를 확인한다. 교제 미확정 상태에서는 R05의 연인 대사가 나오지 않아야 한다. 준비 가지를 되돌려 다시 읽거나 회상해도 호감도·신뢰·교제 기록이 중복되거나 현재 회차에 남지 않아야 한다. END_COMMON의 도입은 실제 대화 기억만 회수한다. 현재는 명세이며 실행 검증 결과가 아니다.

## 9. 썸 단계의 애정 표현 — 리아 R02 샘플

통합 기획서 v2.23의 35절을 따른다. 사건 95개 안의 기존 R02에 들어갈 짧은 대사 초안으로, 전체 R02와 R03~R04는 아직 작성해야 한다. 손잡기와 나란히 걷기는 같은 기본 진행 보상을 가지며 실제 행동과 회수 대사만 다르다. 그림을 새로 생성하거나 기존 리아 이미지를 연결하지 않는다.

상황: 예약하려던 가게가 닫혀 있다. 둘이 다음 후보를 정하고 그곳으로 걷는다. 새 장소는 R02의 실제 대체 계획에 맞춰 연결한다.

리아: “준비한 코스가 문 앞에서 끝났네.”

도현: “문 앞 구경은 여기까지 하고, 대안 같이 찾아보자.”

리아: “좋아. 저 골목에 간단히 먹을 수 있는 카페 있어. 일단 걸어 볼래?”

**선택 A — 손을 내밀며 함께 걷고 싶다고 말한다.**

도현: “같이 걸을 때 손도 잡고 싶은데, 괜찮아?”

리아: “길은 나도 아는데?”

도현: “길 안내하려는 건 아니고.”

리아: “알아. 그냥 네 입으로 한 번 더 듣고 싶어서.”

리아가 내민 손을 잡고 걸음을 맞춘다. 장난을 받아친 뒤 잠깐 시선을 피하지만 손은 놓지 않는다. 도현의 손·몸을 그림에 추가하지 않고 대사와 리아의 반응으로 표현한다.

**선택 B — 나란히 걸으며 더 이야기하고 싶다고 말한다.**

v2.60의 사용자 선택에 따라 아래 비교 부분은 1안으로 대체한다. 앞뒤 흐름은 연결 대본 초안에서 함께 검토하며 이 선택을 다른 히로인의 공통 말투로 확장하지 않는다.

리아: “그럼 이번 코스는 어디부터야? 완벽한 계획 말고.”

도현: “일단 저쪽까지 걸어 보자. 걷다가 괜찮은 데가 보이면 들어가고.”

리아: “나보다 계획이 없네.”

도현: “오늘은 네가 퇴근하면 어떤 사람인지 좀 더 알고 싶어서.”

리아: “회사에서 보는 거랑 많이 다르면?”

도현: “그럼 내가 아는 네가 하나 더 생기는 거지.”

리아가 다음 말을 고르다 웃는다.

리아: “……좋아. 대신 네 얘기도 하나씩. 나만 취재당하는 건 싫어.”

도현: “응. 질문 하나씩 번갈아 하자.”

합류: 이동 중 평소의 저녁 습관을 짧게 주고받고 선택한 대체 장소에 도착한다. A의 접촉도 B의 자기 이야기도 사적인 관심을 보여주되 아직 교제를 확정하지 않는다. B를 ‘손을 못 잡아 실패한 선택’으로 연출하지 않는다. 반말 예시는 현재 검토용이며 존댓말 경로는 단순 어미 치환 없이 별도 집필한다.

기록: 인물·사건·실제 손잡기 발생 여부와 실제로 들은 저녁 습관을 구분한다. R03에는 A일 때 함께 걸었던 감각을 짧게 언급하고, B일 때 실제 들은 습관을 기억한 제안으로 회수한다. R06에서는 당시 선택을 현재 선호로 단정하지 않고 지금 편한 표현을 서로 말한다. 과거 기억이 없는 경우에는 그날 손을 잡았다고 추정하지 않고 현재 바람을 새로 묻는다.

검토 판단: A는 장난으로 대담함을 감추는 리아와 적극적이지만 긴장하는 도현을 함께 보여준다. B는 개인 생활을 알아가는 대화로 다른 보상을 준다. 도현의 마지막 칭찬이 반복되면 대사가 능숙한 작업 멘트처럼 들릴 수 있으므로 전체 R02를 쓸 때 직전 대사와 비교해 자연스러운 문장으로 수정한다. 이 샘플의 승인이나 완성도는 자동 확정하지 않는다.

## 10. 한 화제만 고르는 대화

통합 기획서 v2.24를 따른다. 화제를 하나 골라 발언한 뒤 해당 짧은 대화와 필요한 후속 표현을 진행하고 필수 공통 정보로 합류한다. 같은 대화의 화제 메뉴로 돌아가 나머지를 전부 읽지는 않는다. 선택 취소는 실제 발언 전까지이며 발언 이후의 되돌리기는 기존 저장·롤백 상태 복원으로 처리한다.

각 가지에 실제 선택 화제·공통으로 전달할 필수 정보·가지에서만 알게 되는 정보·즉시 행동·다음 반응·기억 회수·합류 위치를 기록한다. 공통 정보와 가지별 정보를 섞지 않으며 미선택 화제의 기억은 생성하지 않는다. 개인 정보가 없을 때의 후속 대사는 이미 알고 있는 척하지 않고 지금 묻거나 상대가 새로 말하게 쓴다.

예를 들어 지현의 사적인 저녁에서 어느 화제를 골라도 업무 지시가 아닌 개인적인 만남이라는 사실과 다음 약속을 안다. 휴일 취향 화제만 골랐다면 그때 실제 들은 취미를 회수하고, 직접적인 관심 화제만 골랐다면 당시 망설임과 답을 이어가는 메시지를 회수한다. 둘을 모두 이야기했다고 처리하지 않는다.

확인 기준은 각 가지에서 필수 정보가 전달되는지, 선택별 사적 정보·행동은 실제로 다른지, 한 화제를 읽은 뒤 추가 화제 선택을 강요하지 않는지, 기억 없는 경로의 대사가 맞는지다. 대표 선택 3개의 기억 회수와 겹치면 같은 대사를 중복 출력하지 않는다. 메뉴 선택과 후속 선택은 사건의 주요 선택 수에 포함한다. 아직 게임 실행 검증을 마친 상태는 아니다.

## 11. 첫 입맞춤의 발생·미룸

집필 기본 위치는 리아·서윤 R04, 지현·유진 R05다. 인물별 시점을 다르게 한다는 방향은 사용자 확정이고 개별 배정은 어시스턴트 초안이다. 교제 확인을 마친 사적인 만남에서만 제안하고, 진행과 오늘은 대화·다른 인사로 마무리하는 가지를 둔다. 두 가지는 같은 교제 상태·기본 사건 보상으로 합류한다.

인물별 최초 제안 위치와 실제 첫 발생 위치를 구분한다. 미룬 경우에는 다음 R05 또는 R06의 기존 표현 대화에서 플레이어가 원할 때 다시 제안할 수 있으나 자동 발생시키지 않는다. 계속 미뤘다면 실제 첫 발생 위치는 비어 있다. 손잡기·포옹의 기억이 첫 입맞춤의 발생 기록으로 대체되지 않으며 첫 입맞춤의 여부가 R07 진행 조건을 잠그지 않는다.

리아 R04의 현행 연결 대본에서는 메뉴의 입맞춤 경로를 골랐을 때만 도현이 실제 제안을 말한다. 대화를 고른 경로는 ‘오늘 대화로 마무리’이며 제안·수락·발생 기록이 모두 없다. 메뉴 표시·실제 구두 제안·제안 후 미룸을 별도 사실로 관리한다.

후속 대사는 ‘그날의 실제 입맞춤’, ‘입맞춤을 제안했지만 대화로 마무리’, ‘제안·발생 기억 없음’을 구분한다. 저장·되돌리기·회상은 현재 회차의 발생 기억을 오염시키지 않아야 한다. 텍스트·히로인 표정·기존 R04 CG로 연출하며 도현의 신체나 새 CG를 추가하지 않는다. 실제 이미지 작업은 진행하지 않는다.

## 12. 독백과 후일담 계획의 정합성

통합 기획서 v2.25를 따른다. 독백은 긴장·설렘의 순간에 짧은 1인칭으로 쓰며 실제 선택과 맞아야 한다. 입맞춤을 미뤘는데 이미 했다는 독백을 쓰거나 다른 화제의 개인 정보를 이미 아는 것처럼 해설하지 않는다. 상대의 내면을 정답으로 단정하지 않는다.

후일담은 리아의 편안한 일상·지현의 동거 논의·유진의 장기 교제 약속·서윤의 함께 살 준비로 기본 표현을 구분한다. 이는 인물별 집필 기본값이며 플레이어 의사 없이 이미 입주가 확정된 것으로 처리하지 않는다. 각자 살기를 원하는 대안도 같은 E01 안의 안정된 교제·구체적인 만남 약속으로 이어질 수 있다. 계획·합의·실제 실행은 서로 다른 기록이다.

R10의 실제 취향·R14의 수습 행동·R15의 미래 약속 중 현재 장면과 가까운 기억을 회수한다. 친밀한 장면 발생·횟수를 장래 약속의 조건으로 삼지 않는다. 같은 E01 내부 변형으로 작성하며 새 엔딩·CG·배경을 추가하지 않는다. 현재는 상태·집필 명세이며 전체 E01의 실제 대본·게임 코드는 아니다.

## 13. 유진 R09 → R12 → R13·R14의 지원 기억

통합 기획서 v2.26의 38절을 따른다. R09의 지원 선택을 실제 행동·반응으로 보여주고 이후 갈등의 계기에 연결한다. 지원 행동·당시 합의 범위·범위를 넘겼는지·현재 수습 상태는 분리한다. 명확히 부탁받은 요약과 동의 없이 대신 설명한 행동을 같은 위반으로 분류하지 않는다.

**A — 유진이 설명하고 나는 자료·시간을 챙긴다.** 자료 화면·질문 순서를 준비하고 유진이 핵심 의도를 말한다. 도현은 합의한 부분만 돕는다.

도현: “설명은 유진 씨가 해요. 필요한 자료는 제가 맞춰 둘게요.”

유진: “네. 질문이 겹치면 순서만 정리해 주세요. 제 생각은 제가 말하고 싶어요.”

**B — 내가 먼저 설명을 시작해 부담을 덜어 준다.** 동의 범위를 묻기 전에 도현이 핵심 요약을 꺼내고 유진이 자신의 설명 순서를 요청하는 실제 장면을 보여준다. 이어 유진도 자신의 의도를 설명하며 발표 자체를 빼앗긴 인물로 만들지 않는다.

도현: “제가 핵심부터 먼저 말씀드릴게요.”

유진: “도현 씨, 그 부분도 제가 설명하려고 했어요. 이어서 말해도 될까요?”

위 대사는 의도·반응을 확인하는 짧은 초안이다. 실제 R09에서 유진이 먼저 부탁한 경로가 있다면 그 합의에 맞춰 행동과 기록을 달리한다. 지원 선택을 장소 취향처럼 동일한 관계 효과를 가지는 가지로 자동 분류하지 않고, 실제 합의 위반이 있을 때만 신뢰·갈등 규칙을 적용한다. 점수 변화량은 아직 시험 전이다.

R12에서는 지난 실제 지원과 현재 원하는 방식을 짧게 회수한다. R13에서는 존중한 경로에 새 실수를 강제하지 않고 기존 업무 상황에서 필요한 지원 범위를 조율한다. 아직 미해결인 대신 설명 경로는 해당 행동의 수습을 다룬다. 이미 확인·수습한 기록이 있으면 문제를 다시 미해결로 만들지 않는다. 기억이 없는 경우 현재 원하는 도움을 먼저 묻는다.

R14는 자료·시간·발언 순서에서 합의한 지원을 실제 실행하는 공통 핵심으로 합류한다. 조율 경로에 하지 않은 잘못의 사과를 출력하지 않고, 위반 경로에 행동 확인 없이 자동 용서를 출력하지 않는다. R15·E01도 실제 조율 또는 수습 행동을 회수한다. 동일한 위반을 재독·회상·새 사건 진입만으로 반복 감점하지 않는다.

핵심 구간의 음성은 고정된 히로인 줄만 연결한다. 도현의 대사·독백은 텍스트이며 파일이 없으면 로그 음성 재생 버튼도 표시하지 않는다. 각 분기의 실제 읽기·음성·상태 복원 검증은 구현 단계다.

## 14. R14의 추가 확인과 만회

통합 기획서 v2.27을 따른다. R13의 실제 서툰 대응과 상대 반응을 기록한 경로에는 같은 R14 안에서 원하는 방식을 다시 묻고 자기 생각을 말하는 확인 가지를 둔다. 이 대화 뒤 기존 인물별 수습 행동으로 합류한다. 조율·확인·실제 행동을 마친 경우 처음부터 잘 대응한 경로처럼 좋은 결말에 도달할 수 있다. 숨은 영구 실패 기록을 남기지 않는다.

확인 대사와 수정 행동은 실제 문제를 따른다. 유진의 조율 경로에는 하지 않은 잘못을 사과시키지 않고 미해결 위반 경로에는 행동 확인 없이 용서를 자동 처리하지 않는다. 과거 실수가 이미 해결됐으면 중복 확인·감점을 붙이지 않는다. 취향·애정 표현·친밀한 장면 미룸은 이 확인 가지의 발생 원인이 아니다.

확인할 경로는 처음부터 이해한 경로, 한 번 서툰 대응 뒤 확인·행동으로 수정한 경로, 과거 문제가 이미 해결된 경로, 해당 기억이 없는 경로다. 대사·갈등 상태·R15 이후의 기억 회수가 실제 기록과 맞는지 확인한다. 현재는 명세이며 실행 검증 결과는 아니다.

## 15. R11 공동 활동의 짧은 가지와 회수

통합 기획서 v2.28의 40절을 따른다. 공동 활동 중심은 사용자 확정이다. 세부 메뉴·놀이 방식·곡 분위기·길은 집필 기본값으로 관리하고 실제 대본에서 확정한 정보만 기록한다. 기존 사건 안의 짧은 가지이며 전용 CG·미니게임을 추가하지 않는다.

| 인물 | 즉시 가지 | R12의 가까운 회수 | E01의 나중 회수 |
|---|---|---|---|
| 리아 | 추천 파스타를 자기 취향으로 조정 / 도현 제안 덮밥을 함께 준비. 재료·간 보기·정리의 실제 대화와 행동을 달리 씀 | 그날 실제 함께 먹은 메뉴와 지금 먹고 싶은 것을 구분 | 편하게 다시 해 먹거나 다른 메뉴를 함께 고르는 약속 |
| 지현 | 진지한 대결 / 협동 라운드. 상대의 수를 읽는 행동과 함께 해결할 수를 제안하는 행동을 달리 씀 | 실제 놀이 방식에 맞는 재대결 또는 다음 협동 제안 | 그날의 장난·협력 기억을 다음 휴일 계획에 짧게 연결 |
| 유진 | 유진 추천 / 도현 추천을 중심으로 실제로 들은 분위기와 듣는 상황을 나눔 | 실제 들은 추천만 회수. 다른 추천의 정보를 이미 안다고 가정하지 않음 | 여행·전시 계획에서 그때의 취향을 회수하거나 지금 선호를 새로 묻기 |
| 서윤 | 익숙한 길에서 평소 취향을 알아감 / 함께 다른 길을 고르고 머무를 곳을 제안 | 계획한 길과 실제 걸었던 길을 구분해 회수 | 구체적인 다음 산책 약속에 실제 기억을 연결 |

활동 선호·승패에 숨은 정답 보상을 붙이지 않는다. 주요 활동 선택과 기존 친밀한 전환 진행·미룸은 별도이며, 전환을 미뤄도 같은 활동 기억이 유지된다. R11 끝에는 각자의 이후 일정과 연락 약속이 남는다. 추가 화제 메뉴·가짜 게임 규칙·전용 음원을 요구하지 않는다.

확인할 내용은 각 가지에서 행동이 실제 다른지, 합류 뒤 음식·소품·장소가 일치하는지, R12와 E01이 같은 기록을 회수하는지다. 기록이 없으면 현재 제안·질문으로 대체하고 모든 과거 기억을 한꺼번에 길게 나열하지 않는다. 현재는 분기·회수 명세이며 전체 대본·읽기 시간·게임 실행 검증은 아직 하지 않았다.
