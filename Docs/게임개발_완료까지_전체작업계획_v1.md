- 보강된 C01~C08과 리아 R01~R04를 실제로 읽으며 첫인상, 선택할 이유, 썸과 교제의 구분을 확인한다.
- 업무 설명·반복 독백·비슷한 장난을 줄이고, 선택한 행동이 다음 반응으로 이어지는지 확인한다.
- C08은 다음 만남의 상대 선택, R04는 상호 교제 확인으로 유지한다.
- 공통 36~48분·첫 R04 진입 60~90분은 집필 목표다. 자동 넘김 시간을 읽기 시간으로 쓰지 않는다.

완료 기준: 초반의 대사·선택·기억 흐름이 연결되고, 실제 읽기에서 고쳐야 할 반복·급전개를 정리한 검토본이 있다.

### 2단계 — 리아 한 루트를 끝까지 연결

- R05~R08: 연인으로서 달라진 말투·약속·애정 표현과 함께 쉬는 시간을 쓴다.
- R09~R12: 일상·취미·공개 여부·연락 기대를 실제 선택과 연결한다.
- R13~R16: 갈등의 계기, 사과, 행동으로 확인하는 수습, 미래 선택을 완성한다.
- E01과 선택 일상 3개를 연결하고 도현의 기록집·초반 취향을 실제 기억에 맞게 회수한다.
- 관련 공통 업무 사건을 필요한 지점에 연결한다. 새 사건을 임의로 추가하지 않는다.
- 진행·미룸·미경험·존댓말 경로의 대체 대사를 함께 작성한다.

완료 기준: 처음부터 리아 결말·후일담까지 막힘없이 읽을 수 있고, 지나지 않은 사건을 회상하지 않는다. 그림이 없는 상태는 대본 완성으로만 기록한다.

### 3단계 — 공통 시스템과 정식 UI 구현

리아 전체 대본 작업과 조정 가능한 부분은 함께 진행하되, 구현 기준은 한 루트에서 먼저 확인한다.

- UI: 시작·대사·이름표·선택·저장/불러오기·설정·로그·관계 상세·감상·도움말을 Ren’Py 화면으로 구현한다.
- 디자인: 오피스 라운드의 넓은 배치와 부드러운 모에 분위기를 유지한다. 시안에서 선택된 크림 라운드를 작업 출발점으로 삼되 실제 그림과 읽기 면을 조합해 마무리한다.
- 호감도: 기본 5칸 하트와 관계 단계, 상세 수치 옵션. 관계 단계는 점수만으로 자동 변경하지 않는다.
- 기억: 사건 완료·실제 선택·약속/실행·교제·공개·갈등 수습을 분리한다. 재열람·되돌리기로 보상이 중복되지 않게 한다.
- 읽기 편의: 자동 진행·읽은 대사 스킵·되돌리기·글자 속도·음량·창/전체화면·효과 줄이기·처음 한 번의 짧은 안내를 정리한다.
- 저장: 수동·빠른 저장/불러오기·자동 저장의 역할과 화면을 정하고 본편 상태 전체를 복원한다. 슬롯 수는 UI에서 필요한 범위로 정한다.
- 감상/새 회차: CG·장면 해금, C08 뒤 빠른 새 회차, 읽지 않은 개인 만남의 핵심 대화를 연결한다. 감상은 현재 회차의 연애 상태를 바꾸지 않는다.
- 저장 데이터 버전을 기록하고, 기존 시험판 저장을 지원할 수 있는 범위와 새 회차가 필요한 변경을 명시한다.

완료 기준: 웹 시안이 아니라 실제 Windows 게임에서 마우스·키보드로 조작할 수 있고, 저장·복원·새 회차로 상태가 섞이지 않는다.

### 4단계 — 메신저를 본편과 연결

- 연락처·개인 채팅·답장 선택·사진 썸네일/확대·대화 기록을 구현한다.
- 중요한 대화는 본편에서 자동 표시하고 실제 읽기·답장 완료 뒤 다음 사건으로 진행한다.
- 의미 있는 답장에만 짧은 입력 중 표시를 넣는다. 클릭·스킵으로 기다림을 줄일 수 있고 실제 대기 시간 벌점은 없다.
- 하트·스마일 등은 인물별 말투와 관계에 맞춰 사용하고, 사용한 자산의 허용 조건·고지를 관리한다.
- 선택 루트 외의 인물은 정해진 업무·공통 모임·공개 축하 연락으로 제한한다.
- 수신·읽음·답장·확대 열람·영구 해금을 각각 저장한다. 아직 받지 않은 사진이나 다른 회차의 연락이 나타나지 않게 한다.

완료 기준: 리아의 실제 본편 메시지를 읽고 답하고 확대하고 다시 열 수 있으며, 도중 저장·불러오기·되돌리기에서도 대화와 기억이 맞는다.

### 5단계 — 정식 자산과 소리를 넣은 대표 구간 완성

- 실제 필요한 입상·표정·배경·CG·메시지 사진·음성·음악을 사건 ID에 연결하는 자산 목록을 만든다.
- 리아는 사용자가 새로 제공할 자산을 기다린다. 이전 리아 이미지 재사용·새 생성은 중단 상태를 유지한다.
- 다른 일반 자산은 승인된 마스터와 제작 도구의 실제 가용 범위에 맞춰 제작한다. 생성 제한이 생기면 미완료로 남기고 대본·코드 작업을 이어 간다.
- 얼굴·그림체·옷·헤어·귀걸이·전신 비율·손 크기·손가락·손톱·알파·잔상을 확대해서 검사하고 MD에 판정과 수정 이력을 남긴다.
- 승인된 자산을 실제 게임 크기에서 다시 검사한다. 도현의 외형을 추가하지 않는다.
- 대표 CG 한 장에서 기본 연출과 레이어 움직임을 확인한다. 겹친 선·빈 공간·얼굴 변형·루프 이음새를 검수한다.
- 네 목소리의 짧은 샘플과 음악 방향을 정하고, 상업 사용 가능한 조건과 실제 월예산 안에서 제작할 방법을 먼저 확인한다. 대사 확정 후 본 녹음을 만든다.

완료 기준: 대사·선택·UI·그림·음악·핵심 음성이 함께 들어간 대표 구간을 완성한다. 이 구간의 실제 제작 시간을 나머지 분량의 일정 계산에 사용한다. 자산 미수령이면 대본 기준 완료와 시청각 기준 완료를 나누어 표시한다.

### 6단계 — 지현·유진·서윤 루트 완성

- 각 루트 R01~R16, E01, 선택 일상 3개를 대본 작성→상태 연결→실행 검토 순으로 완성한다.
- 지현은 의견 교환과 생활의 균형, 유진은 자기 취향·발언과 합의한 도움, 서윤은 여유 있는 장난 속 직접적인 마음으로 구분한다.
- 고백 주도·첫 입맞춤·갈등·수습·후일담을 인물마다 다르게 쓴다. 리아 대본의 이름만 바꾸지 않는다.
- 유진은 앞서 존중한 선택을 했는데도 도현이 무조건 대신 말하는 갈등을 강제하지 않는다.
- 업무 사건 6개와 동료 결말을 전체 흐름에 맞춰 마무리한다.

완료 기준: 95개 사건이 대본·분기·실행·검토 상태로 추적되고, 네 루트를 각각 끝까지 진행할 수 있다. 같은 사건 안의 선택 가지를 별도 사건으로 부풀리지 않는다.

### 7단계 — 전체 그림·음향·애니메이션 마감

- 일반 CG 18개·일반 메시지 사진 8개·실제 필요한 배경과 입상 차분을 연결한다.
- 기본 연출 18개와 대표 레이어 4개를 실제 장면에 맞게 조정한다. 움직임·효과가 대사와 얼굴을 가리지 않게 한다.
- 사용자 제공 예약 자산은 수령·승인·파일 연결 여부를 별도 표시한다. 빈 항목을 대체 그림이나 완료 자산으로 처리하지 않는다.
- 핵심 히로인 음성의 발음·감정·인물 일관성·잡음·음량을 검사하고 음악·효과음과 균형을 맞춘다.
- 자동 진행·스킵·로그 재생에서 음성이 겹치거나 빈 재생 버튼이 뜨지 않게 한다.

완료 기준: 필수 장면에 임시 문구·잘못된 이미지·누락된 파일이 없고, 자산별 승인·사용 조건·연결 기록이 남아 있다. 확정 범위를 줄이는 결정 없이 미수령 필수 자산을 빼고 전체 완료로 선언하지 않는다.

### 8단계 — 전체 플레이와 수정

- 네 개인 결말·동료 결말·후일담을 실제 Windows 게임에서 끝까지 확인한다.
- 직접 교제/추가 대화/동료, 갈등 대응/만회, 미경험 대체, 공개/비공개, 선택 일상 보기/넘기기, 빠른 새 회차를 검사한다.
- 코드로 확인 가능한 상태 조합은 자동 검사하고, 말맛·설렘·읽기 템포·인물 차이는 사람이 읽으며 검토한다.
- 저장 위치별 복원, 메시지 중간 복원, 감상 후 복귀, 음성 중 스킵, 끝난 사건 중복 처리를 확인한다.
- 720p·1080p에서 글자 넘침·선택지 가림·사진 확대·폰트·알파 경계를 검사하고, 창/전체화면 전환과 입력을 확인한다.
- 실제 읽기 시간을 기록한다. 목표 분량을 맞추기 위한 반복 대사보다 장면의 역할을 우선한다.

완료 기준: 진행 불가·저장 손상·관계 상태 오류·잘못된 인물/자산 연결 문제 0건. 남은 경미한 문제도 목록과 판정을 남긴다. 확인한 PC 환경과 확인하지 못한 환경을 구분한다.

### 9단계 — 로컬 완성본과 원본 정리

- SDK나 개발 도구 없이 실행할 수 있는 Windows 로컬 빌드를 만든다.
- 깨끗한 별도 폴더에서 시작→저장→재실행→불러오기→엔딩을 확인한다.
- 게임 소스·대본·자산·레이어 원본·음원·사용 조건·완료 목록·알려진 제한·수정 이력을 정리한다.
- 버전·파일 해시·세이브 호환 범위·실행법을 기록한다.

완료 기준: 사용자가 로컬 완성본을 실행해 네 루트와 기능을 이용할 수 있고, 이후 수정할 원본과 검수 기록을 함께 보관한다. 이 단계에서 업로드·공개·판매·배포는 하지 않는다.

## 4. Steam 기능의 경계

기존 Cloud·업적 5개 목표는 삭제하지 않는다. 이번 개발에서는 개인 루트 완료 4개·동료 결말 1개의 로컬 달성 판정, 영구 해금과 회차 저장의 구분, 저장 위치·버전 관리, Steam이 없는 환경의 정상 동작을 준비한다.

실제 Steam 연동은 테스트용 앱 접근 권한과 실행 환경이 필요하다. 이용 가능한 경우에만 로컬 연동 검증을 별도 기록한다. 준비가 없으면 로컬 개발 완료와 Steam 서비스 검증 완료를 구분하고 서비스 검증은 미완료로 남긴다. 이를 로컬 검사로 대체 통과 처리하지 않는다.

이번 요청 범위에는 스토어 등록·소개 페이지·가격·출시일·등록비 결제·심사 제출·빌드 업로드·키 발급·공개 체험판·배포를 넣지 않는다.

## 5. 약 두 달 목표를 운영하는 방법

다음은 남은 작업을 8주에 배치한 잠정 목표이며 소요시간 보장이 아니다. 실제 입상 수·표정 수·음성 분량·자산 수정률은 아직 확정되지 않아 정확한 총 작업시간이나 완료일을 산출할 근거가 부족하다.

| 작업 주 | 우선 산출물 |
|---|---|
| 1주 | 초반 읽기·수정, 리아 후반 대본 착수, UI·메신저 구현 뼈대, 실제 자산 목록 |
| 2주 | 리아 끝까지 연결, 공통 시스템·메신저 저장 검증, 준비된 자산으로 대표 구간 검토 |
| 3주 | 지현 루트 연결, UI 적용, 일반 자산 제작·검수 |
| 4주 | 유진 루트 연결, 선택에 따른 갈등 변형, 음성 샘플·제작법 결정 |
| 5주 | 서윤 루트 연결, 선택 일상·업무·후일담 보완 |
| 6주 | 95개 사건 연결 확인, 전체 자산·음성·CG 연출 연결 |
| 7주 | 네 루트 전편 플레이, 상태·저장·메신저·시청각 오류 수정 |
| 8주 | 재검수, 로컬 완성본·원본·문서 정리 |

대본 집필과 일반 자산 준비는 병행할 수 있지만, 음성 본 제작은 해당 대사를 고정한 뒤 진행한다. 대표 CG의 레이어 방식이 통과하기 전에 나머지 대표 CG를 같은 방식으로 대량 작업하지 않는다.

2주차 점검에서는 리아 실제 제작량·읽기 시간·자산 수령 상태·이미지 수정률·음성 제작 가능 여부를 보고 남은 일정을 다시 계산한다. 확정 분량을 유지한 채 일정이 부족하면 연장안을 제시한다. 사용자 승인 없이 95개 사건·18개 CG·네 루트를 축소하거나 비용을 늘리지 않는다.

월 추가 도구 비용은 3만 원 이하를 제약으로 둔다. 새 유료 서비스·구독을 임의로 시작하지 않는다. 구독이 없는 음성 제작과 생성 제한은 실제 진행에 영향을 줄 수 있다. 현재 도구로 가능한 분량을 먼저 시험하고 판단한다.

## 6. 사용자와 어시스턴트의 역할

| 담당 | 작업 |
|---|---|
| 어시스턴트 | 대본·분기·시스템·UI 구현, 일반 자산의 제작 가능 범위 내 작업, 검수 MD, 상태/저장 검사, 로컬 빌드, 진행 기록 |
| 사용자 | 새 리아 자산과 사용자 제공 자산 전달, 대표 대사·UI·목소리·그림의 취향 판정, 실제 플레이 체감 피드백, 필요할 때만 비용·범위 결정 |
| 공동 판단 | 첫 루트가 재미있는지, 최종 그림체가 맞는지, 두 달 목표를 유지할 수 있는지 |

작은 소품·문장마다 질문을 반복하지 않는다. 기존 결정으로 해결할 수 없는 핵심 취향·비용·범위만 실제 비교 결과를 준비한 뒤 묻는다. 토큰 사용량은 게임 완성도나 작업시간과 같지 않으며, 작업 결과와 검사 통과를 진척 기준으로 삼는다. 이 계획만으로 백그라운드 작업이나 예약 실행을 시작한 것은 아니다.

## 7. 최종 완료 판정표

- [ ] 95개 사건과 모든 필수 선택 가지를 실제 게임에 연결했다.
- [ ] 네 개인 루트·후일담·동료 결말을 끝까지 검수했다.
- [ ] 호감도·교제·기억·공개·갈등·메신저·해금 상태가 저장/복원된다.
- [ ] 정식 UI·읽기 편의·감상·빠른 새 회차·도움말을 검수했다.
- [ ] 필수 그림·음성·음악·효과음과 일반 CG 18개/대표 레이어 4개를 검수했다.
- [ ] 사용자 제공 필수 자산의 미수령·미승인 항목이 없거나 변경 범위를 명시적으로 합의했다.
- [ ] 진행 불가·저장 손상·주요 상태 오류가 없다.
- [ ] 개발 도구 없이 실행 가능한 로컬 완성본과 수정 가능한 원본·문서가 있다.
- [ ] Steam 서비스 검증 여부를 로컬 개발 완료와 별도로 표시했다.
- [ ] 업로드·출시·배포는 수행하지 않았다.

바로 다음 제작 작업은 리아 R05~R08 대본·선택·기억 연결이다. 이를 리아 후반과 결말까지 이어 가면서 UI·메신저를 같은 루트에서 검증한다.
