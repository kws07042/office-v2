# 호감도 v2 설계 — 마음과 신뢰 (검토용 초안)

지금 호감도는 장마다 정해진 점수가 쌓이기만 해서 선택이 결과를 거의 바꾸지 못한다. v2에서는 수치를 **마음**과 **신뢰** 두 가지로 나누고, 선택에 따라 오르거나 내리게 한다. 이 문서는 점수를 어떻게 매기는지 확인받기 위한 초안이다. 확인을 받으면 대본과 코드에 넣는다.

---

## 1. 두 수치

| 수치 | 무엇을 재나 | 오르는 선택 | 내리는 선택 | 화면 |
|---|---|---|---|---|
| **마음** (설렘) | 얼마나 가까워졌나 | 데이트·선택 데이트·일정 선택을 함께함, 칭찬, 다가가기 | 계속 거절하거나 피하기(작게) | 오른쪽 위 하트 게이지(지금 자리) |
| **신뢰** | 믿고 기댈 수 있나 | 약속 지키기, 털어놓은 비밀을 받아 주기, 갈등에서 먼저 듣기 | 웃어넘기기, 대신 결정하거나 대신 말하기, 캐묻기, 약속 어기기 | 숨김. 관계 단계 문구로만 드러남 |

- 기존 호감도(`affinity`)는 그대로 둔다. 장마다 쌓이는 기본 점수 역할만 하고, 기존 검사가 그 값을 확인한다.
- 게이지에 보이는 마음 = 기존 호감도 + 선택으로 얻은 마음 보정.
- 신뢰는 0에서 시작한다. 범위는 −10 ~ +12.

## 2. 점수 규칙

| 선택 성격 | 마음 | 신뢰 |
|---|---|---|
| 그 사람의 상처를 이해한 대답 | +1 | **+2** |
| 무난하게 다정한 대답 | +1 | 0 |
| 그 사람의 상처를 건드리는 대답 | 0 | **−2** |
| 서운하게 하는 대답(가볍게) | 0 | −1 |
| 선택 데이트 끝까지 함께 / 짧게 / 건너뜀 | +2 / +1 / −1 | 0 |
| 일정 선택으로 함께함(공통 구간) | +1 | 0 |
| R14에서 헤어지자고 했다가 거둠 | 0 | −2 |

**히로인별 '상처'** — 신뢰가 오르내리는 기준이다.
- 리아: 늘 재밌어야 한다는 부담 → 힘든 걸 웃어넘기면 −, 들어 주면 +
- 지현: 혼자 다 결정하고 떠안는 버릇 → 대신 정해 주거나 토라지면 −, 같이 정하면 +
- 유진: 남이 대신 말해 버리는 것 → 대신 설명하면 −, 기다려 주면 +
- 서윤: 과거와 농담 뒤에 숨는 것 → 캐묻거나 같이 농담으로 넘기면 −, 진지하게 받아 주면 +

### 서윤
| 장 | 선택 | 신뢰 |
|---|---|---|
| R02 | 대답을 재촉하지 않고 기다린다 | +1 |
| R03 | 서윤 씨 보러 왔다고 말한다 | +1 |
| R06 | 진지하게 말하자는 쪽(호칭·표현 선택 중 sincere_first) | +2 |
| R06 | 공개 자리에선 조용히(quiet_public) | 0 |
| R09 | 받는 사람처럼 읽어 본다 | +1 |
| R13 | 무슨 일인지부터 듣겠다고 한다 | +2 |
| R13 | 전남편 일로 날 밀어내지 말라고 한다(몰아붙임) | −1 |
| R14 | 수요일에 다 얘기하자고 한다 | +2 |
| R14 | 수요일 얘기를 듣고 정하겠다고 한다(조건부) | −1 |
| R14 | 끝내자는 말을 거둔다 | −2 |

**마음 선택**은 각 장의 다가가는 선택(손잡기, 입맞춤, 보고 싶다는 말, 함께 있고 싶다는 답, 선택 데이트)에 +1을 준다. 거절이나 미루기는 0이다. 친밀 장면을 미루는 선택은 **감점하지 않는다**(지금 대본의 "정답은 없어요" 원칙 유지).

## 4. 관계 단계 6단계

| 단계 | 조건(마음 / 신뢰) |
|---|---|
| 알아가는 중 | 시작 |
| 신경 쓰이는 사람 | 마음 25+ |
| 설레는 사이 | 마음 40+ |
| 교제 중 | 고백 수락 |
| 서로 기대는 사이 | 교제 중 + 신뢰 6+ |
| 미래를 말하는 사이 | 교제 중 + 신뢰 10+ + R15 이후 |

- 신뢰가 0 아래로 내려가면 "약속 조율 중"(갈등) 단계가 끼어든다.
- 신뢰가 오르면 원래 단계로 돌아간다.

## 5. 결말

| 상태(R16 끝) | 결과 |
|---|---|
| 마음 높음 + 신뢰 8+ | 크리스마스 **True End**(밤) + 1월 장면 X02 |
| 그 밖에 교제 유지 | **Normal End**(저녁) + 1월 장면 N02 |
| R14 시점 신뢰 −6 이하 | **새 결말:** R14에서 히로인이 먼저 이별을 꺼냄(루트당 짧은 장면 1개) |

- 지금의 "마음 점수"는 이 기준으로 대체한다.
- 특별 장면 8개는 R06 뒤 장면을 마음, R11 뒤 장면을 신뢰로 연다.

## 6. 화면 연출

- 마음 +: 하트가 뛰고 숫자가 오른다(지금 연출).
- 신뢰 −: 하트가 짧게 흔들리고, 관계 단계 문구가 잠깐 흐려졌다 돌아온다. 숫자는 보여 주지 않는다.
- 신뢰 +2: 하트 테두리가 잠깐 금색으로 빛난다.

## 7. 새로 쓸 대본

- 신뢰가 떨어지는 선택 뒤 반응 대사: 지금 반응이 약한 곳만 보강한다. 루트당 3~5곳, 약 16곳.
- 신뢰가 바닥일 때의 R14 이별 장면: 4개, 각 약 800자.
- 관계 단계 문구 6개 × 4명. 히로인마다 말투를 다르게 쓴다(예: 지현 "업무 외 협의 중").

## 8. 검사

- 기존 `affinity` 값은 바뀌지 않으므로 기존 검사의 호감도 숫자 확인은 그대로 통과한다.
- 새 검사로 신뢰가 오르내리는지, 단계가 바뀌는지, 세 결말이 갈리는지 확인한다.
