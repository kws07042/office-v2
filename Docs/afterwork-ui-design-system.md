# 〈퇴근 후, 우리〉 UI 디자인 기준

## 저녁의 문턱

퇴근 뒤 관계가 바뀌는 순간을 타이틀의 분할 구도로 표현한다. 기존 키 비주얼과 먹빛 메뉴 사이에 엘리베이터 문이 맞닿는 선을 그렸다. 선은 타이틀에만 사용한다. 메인 워드마크는 Gowun Dodum으로 조판하고, 플레이와 설정에는 Pretendard를 사용한다.

- 타이틀은 어두운 세로 면에 새 게임·이어하기를 먼저 놓고 시스템 메뉴를 아래로 나눈다. 캐릭터가 있는 원화는 오른쪽에서 그대로 표시한다.
- 플레이는 배경 전체를 열어 두고 장소와 관계 상태만 화면 위 두 곳에 놓는다. 대화창은 이름과 대사를 두 열로 구분한다. 선택지는 장면 중앙에 왼쪽 정렬로 배치한다.
- 메신저는 화면 중앙에 놓고 연락처, 대화, 답장 영역을 구분한다. 노란 발신 말풍선과 빈 원형 프로필은 기존 요구를 따른다.
- 설정, 대화 기록, 저장·불러오기, 갤러리는 같은 상단 탐색을 쓴다. 제목과 본문을 나누고 인물 사진을 깔지 않는다. 저장 슬롯은 두 열, 대화 기록은 이름·대사 두 열로 읽는다.
- 밝은 화면은 종이색 `#f0ebe2`와 잉크 `#352b2b`, 선택 상태는 말린 자두색 `#69424b`를 쓴다. 어두운 화면은 `#292326`를 기준으로 한다. 히로인별 이름색은 대화와 기록에서 기존 대응 색을 유지한다.

## 구현과 검수 기준

Frontend Design의 단일 모티프와 용도별 글자 위계, GPT Taste의 화면 단위 시각 점검, UI UX Pro Max의 선택·초점·빈 상태 기준을 적용한다. 실제 Ren’Py 캡처에서 타이틀의 원화 경계, 화자와 본문 간격, 보조 조작의 대비, 메신저 구분을 확인한다. 웹 프레임워크나 새 폰트 다운로드를 요구하지 않는다.

`gui/badge/threshold.svg`는 이 UI에 맞춰 직접 그린 벡터 에셋이다. 타이틀의 기존 v002 키 비주얼과 플레이 입상, 시나리오는 편집하지 않는다.
