# 〈퇴근 후, 우리〉 UI 디자인 시스템

## 방향 비교

| 방향 | 장점 | 이번 원화와 대본에 적용했을 때 |
|---|---|---|
| A. 현대 오피스 로맨스 | 사원증과 코발트만으로 첫 화면에서 배경이 읽힌다. | 기존 원화의 석양과 대비된다. 사원증은 타이틀에 한 번만 쓰고 실제 게임 메뉴는 평면으로 구성한다. |
| B. 일본식 프리미엄 비주얼 노벨 | 장식 프레임과 명조가 로맨스 장르를 빠르게 전달한다. | 장면마다 큰 프레임이 얼굴과 손, 배경을 가린다. 문양을 반복하면 기존 원화의 선 밀도와 경쟁한다. |
| C. 한국식 모던 로맨스 | 짧은 문구, 중앙 자막과 넓은 여백이 플레이에 잘 맞는다. | 기존 엔드 크레딧 시안은 다양한 배경을 수용하지만 메인에서 오피스물의 인상이 옅다. |

**A로 통일한다.** 이전에 선택한 04 사원증의 코발트와 흰색을 사용한다. 메인 배치는 와이드 스크린 안으로 결정했다. 왼쪽 벽의 로고와 하단 조작부를 기준으로 잡으면 향후 완성될 메인 일러스트가 화면 대부분을 사용할 수 있다.

## 색과 글자

| 이름 | 값 | 역할 |
|---|---|---|
| 코발트 | #294DA1 | 현재 선택, 키보드 초점, 시작 버튼 |
| 잉크 | #202A3F | 시스템 화면 본문 |
| 종이 | #F4F5F7 | 인물 없는 설정·기록 배경 |
| 탐색 | #E8EDF4 | 시스템 화면의 왼쪽 영역 |
| 구분선 | #C8D0DF | 목록, 저장 슬롯, 탭 |
| 장면 하단 | #171B26 | 대사 대비를 확보하는 명암 |

Pretendard 한 계열을 사용한다. 화면 제목 42px, 대사 27px, 이름 21px, 메뉴·항목 18–21px, 보조 조작 15px를 기준으로 한다. 레이아웃 기준은 1280×720이며 Ren’Py가 창 크기에 맞춰 축소한다. 이름은 리아의 샴페인 골드, 지현의 장미색, 유진의 세이지, 서윤의 라벤더를 유지한다. 밝은 기록 화면에서는 같은 계열의 짙은 색을 사용한다.

## 화면 배치

- 타이틀은 기존 키 비주얼, 왼쪽 워드마크, 하단 동작 줄을 쓴다. 사원증 실루엣은 워드마크에만 사용한다. 타이틀 이미지 경로는 `window_title_art`에 모았다.
- 플레이는 인물과 선택지를 중앙에 둔다. 대사 영역의 어둡기는 하단에 집중한다. 배경은 기존 `bg` 이미지 태그 경로에 연결한다.
- 기록과 환경설정은 같은 왼쪽 탐색을 쓰고 장식용 인물 사진을 제거한다. 해금된 실제 CG는 갤러리에서 감상할 수 있다.
- 메신저는 중앙의 세로 기기와 배경을 구분한다. 빈 원형 프로필, 상태표시줄, 노란 발신 말풍선과 답장 구역을 유지한다.
- 환경설정과 기록 목록에서는 구획을 전달하는 선만 쓴다. 버튼 상태는 색과 면으로 구분하며 키보드 초점을 실제 화면에서 점검한다.

## 외부 스킬 적용

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/main/.claude/skills/ui-ux-pro-max)에서 초점과 선택 상태, 명암 대비, 뒤로 가기, 비어 있는 슬롯 상태를 검수 항목으로 가져왔다.

게임 배포 코드에 웹 프레임워크를 추가하지 않는다. 자체 제작 SVG는 사원증 아이콘에만 사용한다. Pretendard 라이선스는 기존 게임 폴더의 `Pretendard-LICENSE.txt`를 따른다. 기존 키 비주얼은 새 원화가 도착할 때까지 임시로 사용한다.
