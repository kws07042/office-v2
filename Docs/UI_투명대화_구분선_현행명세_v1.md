## 검증과 사용

낮·밤·긴 대사·세 선택지·사용자가 보여 준R14 화면을 확인한다. 확대 창은1792×1008을 요청하고 운영체제가 실제 허용한 약1739×978에서도 잔선을 확인한다. 요청 해상도를 실제 적용 해상도로 잘못 기록하지 않는다. 전체 시험 수는 현재 검증 보고서를 따른다.

흰 글자와 외곽선은 밝고 어두운 배경에서 확인했지만, 앞으로 실제 장소 그림이 들어오면 배경의 복잡도에 맞춰 다시 확인한다. 이번에 불투명한 대사 면을 자동으로 다시 넣지는 않는다. 일반 대화 UI의 변경이며 전용 이미지 페이지·휴대폰 화면·미구현 루트의 완성을 뜻하지 않는다.
