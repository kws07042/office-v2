# 전편 대본 통합 퇴고 — 0.35.1-full-script-edit

2026-11-02. 업무 미니 사건 PR #2를 main에 머지한 7d04db1을 기준으로 검토했다. 후속 수정은 PR #3이다.

## 읽은 범위

공통 C01~C08, 네 인물의 R01~R16·O01~O03·E01, 업무 미니 사건 여섯 개, 동료 결말을 진행 순서와 선택 가지를 함께 보며 읽었다. 합계 95개 사건 슬롯이다. 메신저의 날짜·장소·답장과 이벤트 전후 대사 16분기·64비트도 대조했다. 조건 없이 한 번에 모두 나오는 선형 대본은 아니다.

실행 소스 30개를 머지 기준과 비교했다. 이번 변경은 대사·지문·표시 38묶음과 버전 표기 1곳이며, 실행 모듈 13개와 이벤트 대사 JSON의 네 필드를 수정했다. 새로운 사건·장소 체계·장기 기억·호감도 보상은 만들지 않았다.

## 남겨 둔 인물 차이

리아의 거품·지도·빈 컵 장난, 지현의 작은 조립집·냅킨 카페·카드 승부욕, 유진의 매운맛·데이지·자기가 먼저 고르는 태도, 서윤의 설탕 취향 오판·다른 감상·케이크와 위스키 대화는 유지했다. 모든 대사를 같은 ‘서로 확인하자’ 문장으로 바꾸지 않았다.

유진에게는 실제로 선을 넘은 지원 경로만 그 잘못을 회상하게 했다. 존중했던 경로에 잘못을 새로 만들지 않았다. 관계 종료 발언을 한 경로에는 그 발언에 대한 감정을 남겼다.

서윤은 현재도 법적 혼인 상태이고 배우자와 함께 산다는 사실을 유지했다. 사적 만남의 장소는 개인 작업실이다. R13 공개·R14 사실을 들은 뒤 계속/종료 선택·E01의 상태를 바꾸지 않았고, 별거·이혼 중이라는 설명이나 새 알리바이를 넣지 않았다. 기억 변수 resolved는 해당 대화 진행 상태이며 혼인 문제가 해결됐다는 뜻으로 쓰지 않았다.

## 분기와 저장

메뉴 문구·수, 호출·점프·반환, 기존 상태 기록·보상과 조건 텍스트를 기준 소스와 비교했다. 추가 조건은 기존 기억/슬롯을 읽어 표시할 대사만 고른다. CG 배정·의상 선택·본장면 자리 표시·관계 종료/취소/보류·미룸은 유지한다.

새 회차에서 전편을 확인하는 기준이다. 이미 지나간 대사는 저장 파일에 소급해서 바뀌지 않는다. 옛 대화 기록은 저장 당시 문자열이 남을 수 있다. 구조 비교와 대표 실행 검사는 모든 저장 파일·모든 선택 조합의 동치 증명이 아니다.

## 검증

최종 실행 결과와 실패 수정 내역은 [검증 기록](validation/full-script-edit-2026-11-02.md)에 남긴다. Source는 0.35.1이며 저장소 Windows 폴더는 기존 0.34.1이다. 새 검증용 Windows ZIP은 공식 SDK에서 다시 빌드한 별도 산출물이다.

## 남은 일과 확인 범위

친밀한 본장면의 생략·자리 표시는 사용자 집필 대상으로 남겼다. 이번에는 그 안을 작성하지 않았다. 최종 그림·음성·배경·연출 제작도 하지 않았다.

편집 판단은 소스를 따라 읽은 결과다. 사람이 실제 게임을 자연스러운 속도로 읽는 실험은 수행하지 않아, 실제 플레이 시간·재미·몰입을 실측했다고 주장하지 않는다. 이번 퇴고의 완료를 상용 게임 전체의 완료로 환산하지 않는다.
