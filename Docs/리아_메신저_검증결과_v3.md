# 리아 메신저 검증 결과 v3

- 최종 소스: 42개 사례·434 assertion 통과. 기존 R08 17개, 추가 문자·날짜·기억·공개 연락·R12 약속·저장 17개, 전체 본편 8개 경로.
- Windows 패키지: 메신저 34개 사례·335 assertion 통과. CRC 및 게임 파일 40개 원본 일치. 테스트 소스·저장 파일은 배포용 패키지에서 제외.
- 실제 화면: 서윤 함께 보낸 연락·주간 대화 기록·다음 날 약속 기록의 글자·말풍선·날짜 구분을 확인.
- 최초 전체 흐름 자동 검사는 기존 R08 전용 입력 가정 때문에 실패했다. 새 문자 화면에서도 Enter로 진행하도록 연결하고 검사 입력을 일반화한 뒤 최종 8개 경로가 통과했다. 실패 로그는 내부 testing에 남긴다.
- 구버전 대본 중간 저장의 모든 위치를 보증하는 결과는 아니다. 새 회차의 선택 전 저장/복원과 기록 중복 방지를 검사했다.
- 캐릭터·표정·리깅·일반 CG·음성 파일은 수정하지 않았다. 이 결과는 아트 최종 승인과 무관하다.
- GitHub 원격 저장소는 이 작업에서 갱신하지 않았다.
