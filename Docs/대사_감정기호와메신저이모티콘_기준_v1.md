## 일반 대화 집필 기준

기호는 메신저 전용이 아니다. 실제로 말하는 대사에도 장난, 반가움, 항의, 당황, 설렘을 드러내도록 적극적으로 쓴다. 기존 문장 끝에 일괄로 붙이지 않고 문장 안에서 어느 말에 힘을 주는지 고른다. 모든 문장에 기호를 붙이거나 감정이 다른 인물을 같은 말투로 바꾸지는 않는다.

| 기호 | 사용할 감정·리듬 | 예시 |
|---|---|---|
| `~` | 능청, 가볍게 놀리기, 부드럽게 말끝 늘이기 | 리아: “퇴근했거든~ 오늘은 내가 개인적으로 부르는 거야!” |
| `~~` | 조금 더 길게 늘이며 장난치기 | 리아: “알아~~ 그냥 네 입으로 한 번 더 듣고 싶어서.” |
| `!` | 반가움, 적극적인 제안, 가벼운 항의 | 유진: “좋아요! 후보를 골라 볼게요.” |
| `!!` | 크게 들뜬 반응, 순간적인 당황, 코믹한 강조 | 리아: “나도 찬성!! 지금 멋있는 얘기 해도 머릿속엔 메뉴판만 떠올라~” |
| `?!` | 놀라서 다시 묻기 | 리아: “그 말 기억하고 있었어?!” |
| `...` | 망설임, 말끝 흐리기, 짧은 침묵, 장난 뒤 진심 | 리아: “한 번 써 놓고도... 자꾸 보게 돼서.” |

대사의 말줄임표 기본 표기는 ASCII 마침표 세 개 `...`로 통일한다. 같은 문장에서 `……`, `…`, `......`와 혼용하지 않는다. 지문·이전 검토본의 인용에는 기존 표기가 남을 수 있다. `...`를 붙였다고 실제 엔진 대기 시간이 생기는 것은 아니다. 중요한 침묵의 연출은 별도로 검토한다.

`~~~·!!!·!!!!`는 강하게 과장하는 드문 코믹 장면에서만 허용한다. 일반 표현에는 `~·~~·!·!!`로 충분하다. `...`도 모든 머뭇거림에 넣지 않으며 유진의 매 대사 첫머리를 말줄임표로 만들지 않는다.

고백·경계·사과·상호 확인에서는 의미를 분명히 한다. 그 직전의 장난과 직후의 기쁜 반응에는 기호를 쓸 수 있다. 예를 들어 “나랑 사귈래?”는 선명하게 두고 답을 기다리는 긴장은 독백이나 짧은 `...`로 전달한다. 업무 설명·독백은 필요한 감정에만 사용한다. 관계 정리·동의·결말 안내 선택지에 장식 기호를 넣어 의미를 흐리지 않는다.

## 메신저 이모티콘

사용할 첫 자산 후보는 하트·웃음·윙크·쑥스러움·놀람·응원 여섯 종류다. Lucide는 단순 아이콘, Twemoji는 컬러 표정 후보이며 실제 사용 파일은 도입할 때 확정한다. 상업 무료 사용 조건·배포 고지는 [이모티콘 상업 이용·배포 고지](<이모티콘_상업이용과배포고지_v1.md>)를 따른다.

- 업무 연락: 필요한 확인·가벼운 웃음·응원 위주. 개인 연애 하트를 업무 단체 채팅에 자동으로 붙이지 않는다.
- 썸: 웃음·윙크·쑥스러움으로 기대를 표현한다. 하트를 넣더라도 장난인지 사적 호감인지 앞뒤 문맥에서 알 수 있어야 하며 교제 확정으로 기록하지 않는다.
- 교제 확인 후: 하트·애정 표현을 더 직접적으로 쓴다. 리아는 경쾌하게, 지현은 드물지만 분명하게, 유진은 존댓말과 짧은 부끄러움, 서윤은 능청스럽게 차별화한다.
- 더 가까워진 후: 기존 장난·실제 공유한 기억을 회수할 수 있다. 잠자리 경험만으로 모든 메시지에 하트를 넣거나 표현 강도를 자동 상승시키지 않는다.
- 한 메시지의 끝에 한 개를 기본으로 하고, 특별한 들뜬 반응에는 두 개 정도까지 검토한다. 이미지 이모티콘만 보내는 짧은 답장도 가능하지만 중요한 약속·관계 확인을 대신하지 않는다. 사용자에게 이모티콘 수집 미션·새 점수 조건을 추가하지 않는다.

메시지 속 하트와 호감도 UI의 하트는 별개의 역할이다. 하트를 받았다고 호감도 증가·교제·접촉 완료를 자동 처리하지 않는다. 실제 답장 선택·기억 기록 규칙은 유지한다. 이모티콘을 보내지 않는 답장도 정상적으로 이어진다.

게임 구현 시 파일을 동봉해 PC마다 같은 모양으로 표시하고 대화 기록에서도 같은 자산을 재현한다. 기호·이모티콘은 음성에서 “물결”, “하트”라고 읽지 않는다. 음성 원고에는 ‘능청스럽게 말끝 늘임’, ‘웃음을 담아’, ‘잠깐 망설임’ 같은 지시를 별도로 둔다.

## 이번 반영 범위

현행 공통 C01~C08·리아 R01~R04의 실행 대사와 검토용 MD를 수정한다. 미래 R05 이후·다른 개인 루트·미완성 메신저에 대사가 이미 구현됐다고 표시하지 않는다. 기존 R03 약속 메시지는 교제 전이므로 밝은 스마일 문자 `:)`를 사용하고, 하트는 억지로 앞당겨 넣지 않는다. 컬러 이미지 이모티콘과 전용 메신저 화면은 아직 구현하지 않았다.

선택지·상태 코드·호감도·기억·교제 조건·사건 95개·일반 CG 18개는 변경하지 않는다. 리아 이미지 작업 중단을 유지한다. 대본 텍스트 수정으로 연출·음성·완성 디자인 검수가 완료되는 것은 아니다.
