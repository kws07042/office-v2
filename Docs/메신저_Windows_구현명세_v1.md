# Windows 메신저 구현 — 0.11.1-office-round / 기획 v2.82

## 구현 범위

- Ren’Py Windows 본편 리아 R08에서 실제 메신저 화면으로 자동 진입한다. 별도 웹 화면이 아니다.
- 기존 HTML 시안의 밝은 오피스 라운드(회청색 바탕·연보라 수신·푸른 발신 말풍선): 왼쪽 연락처 4명, 오른쪽 대화와 답장 3개. 다른 세 명은 수신 내역이 없어 빈 연락처로 표시한다.
- 기존 R08 선택 값 miss / evening / small_memory, 관계·약속·R07 경험 여부·존댓말/반말·일상 기억을 유지한다. 점수는 R08 종료 시 한 번 +4다.
- 중요한 답장만 0.9초 입력 중 표시를 사용한다. 바로 보기·설정 끄기·되돌리기를 지원하며 실제 대기시간 벌점은 없다.
- 메시지 ID와 회차별 대화·읽음·사진 열람 상태를 저장한다. 재열람으로 메시지나 점수를 중복 지급하지 않는다.
- 본편 하단 메신저 버튼으로 받은 기록을 다시 연다. 스크롤, 연락처 전환, 최근 사진 다시 보기, 확대 후 닫기를 제공한다.
- 시작 화면의 R08 메신저 확인은 첫 화면에서 바로 시험할 수 있는 새 회차 확인 진입점이다.

## 사진 자산 상태

실제 R08 식탁 사진은 미제공이다. 경로는 game/images/messages/ria/r08_breakfast.png다. 현재 사진 준비 중 카드를 명시적으로 표시하며 확대 UI도 확인 가능하다. 빈 카드 열람은 phone_photo_previews에만 기록하고 실제 사진 감상 phone_photo_opened에는 넣지 않는다. 테스트에서만 기존 리아 마스터를 로더 검사 자료로 사용하며 이야기 속 전송 사진으로 사용하지 않는다.

## 저장과 호환

phone_threads / phone_read_ids / phone_photo_opened / phone_photo_previews / phone_context는 Ren’Py 기본 저장 변수다. 기존 저장에 없는 변수에는 기본값을 제공한다. 입력 중 연출 설정은 persistent.phone_typing_enabled로 회차와 별도로 유지한다. 답장 선택 전·입력 중 저장 후 복원과 되돌린 뒤 다른 답장 선택을 검사한다. 구버전 R08 메시지 중간 저장의 모든 복원 위치를 보증하지 않으며 새 확인 장면을 권장한다. 기존 저장 파일은 삭제하지 않는다.

## 리깅 작업과 분리

캐릭터 이미지, 마스터, 표정 합성 파일, 리깅 원본은 이번 변경에서 수정하지 않았다. 이전 표정 차분은 사용자 검수에서 반려됐으며 이번 메신저 기능 검증이 그 차분의 시각적 승인을 의미하지 않는다.

## 미완료

다른 사건의 기존 메시지를 모두 이관하지 않았다. 다른 세 히로인의 개인 메신저 대본, 실제 사진, 최종 음향은 후속 작업이다. 일반 CG18개와 사건95개를 추가하거나 줄이지 않았다.

## 디자인 일치 작업 — 2026-10-16

기준은 office-moe-ui.html의 사용자가 선택한 ‘오피스 라운드’ 밝은 테마다. 화면 구성은 좌측 연락처·우측 대화·하단 답장 3개이며 게임의 1280×720 비율에 맞춘다. 시안의 샘플 대사와 하단 별도 대사 상자는 본편 메시지와 중복되므로 복제하지 않는다. 실제 R08 대화·분기·사진 확대·기록을 유지한다.

- 바탕 #e9edf4, 주 화면 #fcfcff, 보조 영역 #f1f3f8, 본문 #29364c, 보조 글 #626d81, 경계 #dce2ed, 포인트 #70619b.
- 수신 말풍선 #f0eaf8, 발신 말풍선 #e8eef6. 선택 연락처만 밝은 표면으로 강조한다.
- 제목·연락처·대화 상대 이름: Gowun Dodum Regular. 본문·답장·도구: Pretendard Regular. 메신저 전용 스타일로 적용하므로 기존 대사창의 글꼴은 변경하지 않는다.
- 두 글꼴은 수정하지 않고 공식 저장소에서 받아 game/fonts에 동봉했다. SIL OFL 1.1 라이선스 원문도 배포 파일에 포함한다. 실행 중 폰트 CDN 연결은 없다.
- 별도 음향, 실제 식탁 사진, 타 히로인 대본은 이번 디자인 변경의 완료 항목이 아니다.
