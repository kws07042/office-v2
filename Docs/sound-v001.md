# 소리 v001 — 배경음·효과음

## 원칙
- 모든 음원은 `Source/tools/make_audio.py`가 numpy 계산만으로 합성한다. 외부 샘플·음원이 없으므로 라이선스 문제 없이 상업 배포할 수 있다.
- 같은 이름(`Source/game/audio/bgm/*.ogg`, `audio/sfx/*.ogg`)의 파일로 바꿔 끼우면 코드 수정 없이 교체된다. 파일이 없으면 조용히 건너뛴다.
- 생성: 저장소 루트에서 `python3 -I Source/tools/make_audio.py` (numpy, ffmpeg 필요). 특정 곡만: `... make_audio.py office sfx`.
- 배경음은 약 −20 LUFS, 반복 지점은 잔향을 앞에 겹쳐 이음매 없이 반복된다.

## 배경음 (장소 문자열의 '·' 뒤쪽으로 자동 선택)
| 파일 | 분위기 | 쓰이는 곳 |
|---|---|---|
| title | 느린 발라드, 종소리 선율 | 타이틀 화면 |
| office | 로파이 비트, 전자 피아노 | 회사·회의실·협업 공간 (기본값) |
| cafe | 재즈풍 워킹 베이스 | 카페·서점·식당·전시·찻집 |
| evening | 따뜻한 아르페지오 | 퇴근길·산책길·공원·회사 앞·옥상 |
| night | 느리고 어두운 비트 | 회식·포차·숙소, 그리고 '밤' 시간의 카페/거리 |
| home | 패드와 드문 피아노 | 각 인물의 집·작업실 |
| pitch | 빠른 16분 아르페지오 | 피칭 당일 클라이언트사 |
| ending | 타이틀 주제 확장 | 엔딩 카드 이후 |

메시지·연락 장면은 직전 곡을 그대로 이어 간다. 규칙은 `silk_audio.rpy`의 `SILK_MOOD_RULES`.

## 효과음
| 파일 | 때 |
|---|---|
| hover / click | 모든 버튼 위·누름 |
| pick | 선택지 고름 |
| phone | 메신저 새 메시지 |
| heart | 호감도 상승 |
| whoosh | 장 제목 카드 |
| menu | 게임 메뉴 열고 닫기 |
| ending | 엔딩 도달 |

효과음은 스킵 중에는 나지 않는다. 설정 화면의 음악·효과음 음량 막대가 이제 보인다.
