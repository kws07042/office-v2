# R15~후일담: 약속 설명에서 달라진 일상으로 — v2.99 / Windows 0.26.0

2026-10-20. 네 히로인의 R15·R16·E01, 총12개 장면을 이어 읽고 편집했다. 앞선0.25.0의 기록집·갈등 편집은 보존한다. 제어 흐름·선택 문구·기억·교제/거절/관계 종료·보상·호감도·사건/CG 계획은 그대로다. 새 이미지·음성·외부 자산은 만들지 않았고 친밀한 본장면의 생략·자리 표시도 유지한다.

## 진단과 편집 원칙

R15는 미래를 조율하고, R16은 그 의미를 다시 설명하고, 후일담은 같은 약속을 되풀이하는 흐름이 있었다. 필요한 미래 선택 자체를 없애면 기존 엔딩과 기억을 바꾸게 되므로 유지했다. 대신 선택 앞뒤의 다짐·교훈·후속 일정 예고를 줄이고, 현재의 작은 행동으로 관계의 변화를 보여 준다.

날짜는 없애는 대상이 아니라 혼동 없이 한 번 전달할 정보다. 장면 머리의 시간·장소, 서윤의 금요일19시·다음 달 둘째 토요일14시 같은 실제 약속, 각 후일담 선택의 날짜와 저장값은 유지했다. 반복적인 대사 확인과 ‘아직 결정한 것은 아니다’라는 설명만 줄였다. 계약·입주·여행·전시 신청이 끝났다고 앞당기지 않는다.

## 강리아 — 함께 읽던 습관이 두 권의 책에 남음

R15의 ‘앞으로도 이런 날 있었으면 좋겠어’ 대신 지금 노트를 덮고 밥 먹으러 가고 싶은 리아를 보여 준다. 일정을 고르는 선택은 각자 늦잠 잘 날과 음식 자랑으로 받는다. 주마다 저녁·함께 일정 선택·각자 쉬기라는 세 값은 바뀌지 않는다.

R16의 업무 결과는 안내 위치 변경 전후와 질문 감소 수치, 다음 현장 검증 담당, 동료별 후속 담당을 짧게 남겼다. 동료들의 비슷한 확인 발언을 한 문단으로 묶었지만 업무 성취와 역할을 없애지는 않았다. ‘아무것도 없는 날에도 만나자’는 선택은 초안을 두고 가도 된다는 리아의 욕심으로 이어진다.

- 이전 후일담: ‘마지막 장이 너무 빨리 오면 어떡하지~’ → ‘다음 권 얘기도 하면 되지.’
- 이후: 도현이 자기 책에도 별표를 그리려 하자 리아가 ‘첫 독자 판본이라며’라고 막는다. 대신 도현 책의 책갈피를 직접 고른다.
- 주간 저녁 약속의 유지와 일정 변경은 달력 표시로, 각자 쉴 날은 빈칸과 두 사람의 약속이 함께 있는 달력으로 보여 준다. 두 부 완성·각자의 집·오늘은 외출하지 않음은 유지한다.
- 보존: 기존 책갈피/별표 장난, 선택한 O03 회상, 실제로 이름 붙인 장소만 되짚는 조건, 코스프레를 선택한 경우에만 나오는 개인 기억. 말투는 반말·존댓말 모두 반영했다.

## 백지현 — 계획표를 닫고도 상대를 붙잡을 수 있음

R15는 빈 날짜를 제안서처럼 설명하기보다 이미 후보가 있는데도 아직 고르지 않았다고 말하는 작은 빈틈을 쓴다. 힘들 때 부탁하겠다는 선택은 지금 설거지를 조금 미루고 같이 앉아 달라는 부탁이 된다. 의견이 달라도 연애는 계속한다는 선택은 ‘내 후보가 지면?’이라는 짧은 응수로 받는다.

R16의 시험 자료는 담당별 확인란·월요일 공유·시험 예정 상태만 남기고 가방을 닫는다. 끝의 ‘다음에 바뀔 일정은 다음에 이야기’는 삭제한다. 손잡기 조건을 거친 뒤 긴 귀갓길을 고른 도현에게 지현이 더 길 안내를 하지 않는 행동으로 마친다.

- 이전 후일담: ‘오늘은 게임 전에 부탁 말고 제안 하나. 같이 사는 걸 이야기해 보고 싶어.’
- 이후: 조립집과 도현 책의 자리를 만들다가 ‘이거랑 네 책, 같은 집에 두면 어떨까. ...장식 얘기 말고’로 말을 꺼낸다.
- 동거의 공간·생활 분담·생각할 시간 선택은 유지한다. 이미 동거한 것은 아니다. 차를 골라 온 도현, 컵을 치우지 않고 카드를 준비하는 지현으로 끝낸다.
- 보존: 소금빵/크림빵 등 O03 세부 활동을 일괄 회상하지 않는다. O01의 비는 그 일상을 실제 본 경우에만, O02 지붕 회상도 실제 본 경우에만 유지한다. 집안일 선택의 ‘한 번?’ 받아치기는 이미 좋아 그대로 뒀다.

## 차유진 — 먼저 부르는 횟수보다 지금 보여 주고 싶은 것

R15의 반복적인 ‘다음엔 도현 씨 차례’를 오늘 준비한 말이 중간에 끊긴 모습으로 바꿨다. 초대·지원 범위·휴식 균형은 그대로 선택한다. 친밀한 장면을 선택한 뒤의 비노골적인 대화는 ‘연습한 말을 잊었다’와 ‘중간부터 더 좋았다’라는 짧은 응수로 정리했다. 본장면 자체는 손대지 않았다.

R16의 업무는 최종본 저장·자기 이름 확인·월요일 전달 예정으로 압축했다. 교제 비공개는 설명을 반복하지 않고 다른 사람에게 메시지를 보내지 않는 지문으로 남긴다. 이전 과잉 지원 경로는 말한 도움을 지켰다는 재해설 대신 지금 보고 싶은 페이지를 유진이 고르는 모습으로 받는다. 실제 사진 여부에 따른 초안 설명은 유지한다.

- 이전 본편 끝: ‘다음에도 저랑 만나 주세요’ → ‘이번에는 저도 먼저 약속할게요.’
- 이후: ‘다음 장 넘겨도 돼요?’ → ‘그쪽으로 좀 기울여 주세요. 저도 같이 볼래요.’ 두 사람이 같은 초안을 본다.
- 이전 후일담 끝: ‘다음 주말에는 제가 먼저 부를게요’ → ‘그럼 오늘은 제가 한 번 더요.’
- 이후: 여행 준비물과 카메라를 얘기하다, 소개지에 적힌 도현의 이름을 보고 ‘그건 처음부터 도현 씨 거예요’로 끝낸다. 전시 신청/휴가/후보 선택은 계획 단계이며 예약·참가·여행 완료가 아니다.
- 보존: 음악은 실제 골랐던 곡만 회상한다. 개인 작업 완성·두 장짜리 초안에서 인쇄본으로 바뀐 결과, 선택 일상을 본 조건도 유지한다.

## 한서윤 — 날짜를 외우게 하기보다 같이 머무는 시간을 남김

R15는 메뉴 선택이 다른 둘이 각자 주문을 마치는 짧은 행동 뒤에 대화를 시작한다. 금요일19시는 서윤이 한 번 제안하고 도현은 수락하며 장소를 확정한다. 생활 대화 날짜는 기존대로 말하되 ‘결정을 약속한 건 아니다’를 도현이 다시 설명하지 않는다. 서윤의 제안과 미정 상태는 유지된다.

R16의 업무는 다음 제안서 담당과 범위 설명 역할을 자료로 확인하고 가방에 넣는 것으로 줄였다. ‘그래서 다음에도 보고 싶어’ 대신 책갈피를 든 채 도현이 일어나길 기다렸다가 오늘 걷자고 꺼낸다. 손잡기는 기존 공개 애정 표현 선택의 조건을 따른다.

- 이전 후일담: 자기 업무 계획을 다시 보고하고 ‘같이 살 준비, 날짜를 정해서’라는 안내를 길게 붙임.
- 이후: 업무 수첩은 가방 안에 두고 인쇄본과 버리지 않은 감상 쪽지를 나란히 본다. 함께 살 준비를 시작하고 싶다는 의사는 분명히 말한다.
- 다음 대화의 세 날짜·비용/통근·공간/생활·목록/순서라는 선택은 유지한다. 계약·입주 미완료는 합류 지문에서 한 번 명시한다.
- 끝은 다음 질문과 연락의 약속 대신 책을 둘 사이에 펴고 서윤의 속도로 읽는다. 예전 실패한 농담은 실제 O02를 본 경우에만 ‘이번엔 설명 먼저 붙였어’로 회수한다.

## 무엇을 남겼고 무엇을 검증하지 않았나

미래 약속이 전부 사라진 것은 아니다. 선택지 자체가 앞으로 어떤 연인이 될지 고르는 구간이고, 동거/여행/전시를 계획하는 후일담도 기존 도달점이다. 그 의미와 정확한 날짜는 유지했다. 현재의 행동으로 대신할 수 있는 다짐·업무 해설·다음 회차 예고를 줄인 작업이다.

편집자 판단으로는 네 후일담의 끝이 ‘다음 약속 하나 더’로 모이던 인상이 줄었다. 리아는 서로 다른 별표가 있는 두 권, 지현은 컵과 카드, 유진은 이름 적힌 소개지, 서윤은 같이 펼친 책으로 마무리한다. 각 지문은 텍스트 연출이며 새 그림/리깅/음성 자산 구현을 뜻하지 않는다.

사람 대상 재미 평가·독서 시간 측정은 하지 않았다. 자동 실행 검사는 선택·기억·결말 조건의 유지와 실행 오류를 확인한다. 실제 독자의 반응은 별도다. 선택 메뉴에는 구체적인 약속 설명이 남아 있어, 실제 읽기에서 여전히 길게 느껴진다면 메뉴 문구를 별도 편집할 여지는 있다. 이번에는 기존 선택 문구까지 바꾸지 않았다.
