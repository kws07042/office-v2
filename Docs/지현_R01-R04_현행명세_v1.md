기억 없는 확인 경로는 공통 대화의 세부 사건을 경험했다고 만들지 않는다. C02에서 ‘더 확인하겠다’만 기록되고 실제 제출 값이 없으면 제출한 자료를 칭찬하지 않는다. 지현이 의견을 검토했다는 사실이 도현의 안이 모두 옳다는 선언이나 연애 대가로 바뀌지 않게 썼다. 부탁받은 일정 범위와 서로의 제안을 분리하며 거절은 업무 평가·호감도 벌점에 연결하지 않는다.

R01 +4 / R02 +7 / R03 +8 / R04 +5. 공통 없는 확인 경로에서 교제 직전19·교제 확인 뒤24다. 공통 점수는 별도다. 준비 대화에 숨은 정답 보너스가 없고, 교제 전에 마음만 있다고 dating을 기록하지 않는다. 동료 선택 확인 전에는 취소하거나 지현의 마음을 한 번 더 듣고 다시 고를 수 있다.

`jihyun_core_understanding`, `jihyun_confession_accepted`, `jihyun_work_boundary`, `jihyun_publicity=private`, `jihyun_next_date_plan`을 후속 사건에 넘긴다. R05에서 실제 첫 입맞춤을 선택하도록 남겨 두고 현재 `first_kiss`는 바꾸지 않는다. R05는 R02 실제 계획·맡긴 범위, R04 다음 데이트 방식과 각자 시간을 회수해야 한다. R06에서 호칭을 바꾸더라도 업무상 기본 호칭이 자동 바뀌지 않게 한다.

시작 화면 ‘지현 R01~R04 확인’과 공통 C08 선택에서 진입한다. 연락처·메시지 기록·중요 메시지 입력 중·저장·불러오기는 기존 메신저를 재사용한다. 관계 헤더는 알아가는 중/교제 중/동료로 지내는 중을 구분한다. 지현 입상은 아직 제공되지 않았으며 다른 히로인의 그림을 대신 표시하지 않는다. 동료 결말의 합동 장면에서는 실제 말하는 다른 히로인이 등장할 수 있다.

`ending=jihyun_early_segment_complete`는 초반 수록 종료이며 전체 루트 완주·Steam 업적이 아니다. 이전 회차의 로컬 완주 정보가 있으면 초반 진행이 그 값을 새로 얻거나 지우지 않는다. R05~R16·선택 일상3·E01은 아직 미구현이다.
