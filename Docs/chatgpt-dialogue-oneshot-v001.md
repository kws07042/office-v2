첨부한 zip은 한국어 성인 연애 비주얼노벨 〈퇴근 후, 우리〉의 Ren'Py 대본 26개다. 너는 대사 교정자다. 코드 실행 도구를 써서 아래 순서를 끝까지 혼자 진행하고, 마지막에 patches.json 파일 하나만 내라. 중간에 나한테 묻지 마라.

## 1단계: 압축 풀기
zip을 풀고 .rpy 26개를 UTF-8로 읽어라. 줄 번호는 1부터 센다.

## 2단계: 파일마다 고칠 줄 고르기
'사람이 쓴 것처럼' 고칠 필요가 있는 줄만 골라 새 문장을 써라. 이미 자연스러운 줄은 두고, 파일당 10~30%만 고친다.

고쳐도 되는 줄(이것만):
- 대사: 들여쓰기 + 화자(r, d, j, y, s, dn 등) + 공백 + "..."
- 지문: 들여쓰기 + "..."  (선택지처럼 끝에 : 가 붙은 줄은 제외)
- 문자: call phone_deliver("ID", "보낸사람", 내용, ...) 줄의 '내용' 부분만

인물:
- 리아(r, 28): 밝고 빠른 말끝, 장난, ~·!. 결정적인 순간엔 말이 짧아진다.
- 지현(j, 30, 팀장): 짧고 결론부터. 버릇 '결론부터 말할게'는 남긴다. 칭찬엔 "...그런 건" 하고 말을 잃는다.
- 유진(y, 27, 디자이너): 존댓말, 말끝을 흐리다 직구. 색·빛·그림 이야기.
- 서윤(s, 32): 여유로운 반말로 떠보다 진심일 땐 장난을 멈춘다. 이혼(자녀 없음).
- 도현(d/dn): 주인공. 다정하고 차분. dn은 속마음(1인칭 가능).

사람이 쓴 것처럼:
- 실제로 말하는 길이와 리듬. 끊고, 되묻고, 피하기도 한다.
- 감정을 이름으로 말하지 않는다('설렜다', '마음이 따뜻해졌다' 금지). 행동과 사물로 보여 준다.
- 결론을 대사로 정리하지 않는다. 서로를 설명해 주는 대사 금지.
- 금지 표현: 왠지 모르게, 문득, 살며시, 조심스럽게, 어느새, 그 순간, 진심으로, 소중한, 특별한, 함께라서, 줄표(—), 셋씩 나열.
- 일어난 사실(시간·장소·옷·약속·행동)과 관계는 바꾸지 않는다.

## 3단계: 검사 코드를 만들어 모든 제안을 돌려라
아래 규칙을 파이썬 함수 check(old, new)로 구현하고, 모든 제안에 실행해라. 하나라도 걸리면 그 줄을 다시 고치거나 버린다. 위반이 0이 될 때까지 2~3단계를 반복해라(최대 5회).

R1 old는 원문 그 줄과 정확히 같아야 한다(앞 공백 포함).
R2 new도 한 줄이다. 들여쓰기 공백 수와 화자 표시가 old와 같다. 줄을 넣거나 지우지 않는다.
R3 old가 대사/지문/문자 줄 패턴이 아니면 고치지 않는다(label, menu, 선택지 "...":, if/elif/else, $, call(phone_deliver 제외), jump, return).
R4 phone_deliver 줄은 첫 두 인자(ID, 보낸 사람)가 같아야 한다.
R5 old에 [ri('A','B')]가 있으면 new에도 정확히 하나 있어야 하고, 없으면 new에도 없어야 한다.
R6 ri의 A는 반말, B는 존댓말로 남아야 한다. A가 '요/니다/죠/세요/까요/어요/아요/에요/예요'(뒤에 . ? ! ~ … 허용)로 끝나면 위반이다. B가 그렇게 끝나지 않으면 위반이다. A와 B가 같으면 위반이다.
R7 ri가 없는 d 줄은 old가 존댓말로 끝나면 new도 존댓말로, old가 반말이면 new도 반말로 끝나야 한다.
R8 '도현' 등장 횟수가 old와 new에서 같아야 한다. '도현이가', '도현이는', '도현이를', '도현이도', '도현이랑'은 금지다.
R9 지문 줄(화자 없이 "로 시작)은 old에 없던 '나/내/내가/나는/나를/나도'를 쓰지 않는다.
R10 이모지 금지. old보다 [ ] { } 개수가 늘면 안 된다.
R11 j 줄에서 old의 '결론부터'가 new에서 사라지면 위반이다.
R12 금지 표현 목록의 단어가 new에 새로 들어가면 위반이다.

  "파일이름.rpy": [ {"line": 12, "old": "원문 줄 그대로", "new": "고친 줄"}, ... ],
  ...
}
