## 1. 현재 구현과 판단

현재 실행판 0.3.0-ria08에는 생명력·남은 실수 횟수·게임오버 시스템이 없다. 실제 상태는 인물별 호감도, 리아 신뢰, 선택 기억, 사건 완료, 교제 여부다. 공통 C01~C08·리아 R01~R08·O01에서 선택 실패를 이유로 생명력을 차감하는 호출도 없다. 동료 결말은 명시적으로 연애를 시작하지 않기로 고른 결과이며 생명력 소진에 따른 실패가 아니다. R09 이후의 갈등 시스템은 아직 미구현이다.

**추천: 별도의 생명력은 추가하지 않는다. 대신 중요한 대응이 실제 반응·후속 대화·수습 행동을 바꾸게 한다.**

## 2. 전체 MD와의 적합성

outputs의 MD 29개를 대상으로 문서 역할·관련 규칙을 대조했다. 현행 통합 기획서의 12·16·30·31·38·39절, 95개 사건 명세의 각 R13~R16과 21절, 선택 분기 명세의 13·14·21·23절, 리아 참고 점수표, UI·핸드폰·개발 계획을 판단 근거로 삼았다. 초기 보관본의 9엔딩·옛 점수 문턱을 현행 규칙으로 사용하지 않았다. 그림 검수·라이선스·과거 빌드 기록은 해당 문서의 역할로 분리했다. 전체 대사의 최종 교정이나 게임 전체 실행 시험을 뜻하지 않는다.

- 현행 방향은 빠른 교제 이후의 달콤한 연애·장난·기억 회수다. 숨은 오답 누적으로 루트를 끊으면 자연스러운 대답보다 정답 찾기와 선택 전 불러오기를 유도할 가능성이 있다. 이는 설계 판단이며 실제 플레이테스트 결과가 아니다.
- 취향·말투·개인 시간·애정 표현을 미루는 선택에는 벌점이 없고, 한 번 서툰 갈등 대응 뒤 R14에서 만회할 기회를 주기로 이미 정했다. 선택마다 생명력을 깎는 규칙과 충돌한다.
- 호감도는 보이는 관계 피드백이고 신뢰·갈등 기록도 이미 있다. 별도 생명력은 같은 문제를 중복 관리하며, 왜 감소하는지와 회복·저장·엔딩 조건을 추가로 설계해야 한다.
- 기본 결말은 개인 좋은 결말 4개와 동료 결말 1개다. 생명력 소진 결말을 추가하면 현재 종료 구조와 집필·검증 범위를 다시 정해야 한다.

## 3. 생명력 대신 선택에 결과를 주는 방식

모든 선택을 같은 반응으로 합류시키는 것도 부족하다. 현재 초반의 긍정적인 선택·같은 기본 보상은 취향과 표현을 고르는 장면에는 맞지만, 후반 갈등에서도 그대로 적용하면 선택의 무게가 약해진다. 다음은 기존 R13·R14 안에서 적용할 집필·구현 기준이다.

| 선택의 성격 | 결과 | 수치와 진행 |
|---|---|---|
| 카페/산책, 유머/직구, 다른 의견, 입맞춤·친밀한 전환 미룸 | 실제 활동·대사·기억이 달라짐 | 오답으로 분류하지 않고 자동 차감 없음 |
| 사실을 잘못 기억하거나 의도를 오해함 | 상대가 구체적으로 정정하고 다시 묻거나 설명할 기회 | 추측 한 번으로 생명력·신뢰 차감 없음 |
| 실제 약속·합의 범위를 무시한 대응 | 상대 반응과 남은 문제가 달라짐. 무엇이 어긋났는지 대사로 전달 | 해당 사건의 신뢰·갈등 기록만 사용. 모든 서툰 말에 고정 감점하지 않음 |
| 문제를 확인하고 실제 행동으로 수정 | R14에서 바뀐 행동 확인, 이후 그 사실을 기억 | 해결 기록과 사건별 피드백. 사과 버튼만으로 즉시 해결하지 않음 |
| 관계를 계속하고 싶지 않다고 명확히 선택 | 결과를 알리는 문구 뒤 기존 짧은 관계 종료 대화 | 남은 목숨 0에 의한 갑작스러운 종료로 만들지 않음 |

추가 확인은 ‘잠깐 다시 물어보기’가 실제로 필요한 경로에만 둔다. 처음부터 잘 이해한 경로에 같은 확인을 반복시키지 않는다. R14의 문제가 미해결인데 R15·R16에서 해결됐다고 자동 회상하거나 좋은 결말을 무조건 출력하지 않는다. 기존 확인·합의·실행을 마치거나 명확한 관계 종료 선택으로 이어질 수 있도록 연결하고, 별도 배드엔딩·벌점 모드·새 사건은 자동 채택하지 않는다.

## 4. 리아 갈등에서 주의할 실제 책임

리아 R13의 출발은 리아의 반복된 일정 변경이다. 도현이 기다린 시간이 속상하다고 말하거나 연락 기준을 요구하는 것은 잘못된 선택이 아니다. 리아의 문제 때문에 도현이 사과하거나 벌점을 받게 만들지 않는다. 리아는 위임·변경 연락·재예약을 실천하고, 도현은 자기 필요를 말하며 두 사람의 기대를 조율한다.

리아 참고 점수표의 ‘R13 -1, R14 +1’은 모든 경로의 필수 수식으로 읽으면 안 된다. 기존 신뢰 0~3은 약속에 대한 관계 맥락이며 플레이어의 남은 실수 횟수가 아니다. 실제 합의 훼손이 있는지, 누가 어떤 행동을 했는지, 이전에 이미 수습했는지에 따라 판단한다. 갈등을 상대가 일으켰다고 도현의 대답을 자동 오답 처리하지 않는다.

## 5. UI·저장·검증

계획된 5칸 하트는 호감도 0~100 표시다. 하트 한 개가 남은 목숨 하나라는 뜻이 아니며 0이어도 자동 게임오버하지 않는다. 실제 Windows 개발판은 아직 숫자·막대 임시 UI다. 별도 라이프 표시나 ‘실수 2회 남음’ 경고를 추가하지 않는다.

후반 구현 때 확인할 것은 취향·미룸 무감점, 정당한 서운함 표현의 무벌점, 위반과 단순 오해 구분, 잘 대응한 경로와 확인이 필요한 경로의 실제 차이, R14 행동 확인 후 회복, 미해결 상태의 허위 회상 방지, 같은 위반 중복 적용 방지, 저장·되돌리기 뒤 상태 복원이다. 이번 작업은 문서 검토이며 새 코드·새 빌드·이 항목의 실행 시험을 완료한 것은 아니다.
