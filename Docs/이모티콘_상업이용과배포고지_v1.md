## 확인 결과

| 후보 | 유료 게임에 포함 | 비용 | 배포 조건 |
|---|---|---|---|
| Lucide | 가능. 이용·수정·배포를 허용 | 아이콘 사용료·판매 로열티 없음 | ISC 저작권·허가 고지 보존. Feather 유래 아이콘을 쓰면 해당 MIT 고지도 보존 |
| Twemoji 그래픽 | 가능. CC BY 4.0은 상업 이용·수정을 허용 | 그래픽 사용료·판매 로열티 없음 | 제공된 제작자·저작권 고지, 출처, 라이선스 링크, 수정 내역 표시. 해당 그래픽에 라이선스상 권리를 제한하는 추가 조건이나 기술적 제한을 부과하지 않음 |

Lucide 전체를 단순히 ISC라고만 설명하면 빠지는 부분이 있다. 공식 라이선스의 Feather 유래 목록에 `smile`이 포함되어 있으므로, 스마일 사용 시 Cole Bemis의 MIT 고지도 배포본에 넣는다. 공식 전체 라이선스 문서를 보존하면 이 두 고지를 함께 관리할 수 있다.

Twemoji의 코드 MIT와 그래픽 CC BY 4.0을 구분한다. PNG/SVG 이미지만 도입해도 그래픽 라이선스는 적용된다. CC BY에는 ShareAlike 조건이 없으며 이 이미지 사용만으로 독립적인 게임 코드·대사 전체를 공개해야 하는 것은 아니다. 이미지의 재이용 권리는 유지한다.

## 실제 도입·배포 방법

1. 공식 저장소에서 필요한 파일만 선택하고, 사용한 태그 또는 커밋·원본 URL·파일명·라이선스 원문·취득일을 자산 대장에 기록한다. 이 문서는 최신 공개 페이지 확인 기록이며 특정 다운로드 버전을 확정한 기록은 아니다.
2. 게임 배포 폴더에 `licenses/`와 `THIRD_PARTY_NOTICES.txt`를 넣는다. Lucide ISC 및 해당 Feather MIT 원문, Twemoji 그래픽 라이선스 원문과 귀속 정보를 보존한다. 게임의 ‘크레딧 → 외부 자산·라이선스’에서도 열람할 수 있게 연결하는 것을 권장한다. 매 메시지나 매 하트 옆에 제작자 이름을 붙이는 방식은 필요하지 않다.
3. 색 변경·표정 변경·선 두께 변경 등 실제 수정을 기록한다. CC BY 그래픽 고지에 변경 사실을 적고 원본 귀속 정보를 유지한다. 아직 수정한 자산이 없으므로 가상의 변경 내역을 적지 않는다.
4. Twemoji를 사용할 때 게임의 ‘모든 자산 재배포 금지’ 문구에 외부 라이선스 자산 예외를 명시한다. 출시 배포 구조에서는 해당 그래픽의 CC BY 권리를 제한하지 않도록 별도 평문 파일로 제공하고, 해당 파일에 별도 DRM을 적용하지 않는 방식을 권장한다. Steam을 이용한다는 이유만으로 사용이 금지되는 것은 아니다. 실제 적용하는 보호 방식은 배포 시 확인한다.
5. 최종 Windows 설치본에서 고지 파일이 빠지지 않았는지, 게임 내부 링크·720p/1080p의 작은 표정 이미지·로그 표시가 정상인지 확인한다. 기존 빌드에 라이선스 화면이나 새 아이콘이 이미 들어갔다고 표시하지 않는다.

고지에는 실제 파일에서 제공된 저작권·귀속 정보를 그대로 유지한다. 기본 양식은 ‘자산명 / 원 제작자·귀속 정보 / 사용 버전·출처 / 라이선스·원문 위치 / 실제 수정 사항’이다. 제작자가 본 게임을 후원하거나 성인 콘텐츠를 승인한 것처럼 표시하지 않는다.

## 본작 추천

빠른 제작과 고지 관리의 단순함을 우선하면 Lucide의 단순 하트·스마일부터 사용하는 안을 추천한다. 컬러 이모지의 표현력이 필요하면 Twemoji를 추가한다. 두 안 모두 라이선스상 상업 이용이 가능하며 아직 사용자 최종 선택은 아니다.

메신저에서는 리아의 장난, 지현의 드문 하트, 유진의 웃음·응원, 서윤의 능청스러운 윙크처럼 사용 습관을 구분한다. 대사창 기호는 드물게 사용하고 고백·갈등에서는 절제한다. 표정 이미지와 호감도 UI의 하트를 역할·크기로 구분한다. 이는 집필 제안이며 현재 대본이나 호감도 구현을 변경한 것은 아니다.

문자 `♡` 자체와 특정 회사가 그린 이모지 이미지의 이용 조건은 구분한다. 문자 표시에는 동봉 글꼴의 지원·라이선스를 확인하고, 이미지 표시에는 선택한 자산 라이선스를 적용한다. 실제 플랫폼 표정을 캡처해 대신 쓰지 않고 검증한 원본 파일을 동봉한다.

아이콘 라이선스의 허용과 Steam의 작품 심사·성인 콘텐츠 심사는 별개의 문제다. 이 기록은 아이콘 사용 조건을 확인하며 작품 전체의 출시 승인을 보장하지 않는다.
