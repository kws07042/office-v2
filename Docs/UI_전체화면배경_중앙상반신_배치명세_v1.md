# 전체 화면 배경·중앙 상반신 — 대화 화면 배치 기준

## 사용자 확정

- 배경 그림은 화면 전체를 빈틈없이 채운다.
- 기본 대화 화면의 캐릭터는 화면 정중앙에 둔다.
- 대화 중 캐릭터는 상반신이 보이는 크기로 배치한다.
- 대사창·버튼·메뉴는 크림 라운드 방향으로 맞춘다. 장소·시간대의 분위기는 배경 그림이 담당한다.

‘중앙’은 기본 대화 인물의 가로 중심을 화면 중앙에 맞추는 기준이다. 상반신이 보이도록 캐릭터를 크게 표시하고, 세로 위치는 머리와 표정이 잘 보이게 조정한다. 특수 이벤트 CG의 별도 구도는 이 기본 입상 배치와 구분한다.

## 적용할 배치안

1. 맨 뒤에는 회사·카페·거리 등 상황에 맞는 배경을 전체 화면으로 표시한다. 밝은 낮·어두운 밤 모두 같은 화면 구조를 사용한다.
2. 그 위 중앙에는 투명 배경 캐릭터를 표시한다. 머리 전체·얼굴·어깨·상체가 자연스럽게 보이고, 정수리나 머리카락 끝이 잘리지 않도록 위쪽 여백을 확보한다.
3. 하단에는 크림색 대사창과 이름표를 겹친다. 얼굴·눈·입과 주요 표정은 대사창 밖에서 충분히 보이게 한다. 하단 창의 정확한 높이·투명도는 임시 그림으로 비교한 뒤 결정한다.
4. 선택지 세 개와 빠른 메뉴도 같은 색·글꼴·모서리 기준을 사용한다. 선택지는 얼굴을 피한 영역에서 읽기 편하게 배치하고 긴 한글 문장·존댓말 줄바꿈을 확인한다.
5. 휴대폰은 기존 오피스 라운드의 연락처·대화 나란히 배치를 유지하면서 공통 색·글꼴·버튼 규칙을 공유한다. 휴대폰 화면이 열린 동안 인물이나 배경을 어느 정도 보일지는 해당 화면 제작 때 검토한다.

## 원본 이미지와 제작 순서

전신 원본이 들어와도 파일을 영구적으로 잘라 덮어쓰지 않는다. 표시 단계에서 확대·위치·보이는 영역을 조정해 상반신 구도를 만든다. 인물마다 눈높이와 얼굴 크기가 크게 달라지지 않도록 기준을 맞춘다. 투명 PNG의 알파·머리카락 가장자리·잔상은 실제 납품본 검수 때 확인한다.

배경·캐릭터 자산이 없어도 전체 화면 배경 자리, 중앙 상반신 자리와 하단 대사창의 관계부터 임시 도형으로 검토할 수 있다. 이후 확정한 화면 구도에 맞춰 상황별 배경을 제작하고 실제 자산으로 교체한다. 배경 기본 비율은 16:9를 기준안으로 삼고 최종 해상도는 제작 때 확정한다.

리아는 사용자 새 마스터 대기·이미지 작업 보류를 유지한다. 이번 결정으로 기존 리아 이미지를 다시 연결하거나 새 그림을 생성하지 않는다. 네 히로인의 귀걸이 없음 규칙도 유지한다.

## 완료 판단

밝은 배경과 어두운 배경, 기본/부끄러운 표정, 길이가 다른 세 선택지, 1280×720과 1920×1080에서 얼굴·대사·버튼의 겹침과 가독성을 확인한다. 아직 이 배치로 실행 검증을 마쳤다는 뜻은 아니다. 다음 구현은 공통 UI 기준과 기본 대화 화면 적용이며, 이후 R08 휴대폰 화면을 연결한다.
