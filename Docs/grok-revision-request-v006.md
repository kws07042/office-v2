## 규칙

1. **아래 표의 줄만** 새로 쓴다. 다른 줄은 건드리지 않고, 장면 전체도 돌려주지 않는다.
2. **위치 확인:**
   - 줄 번호는 1부터 센다. 각 CG의 `lines` 배열에서 첫 항목이 1번이다.
   - 반환할 때 `old`에 지금 그 자리에 있는 문장을 **글자 그대로** 적는다. 그래야 위치가 맞는지 확인할 수 있다.
   - `who`(heroine/dohyun)도 표에 적힌 그대로 쓴다.
3. **금지 단어:** 아래 단어는 새 줄에 한 번도 쓰지 않는다.
   > 급해 / 천천히 넣을게 / 천천히 들어갈게 / 리듬 / 거기. 계속 / 더 세게 / 집중 / 흔들게 / 움직일게 / 가득 / 주물러 / 치료 / 진찰 / 같이 가요 / 다 받을게 / 보고 싶었어요 / 속도를 올려 / 단단 / 삼켜 / 젖어 / 두 개 / 이 옷 입은 채로 / 예쁘세요 / 귀여워요 / 서두르
4. **같은 문장의 기준:** 다른 히로인 장면에 이미 있는 문장, 또는 그 문장에서 어미·문장부호·감탄사만 바꾼 문장은 쓰지 않는다. 이번에 쓴 줄끼리도 겹치지 않게 한다.
5. **말투와 수위:**
   - 도현은 서윤·유진에게 항상 존댓말을 쓴다.
   - 서윤은 반말, 유진은 존댓말을 쓴다.
   - 절정 표현은 '싸' 대신 '안에 해 줘' 계열로 쓰되, 장면마다 다르게 쓴다.
   - 수위는 지금과 같게 유지한다.
6. **앞뒤 연결:** 표에 적힌 앞 줄과 뒤 줄 사이에 자연스럽게 들어가야 한다.
7. **제출 전 점검:** 줄마다 아래를 확인하고, 걸리는 줄은 고친 뒤에 낸다.
   - 금지 단어가 있는가?
   - 다른 히로인 장면에 같은 문장이 있는가?
   - 말투가 맞는가?
